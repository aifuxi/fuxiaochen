# 产品行为规范

本文件维护字段约束、公开条件、业务状态、查询与分页、保存和失败反馈，以及统计口径。由原 `DESIGN.md` 的业务规则拆分而来；本轮后台布局接入后的实际行为在下文维护，权限、写入校验和安全边界继续沿用既有约定。

共享视觉与基础控件状态见 [DESIGN.md](../../DESIGN.md)，页面布局分别见[前台场景规范](../design/frontend.md)和[后台场景规范](../design/admin.md)。数据库、正文数据格式、媒体上传协议和调度命令属于工程实现，分别查阅[数据库维护](../maintenance.md)、[媒体存储配置](../media-storage.md)和[部署文档](../deployment.md)。外部参考站与历史验收记录不直接覆盖本文件。

## 通用反馈与查询

- 加载、空库、无匹配、查询失败、提交中、成功和版本冲突分别提供文字反馈；查询失败可重试。不使用演示数据填补空集合，不展示没有数据来源的指标、通知或未实现的操作。
- 字段错误与实际控件关联；通用错误单独显示。失败保留当前输入或草稿，不能将写入成功后的查询刷新失败报成保存失败。删除保留原有确认和禁用条件。
- 写入期间禁用重复操作；需要确认或编辑的业务弹窗按对应章节禁用关闭。弹窗、菜单与字段的焦点行为沿用本地基础组件，业务完成后的焦点落点遵循以下各节。
- 时间与统计日期使用北京时间。查询变更取消旧请求，不能用旧条件的结果覆盖当前列表。
- 界面文案只描述操作、业务状态、输入要求和影响决定的限制。草稿保留、删除影响、第三方统计开关保持可见；开发阶段、框架、持久化机制、内部请求标识及交付过程放在工程文档。

## 登录

`/login` 继续服务端检查现有会话；有效会话直接进入 `/admin/posts`。用户名和登录密码均为 1～128 个字符，不裁剪或规范化凭据。登录密码下限与创建、重置密码的下限分别维护；用户名或密码不正确统一提示，不区分账号是否存在。

表单保留 `POST /api/login`、URL 编码或 multipart 正文。增强表单显式请求 JSON：字段输入错误返回 400、凭据错误 401、非同源请求 403、正文过大 413、正文类型不支持 415、限流 429、服务异常 503；429 保留 `Retry-After` 秒数。响应仅包含安全错误或明确的 `{ success: true }`，会话令牌只通过 Cookie 返回。客户端仅在成功状态和明确成功响应同时成立时完整 `replace` 到 `/admin/posts`；无法确认的响应和网络错误显示当前页提示，不自动重试，不将凭据写入 URL、日志或浏览器存储。

失败保留输入，并将焦点移到首个错误字段或通用错误提示；提交中禁止重复请求、输入只读。成功前不清空凭据。离开登录页后取消客户端请求并忽略旧响应，不覆盖用户的新导航。无 JavaScript 时继续原生提交：无效输入或凭据 303 回到 `/login?error=invalid`，成功 303 到 `/admin/posts`；403、413、415、429 和 503 保留对应状态的纯文字响应，因此原生 fallback 不承诺原位错误或输入保留。

安全处理顺序保持为禁止缓存、精确同源检查、16 KiB 正文限制、全局每分钟最多 20 次登录尝试、正文类型、Zod 输入校验、Better Auth 认证与签名 Cookie。非同源或正文过大不进入限流；正文类型错误及字段错误仍消耗尝试。限流或认证依赖失败拒绝登录并返回 503。会话 Cookie 由 Better Auth 生成和校验签名，保持 HttpOnly、SameSite=Strict、Path=/、固定有效期 7 天，不滑动续期、不启用 Cookie 会话缓存。开发环境名称为 `fx_admin_session`，生产环境使用 `__Secure-fx_admin_session` 并增加 Secure；成功登录仍撤销当前 Cookie 对应的旧会话。鉴权、会话撤销和数据库规则继续遵循 [AGENTS](../../AGENTS.md#后台鉴权与登录范围)。

单管理员账号只通过 CLI 创建和重置密码，关闭公开注册，不挂载通用 `/api/auth/*` 入口。首次 Better Auth 升级保留原密码并撤销旧会话；Passkey 增量迁移只新增表，保留已有认证数据。

通行密钥使用 Better Auth 官方 `@better-auth/passkey` 插件。登录页提供「密码登录」和「使用通行密钥」，通行密钥不要求先填写用户名或密码，成功完整导航到 `/admin/posts`。两种方式共用提交锁，取消或验证失败保留密码表单、显示中文反馈并解除锁定；不支持 WebAuthn 或非安全上下文时禁用通行密钥入口并说明密码备用。无 JavaScript 时密码原生提交仍可使用。

后台「管理账户」展示当前账号的真实通行密钥列表，支持可选名称（最多 64 字符）的添加，以及明确确认后的删除。注册要求有效且创建时间不足一天的登录会话，超过时提示退出并重新登录；不允许匿名注册或注册后另建会话。空列表、加载失败及重试有独立反馈。添加和删除期间禁止重复操作、关闭账户弹窗、退出和后台导航；写入成功后列表刷新失败分别说明两种结果，避免误报写入失败。删除取消不修改数据，删除成功移除条目并聚焦结果提示。删除使该密钥无法继续登录，已签发会话保持原有效期；密码或其他通行密钥继续可用。

只开放 `/api/auth/passkey/` 下的生成注册选项、验证注册、生成登录选项、验证登录、列出与删除六个官方接口。POST 延续精确同源与 16 KiB 限制；产生挑战的 GET 拒绝明确跨来源请求。生成注册选项、生成登录选项和验证登录各消耗一次共享全局每分钟 20 次尝试（完整通行密钥登录消耗两次）。挑战由插件持久化且一次性消费，注册与登录均要求设备用户验证；公开成功登录响应只有 `{ success: true }`，会话令牌只通过安全 Cookie 传递。

私钥由认证器管理，服务器保存公钥及签名计数，不自研 WebAuthn 验证。RP ID 固定取 `APP_ORIGIN` 的主机名，认证 origin 固定为完整 `APP_ORIGIN`，生产必须 HTTPS，本地使用 localhost。密码重置撤销全部登录会话并保留通行密钥；设备遗失可先用密码登录并删除相应密钥。备份恢复保留备份时的公钥列表，同时清空会话和挑战。账号无法登录时由现有 CLI 重置密码恢复入口。

## 后台列表、排序与按批加载

文章、友情链接、后台更新日志和备份仍通过真实服务端分页 API 取数：先对完整筛选结果排序，再读取指定批次，不能只排序当前已加载条目。前端将成功返回的批次按服务端顺序合并、按记录 ID 去重，通过条件追加入口访问后续记录。分类一次加载完整真实集合，再用 TanStack 对完整集合排序并按所选数量展示。

| 列表                 | 默认每批条数 | 数量与排序规则                         |
| -------------------- | ------------ | -------------------------------------- |
| 文章、友情链接、分类 | 8            | 保留 8、10、20、50 的每次加载条数选项  |
| 后台更新日志         | 8            | 默认按真实创建时间、ID 降序            |
| 备份执行记录         | 8            | 默认按真实创建时间降序，同值按 ID 降序 |

上述后台列表不显示常驻分页条。存在后续记录才显示“显示更多记录”“显示更多分类”或“加载更早更新”等追加入口；成功后保留已加载记录，聚焦首条新记录，并向辅助技术播报已显示数量。文章旧 URL 的 `page` 深链从指定批次开始；前面仍有记录时提供“显示前面的记录”，可继续向前或向后加载，全部记录均可到达，不悄悄改写原深链。

搜索、筛选、排序和每次加载条数变化重置到首批，写入后的版本变化或明确刷新清空已追加结果，重新查询当前起始批次；已有 `page` 深链仍保留其起点。条件变化与离开页面取消旧请求，旧响应不得串入新条件；追加失败保留已加载结果、明确失败并提供重试。服务端在数据减少后仍校正越界页码，客户端据返回批次合并，不显示虚构空页。排序通过具名控件提供适用字段的升序、降序及默认顺序；保留表格的其他场景继续遵守标题、表头、行标题与可访问排序状态规范。

`GET /api/admin/backups` 接受 `sortBy=createdAt|status|bytes` 与 `sortDirection=asc|desc`，默认 `createdAt desc`。状态升序为 `running`、`complete`、`failed`，降序反转；按原始字节数排序时，`null` 表示未知大小，升降序都置于末尾。任一主排序值相同均按 ID 降序，分页前完成排序。

行操作使用点击打开的菜单，不通过 hover 展开。保留方向键、Enter、Escape、外部点击及焦点恢复；关闭菜单或取消确认回到行按钮。删除成功聚焦搜索或新增入口，具体业务有更明确落点时按对应章节执行。

## 后台入口

后台默认页为文章管理 `/admin/posts`，不再提供工作台。旧地址 `/admin` 在服务端鉴权后重定向到文章管理，匿名访问仍进入登录页。

文章列表保留已发布、草稿数量与筛选，写入成功后刷新相关查询；不再请求工作台专属的文章汇总与最近草稿数据。文章页面内的新建、列表的编辑入口统一进入独立写作页面，分类和备份通过侧栏进入各自管理页。各入口的视觉层级见后台场景规范。

主题切换、通知和账户菜单通过 Dock 访问；手机端通过左下角悬浮按钮打开导航抽屉。后台不再提供顶部栏及全局新建入口。通知保留真实未读数量、未知／失败提示与重试；账户菜单保留通行密钥和退出功能。关闭通知或账户弹窗回到原 Dock 按钮，手机端回到悬浮导航入口。

## 文章管理与写作

### 列表与入口

`/admin/posts` 管理实际文章、分类和标签。全部文章、已发布、草稿箱三个筛选入口与分类、关键词组合筛选；状态数量来自完整文章集合，筛选、搜索、排序和批次查询由服务端执行，前端按本节规则追加。

列表展示标题与人工摘要、分类、状态、精选、时间、标签和操作。人工摘要留空显示“未填写摘要”；精选不提供排序，保留“精选 · 排序值”信息。精选筛选为全部、精选、非精选，与其他筛选组合并重置到首批；重置时一并清除精选筛选。

操作菜单提供编辑与删除；已发布文章可在新标签页查看前台，所有状态可设为精选或取消精选。精选快捷操作保留排序值，提交中禁用重复操作，成功刷新查询；冲突刷新后需再次操作，失败明确提示。行操作有包含文章标题的可读名称。空状态提供重置筛选或创建入口；删除后刷新当前查询并重置追加结果，服务端校正越界批次。

新建地址为 `/admin/posts/new`，编辑地址为 `/admin/posts/[id]/edit`；两个页面分别要求管理员权限，进入编辑页继续标识内容管理导航。

文章仅支持草稿与已发布状态，发布由管理员手动保存执行。旧状态筛选链接清除无效状态并进入全部文章，保留其他筛选。

### 设置、字段与发布状态

文章设置默认关闭，以“发布与归类”“内容摘要”“展示与排序”三组收纳原有 slug、分类、标签、摘要、精选、排序和状态字段。真实正文继续使用 Tiptap，导入、媒体、历史与保存能力不因分组而替换。关闭设置不丢失输入，关闭后焦点回到文章设置按钮；所有宽度均使用右侧抽屉，保留关闭与保存操作。

- 标题最多 120 字符，保留可访问标签与字段错误。草稿可暂不填写标题、slug、分类和正文，保存时仍校验已填写字段及正文结构；空标题在列表、检索和引用确认中显示“未命名草稿”，空分类显示“未分类”，不将占位文案写入文章。发布前必须补齐标题、唯一 slug、分类和有效正文。
- slug 手动填写，草稿留空时不生成链接，填写后显示相对链接与字段错误；首次发布后只读并说明原因，删除文章后可复用该 slug。
- 摘要可留空，建议 50～100 字、最多 200 字符，显示当前字符计数。人工摘要与精选配置在文章设置中编辑，列表只提供预览和精选快捷操作。
- 精选排序为 0～9999，数值越小越靠前；仅开启精选时可编辑，关闭精选保留排序值。草稿和已发布文章均可维护精选。
- 上述字段参与未保存状态、失败输入保留、重新载入和隐藏错误定位。保存中禁用控件；隐藏字段无效时自动打开设置并定位首个相关错误，标题和正文错误在写作画布内提示。设置入口用“待完善”或“有错误”标明状态。
- 首次发布时间保持不变，修改时间单独显示。发布后继续锁定 slug；删除文章须确认，并清理文章与标签的关联。

### 写作与保存

文章编辑页默认进入独立文档工作区，隐藏后台 Dock、手机悬浮导航与页脚，离开后恢复，不调用浏览器全屏。写作栏提供返回、真实标题与保存状态、文档目录入口、主题切换、更多操作、文章设置和保存。目录按正文 H1–H6 实时生成，区分同名标题并跟随滚动；目录点击只滚动，不写入正文、不增加路由历史。

手动保存后可以继续写作。首次创建成功以 `replace` 进入该文章的编辑地址；之后使用返回的文章版本继续保存，不重建正文实例，不清空光标、滚动位置和撤销历史。已有文章状态为“未保存／保存中／已保存”，尚未创建且未修改时显示“新草稿”；初始化规范化正文不计为用户修改。Ctrl／Cmd+S 触发同一个手动保存流程，编辑浮层尚未完成时不提交。

保存失败保留输入；版本冲突需在重新载入前确认替换。提交期间禁用重复保存、页面内退出操作及编辑相关操作；成功后刷新后台查询，写入成功与刷新失败分别反馈。不增加自动保存、自动生成 slug 或本地草稿。

### 块编辑与代码操作

正文支持段落、H1–H6、列表、任务列表、引用、高亮块、代码块、分隔线、表格、链接与图片；文字支持加粗、斜体、下划线、删除线、行内代码、预设文字颜色及背景高亮，段落和标题支持左／中／右对齐。输入 `/` 搜索插入块，方向键切换、Enter 插入、Escape 关闭；中文输入法组合输入期间不触发选项。菜单不夺取正文输入焦点，以 `listbox`、`aria-activedescendant` 与文字提示表达选择。

选中文字出现格式操作；文字类型为带当前项的列表，H4–H6 收进“其他标题”，不复用块菜单的图标网格。颜色分为最近颜色直接应用与展开色盘，最近颜色按 Editor 隔离，不进入正文。链接在选区下方编辑，非法地址保留输入，清空确认则移除链接。空段落只有一个“＋”插入入口；有内容的块侧显示当前类型图标与拖拽手柄，点击其中任一入口打开同一个块菜单，拖动手柄排序。正文末尾不显示常驻操作。右键操作指针所在的块，Shift+F10 操作光标所在的块；触屏可长按块打开上下文菜单。菜单打开时选中整块，后续转换、对齐、颜色、剪贴板复制／剪切、创建副本、删除和上下移动均作用于该块。块选中时不再叠加文字选区工具栏。

插入菜单的基础类型使用图标网格，图片、表格与高亮块使用常用条目；块菜单通过子菜单选择对齐、颜色及上下方要添加的实际内容类型。取消图片或表格选择不产生空段落。剪切只有复制成功且目标正文未变化时才删除原块；剪贴板失败显示可读反馈。菜单关闭后保留目标选区，键盘取消恢复正文焦点；整篇替换、删除或撤销后忽略失效位置，不能读取越界节点。表格提供锚定的 9×9 行列选择、增删行列、合并／拆分、标题行／列、单元格预设背景、列宽拖动及均分。点击顶部／左侧选择条选择整列／整行，Shift 扩展，边界插入点新增行列；普通单元格光标不显示浮动栏，单元格选区才显示表格与文字操作。合并和拆分共用一个入口，按选区能力切换；不可执行的命令禁用。图片可上传后直接插入，或粘贴完整 HTTP／HTTPS 图片 URL，插入后通过图片更多菜单设置替代文字。正文错误关联实际可编辑区域。

前后台代码块提供常驻语言名称与“复制代码”。后台可选语言，前台只展示名称；未知语言保留名称并按纯文本显示，未指定时显示“纯文本”，不自动识别。复制保留原始缩进和换行；成功显示“已复制”两秒，失败显示“复制失败，请手动选择代码”，以可访问状态文字反馈。保存期间后台语言与复制工具禁用。语法高亮不改变代码文本、编辑选择或撤销历史。

### Markdown 导入

写作栏“更多文档操作”提供“导入 Markdown”，可以选择 UTF-8 的 `.md`／`.markdown` 文件或粘贴源码；文件最多 1 MiB，源码最多 100,000 字符。支持 GFM；原始 HTML 和不支持的语法保留为文字，不执行。

导入插入打开弹窗时的光标位置，不替换选区，不修改标题和设置，作为一次可撤销操作并标记未保存。取消不改变正文；插入前校验合并后的完整文档，失败保留输入和原正文。文件读取时禁用重复读取与导入，保存时禁用导入；关闭后焦点回到正文。正文存储格式和渲染机制见[数据库维护](../maintenance.md)。

## 编辑器图片

不提供独立媒体库页面、后台素材列表或全局上传队列；侧栏不再提供媒体入口。文章正文保存图片 URL、替代文字、图注、可选宽高与归一化裁剪矩形；删除正文图片不删除 OSS 对象。选中图片的紧凑工具栏提供原位裁剪、图注与直接对齐；更多菜单可替换、编辑替代文字、按整数宽度调整、恢复原始尺寸和删除。裁剪不修改原始文件或重新上传，Enter／外部点击完成，Escape 取消，恢复裁剪与撤销都可还原；图注和替代文字独立。四角拖动保持当前可见图片的比例。替换上传成功后清除旧裁剪和宽高，保留图注，可撤销恢复原图。宽高范围为 1～10,000px；尺寸 Dialog 按当前可见图片比例计算高度，非法输入保留原图和输入。

- 「图片」和「替换图片」直接打开系统文件选择器，不先弹出上传表单。选图后在正文原位显示本地预览、文件名、上传阶段／百分比和取消；一次只运行一个图片任务，上传与失败状态都不写入正文。
- 上传期间允许继续编辑正文和切换主题，保存暂时禁用；存在未完成或失败任务时启用离开保护。锚点跟随正文事务、撤销和重做移动，完成时在当前位置插入独立图片段落，不覆盖原选区或上传期间输入的文字。原位置被删除、整篇替换或原图变化时取消任务，不恢复已删除内容。
- 取消停止签名或 PUT 请求、移除占位并回焦正文；取消替换保留原图。晚到的成功和进度不得插图。失败保留文件与预览，可在原位重试；重复点击不并发上传，成功上传但插入失败时复用 URL。相同文件可以取消后重新选择。
- 上传完成时若正文仍在中文组合输入中，等待候选提交后插图；等待期间仍可取消。斜杠菜单、链接、图片描述及保存快捷键识别组合输入和 keyCode 229，不把候选确认当作编辑命令。触屏缩放在松手时提交一次，系统取消手势时还原，卸载清理监听。
- 未设置替代文字时上传图片沿用文件名，之后从图片更多菜单编辑。写作栏「更多文档操作 → 插入网络图片」使用锚定正文位置的非模态 URL 浮层；只检查完整 HTTP／HTTPS URL 与正文结构，不探测远程文件，错误保留输入并关联控件。
- 应用不执行文件大小、摘要、格式解码和像素数校验，不下载上传内容，也不调用完成核验接口。签名接口保留后台认证、同源保护、JSON 请求约束和每分钟限流。
- 删除正文图片、替换图片、删除文章和取消上传不触发 OSS 文件删除。上传后未插入或未保存的文件也保留；需要回收时由管理员在 OSS 控制台自行处理。
- 新图片无需媒体数据库记录。文章、站点设置和友情链接允许保存合法图片链接，不依赖本站媒体记录状态；既有正文链接和历史媒体元数据保留。

签名配置与存储范围见[媒体存储配置](../media-storage.md)。

## 分类与标签

分类、快捷分类入口、文章编辑和文章筛选共用实际分类与标签，不导入演示列表。空列表引导创建；加载中显示文字状态，失败提供重试和会话失效后的登录入口。

分类与标签通过顶部 Tabs 切换全宽内容；通知的 `record`／`kind` 定位打开正确分组。分类提供名称、颜色、页首新增 Dialog、编辑、搜索、排序与按批展示的紧凑分类块；标签提供名称、添加与可移除的列表。分类颜色是用户数据，不改变主题。分类编辑保留 ID 与文章关联；保存时比较打开编辑时的名称、颜色，过期编辑须放弃修改并重新载入，重名失败保留输入。名称去除首尾空格，空值或忽略大小写的重名显示关联字段错误。

写入期间禁用重复操作，成功后更新列表并清空表单，失败保留输入。分类删除须确认，标签直接移除；取消分类删除回到触发按钮，删除成功回到页首新增分类按钮；新增 Dialog 关闭后也回该入口。标签移除后焦点移至相邻移除按钮或新增标签输入。

文章与分类、标签的关联持久化，后台关联数量来自完整数据库集合，前台只统计已发布文章。文章从已有标签中多选并提供移除选中项；历史演示分类或标签未登记时明确标记，保存前须重新选择或移除。新建文章没有可用分类时引导前往分类管理。

## 友情链接

`/admin/friends-links` 提供分类、审核、展示状态与关键词筛选；服务端按名称、地址、简介进行字面搜索，默认每批 8 条，按完整结果筛选排序后追加；删除后重查首批，服务端继续校正越界批次。

审核状态为待审核、已通过、已拒绝，展示开关独立标明“启用／停用”，新建默认待审核。前台只公开已通过且启用的记录；不展示健康状态、不探测外站。

表单包含名称、HTTP(S) 链接、图标、简介、分类、审核与展示开关。HTTPS 或站内图标图片失败时显示 `Link2`。字段错误关联控件，加载和查询失败明确反馈；提交中禁用输入、关闭和重复操作，失败保留草稿。

新增成功后清除筛选和通知定位，恢复默认的创建时间降序，重查首批；待表单关闭及真实记录出现后聚焦新项。编辑成功保留当前筛选和排序，重置已追加批次。

冲突时可明确放弃草稿重新载入，再确认保存；删除冲突须重新载入最新记录并再次确认。删除取消焦点回到触发按钮，成功回到搜索框。

## 更新日志

`/admin/changelog` 支持新增、读取、编辑、撤回与重新发布，不提供永久删除。撤回保留记录和内容，前台隐藏；重新发布保留原创建时间。后台按已发布／已撤回筛选，按版本、主题、条目进行服务端搜索；默认每批 8 条，按真实创建时间和 ID 降序，日期显示北京时间。列表仅在有后续记录时提供“加载更早更新”，保留前述追加、错误重试和焦点规则。空条目显示“未填写更新详情”，不生成虚构更新。

类型为功能特性、缺陷修复、性能优化、安全加固。发布表单包含版本文案、主题、类型与可选逐行清单；版本必填、不限制 SemVer，清单最多 20 条、每条最多 200 字符。

校验错误关联字段并聚焦；提交中禁用输入、关闭和重复提交。新增成功清空搜索并重查首批；编辑成功保留当前列表条件并重置追加批次，创建时间不变。保存成功与列表刷新失败分别反馈。响应不确定时保留草稿，先查询核对记录，再明确允许重新提交，不自动重试创建。编辑和状态切换使用独立的数字 `revision` 拒绝过期写入，版本文案仍为原始 `version` 字段；冲突保留编辑输入，可明确放弃修改并重新载入。撤回和重新发布均须确认，状态切换失败或结果不确定时先载入当前状态并重新确认。发布日志不部署软件。加载、空库、无匹配与失败分别反馈。

前台 `/changelog` 仅读取已发布记录，仅第一页第一条标记“最新”，历史页不显示。无效页码提示“页码无效，请返回更新日志。”，提供指向不带查询参数 `/changelog` 的“返回更新日志”入口。

## 系统设置与公开资料

### 设置保存与分组

`/admin/settings` 提供资料与站点、SEO、系统偏好、备案、社交账号、访问统计六个分组。保存所有变更为一次原子写入；加载和查询失败明确反馈，失败保留草稿，版本冲突须明确确认后重新载入。错误切换至对应分组并聚焦字段；提交中禁用输入与重复保存，重新载入与保存均在页首操作区，重新载入作为次要操作保留。

`group=analytics` 仍直接选择访问统计分组，仅提供 GA4／百度配置；其他 group 默认资料与站点，定位不改变或保存配置。

备案由展示文案与 HTTPS 查询链接配对组成；整项可留空，填写时须完整。

社交账号最多 20 条，同平台可以有多个账号；支持预置 Lucide 图标或 HTTPS／站内图片、启停和上下排序。排序和删除有可读名称，操作后焦点回到相邻条目或新增按钮；图片失败显示通用图标。

GA4／百度分别提供启用开关和站点 ID，不提供任意脚本输入；默认关闭，开发环境不采集。阅读偏好控制前台文章每页条数。不展示自动备份、AI 服务或开发信息占位项，备份功能由控制台独立入口承载。

### SEO 与搜索索引

- 站点名称用于默认标题和栏目标题后缀；搜索描述最多 300 字符，留空依次使用副标题、个人简介及站点默认描述。关于页优先使用个人简介，其他栏目提供与用途对应的描述。
- 文章搜索与分享描述优先使用完整人工摘要；留空时合并正文纯文本空白后取前 160 字符，超出追加省略号，没有文字时使用文章标题。列表正文摘录仍取前 100 字符，两处不回写数据库。
- 默认分享图片接受 HTTPS 图片链接或站内绝对路径，留空使用项目内置 PNG。文章优先使用正文首张可用于公开分享的 HTTP(S) 图片，再回退到配置图片和内置图片；相对正文图片按文章 URL 解析，带凭据的图片不进入元数据。公开页面输出完整 OG、Twitter 图卡与各自 canonical。
- Google Search Console、Bing Webmaster Tools、百度搜索资源平台验证独立于访问统计；每项最多 200 字符，只接受字母、数字、下划线与连字符，填写 token 而非整段标签或脚本。留空不输出对应验证标签。
- 正常文章和日志分页具有独立 canonical；`page=1`、重复业务参数及超出总页数的有效页码规范化到实际地址。未知与 UTM 参数不进入 canonical，必要跳转保留它们；非法参数保留原有错误反馈并禁止索引。
- 文章关键词、分类、标签筛选和友链分类结果设为 `noindex, follow`；原分类、标签栏目地址永久跳转到文章页，不再单独进入 sitemap。登录和后台设为 `noindex, nofollow`，后台继续服务端鉴权。不存在或未发布的文章保持 404 和 noindex。
- 首页、关于和文章输出与真实资料一致的 WebSite、Person、ProfilePage、BlogPosting 和文章面包屑结构化数据；文章结构化数据只使用实际正文图片，无图时省略 image，不将默认品牌分享图作为正文图片。结构化数据不保证搜索引擎采用或即时更新展示。
- sitemap 只包含公开栏目与已发布文章，发布、撤回和修改后在下一次请求更新；文章使用实际修改时间，栏目没有独立修改时间时省略 lastmod。robots 允许读取登录页 noindex，限制后台和 API 抓取。

### 首页、导航与页脚内容

首页从 `getPublicSettings` 读取站名、副标题和个人资料，标题优先副标题、为空回退站名。作者资料辅助识别，完整介绍由关于页承载；简介取真实个人介绍首段，压缩空白并限制为 72 个 Unicode 字符，超出追加省略号；完整原文保留在关于页，空值省略。阅读 CTA 进入 `/posts`。

首页读取最近三篇已发布文章，按既有发布时间降序，不受文章列表 `postsPerPage` 设置影响；精选不改变排序。标题、摘要、分类、日期沿用列表同源数据，不增加统计、虚构内容或写入操作。空库显示尚无公开文章。

前台导航收敛为：首页、文章、日志、友链、关于。导航使用真实链接，当前项声明 `aria-current="page"`，子页归属对应栏目，首页精确匹配。767px 及以下或空间不足时使用可访问折叠菜单，保留关闭、回焦和跨断点复位。

`/categories` 与 `/tags` 不再提供独立页面，均以 HTTP 308 永久跳转 `/posts`，原始查询参数透传，包括筛选、页码与重复追踪参数；目标页面继续执行已有参数校验、规范化和索引规则。分类、标签管理及文章关联不删除。

页脚仅展示作者与已填写备案，并提供后台登录入口；不重复站名、副标题、栏目导航或社交账号。社交账号在关于页展示，只显示启用项、保持配置顺序，没有账号时隐藏联系区域。备案与社交外链在新窗口打开并使用 `noopener noreferrer`。

统计不提供可见加载界面，采集或加载失败不阻碍阅读。关于、更新日志和页脚读取真实资料。

## 博客阅读与前台查询

`/posts` 承担文章列表、关键词、分类、标签与分页。页首 h1“文章”显示真实文章总量，结果栏另显示“全部文章”或当前匹配数；列表文章标题 h2，首页近期标题 h3。分类和标签计数仅包含已发布文章，并显示全库公开总量，不随当前组合条件重新计算。

关键词、分类与标签可组合，URL 保留 `q`、`categoryId`、`tagId`、`page`。搜索有可见标签，支持 Enter 或具名提交；分类直接呈现，标签可展开，每类单选。已选标签在载入时展开，用户可主动折叠。点击分类、标签及逐项清除即时应用，不再保留“取消／应用”弹窗草稿。

搜索提交保留当前分类和标签；分类、标签切换保留已应用关键词，均回到第一页。已选条件可以逐项移除，也可一次清除。请求期间禁用重复操作并显示“更新文章列表中”，结果与地址同步；空库、无匹配、加载和参数／查询错误分别反馈，真实错误不暴露内部异常。

详情通过 `returnTo` 保留来源列表的有效关键词、分类、标签和页码，刷新后返回仍有效；只接受站内 `/posts` 与这四种已校验参数，非法地址或参数回退 `/posts`，不允许跨站跳转。返回上下文不进入文章 canonical、OG URL 或 JSON-LD。同一标签页存在有效列表快照时，顶部或底部返回入口恢复离开位置与文章链接焦点，详情刷新不清空快照；浏览器后退／前进保留原生历史与滚动行为，存储不可用时仍正常导航。

文章与日志翻页保留既有查询条件；不足两页时隐藏分页。分页可用项保留链接语义，不可用项使用真实禁用按钮；显示“当前页 / 总页数”，辅助技术读取“第 1 页，共 3 页”等完整含义。视觉调整不改变页面内容与排序。

文章列表保留日期、摘要、分类、标签与文字“精选”，精选不改变发布时间排序。标题与摘要共用文章链接，由标题关联可访问名称，分类和标签可独立操作。人工摘要为空时，将正文纯文本合并空白后取前 100 字符，超出追加省略号，不回写数据库；没有文字时不显示摘要。前后台关键词搜索均包括人工摘要，正文搜索只匹配文字。

首次发布时间与修改时间分别展示；文章标题自然换行，图片不超出阅读宽度，代码和表格只在自身容器内横向滚动。Markdown 是导入格式，原始 HTML 按文字显示；内容格式和静态渲染机制见[数据库维护](../maintenance.md)。

## 通知与备份

通知徽标显示真实未读数量；读取失败显示未知数量并提供重试。已读与已处理分别展示，不将已读视为审核完成；“本页全部已读”只作用于当前显示的通知。

数据库备份通过 `/admin/backups` 管理，Dock 与通知的备份入口统一跳转该页。页面保留最近执行、自动备份、范围说明与真实执行记录；记录按前述服务端排序和按批追加规则读取，完整编号、字节数、校验摘要与执行状态可在详情核对。自动备份默认关闭，显示真实调度时间和执行记录，配置外部调度后执行。备份只包含数据库与媒体元数据，不包含 OSS 文件；备份进行中禁用重复提交。调度、备份范围和恢复约束见[部署文档](../deployment.md)。

## 后台编辑保护与记录定位

文章与系统设置按实际字段变化判断未保存；空白新文章不提示。站内链接、返回、程序跳转和退出均需选择继续编辑或放弃修改，保存期间阻止离开。浏览器前进／后退先恢复当前历史条目再确认，不新增占位历史；刷新、关闭与跨文档离开使用原生提醒，受浏览器平台支持限制。继续手动保存，不提供本地草稿恢复。

文章列表以 URL 保存关键词、状态、分类、精选、排序、每次加载条数与起始页码；旧 `page` 作为首次批次定位，后续追加不改写原 URL。进入文章编辑时先记录该文章所在的真实批次，返回后从该批次开始展示。编辑页只接受本站 `/admin/posts` 返回地址。通知通过 `record` 定位具体记录，定位查询忽略普通筛选，提供返回全部及目标不存在反馈。原有文章、友链和日志模块地址仍可使用。
