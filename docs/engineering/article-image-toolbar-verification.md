# 飞书图片预览工具栏与交互复查（2026-10-18）

本轮按用户指出的白底问题，替换此前“普通 overlay 工具栏”的适配。前次验证是历史事实，当前外观与行为以本记录为准。范围仅为前台图片预览和 Tooltip 的可选局部层级；不改 API、正文格式、数据库或依赖。

## 参考与采用范围

实际操作[飞书测试文档](https://my.feishu.cn/wiki/JZpsw3rXwiMra2k1Rm7cOHYFnXg)，独立标签只读采集，未改写文档。1280×720、100% 缩放下 computed style：工具栏 black 70%、6px 圆角、高 48px、内边距 12px／16px；24px 图标与工具目标、白色文字、disabled white 40%、组间竖线。关闭按钮为 black 60%、48px 圆形、顶／右 20px；全屏遮罩 black 80%。截图 `02-reference-rotate.png` 显示原尺寸与旋转后的工具栏及白色提示气泡。

实际运行参考原尺寸切换、旋转、拖动、点击图片／空白关闭和 Escape。原尺寸切换后由 1:1 图标变为适配图标；1024px 原图在 1280×720 的默认显示尺寸为 648px（视口高的 90%）。原尺寸拖动后图像 top 从 -152px 变为 -102px；拖动不关闭，单击图片和空白关闭。指针移动后控制层显示，空闲 1.8 秒后观察到隐藏。滚轮采集会改变浏览器焦点／文档位置，本轮不据此推定参考滚轮语义，也未新增滚轮缩放。

采用上述控制层外观、分组、单按钮切换、图片留白、点击关闭与指针显隐。项目适配：保留 Inter 与现有 Lucide；窄屏／粗指针仍为 44px 目标，工具组换行；本地空闲时限为 1.5 秒，键盘保持可见，触屏不自动隐藏；保留多行图注与原图链接，不增加下载代理和区域评论。前台工具栏宽 402px，参考为约 451px，源于操作集合不同，不宣称图像或整栏像素完全相同。

## 实现与发现的问题

- 局部媒体变体直接消费 Semi black／white，深浅主题均不再变成白色卡片；工具栏无 modern 阴影，关闭按钮恢复深色圆形，Tooltip 为白底深字，禁用、hover、active、focus-visible 各有明确状态。
- 图片按完整画布的 90% 适配，悬浮工具栏不挤占图片布局；保留原生局部滚动与键盘，隐藏画布滚动条外观。根滚动预留区在打开时着相同遮罩色，避免白边；六组关闭后均恢复原值，不改变阅读列宽度。
- 原始尺寸／适应窗口合并；缩放使用整数百分比计算，避免连续加减影响 100% 判断。新增 helper 测试覆盖视口、旋转长边、小图、缺少尺寸、连续缩放与边界。
- 普通画布点击通过 Base UI Close 结束，拖动后使用公开 `preventBaseUIHandler()` 阻止关闭；单用 `preventDefault()` 无法阻止 Base UI 行为，已实际修复重测。适配状态下拖动也记录位移，避免不产生滚动时误关；pointercancel 清理拖动状态。
- Tooltip 通过可选 `positionerClassName` 提升至 70，只改变预览实例。末轮发现 Tooltip 抢先消费 Escape，已在预览的捕获阶段统一关闭；重测一次 Escape 后预览消失，焦点回到原图片。
