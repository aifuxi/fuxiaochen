# Better Auth 认证迁移验证

验证日期：2026-10-13。范围为单管理员用户名密码登录、服务端会话、后台鉴权及 SQLite 运维适配；Passkey、MFA 和公开用户体系不在本次实现范围。

本文件记录首次认证迁移阶段；后续官方 Passkey 插件接入与验证见 [Passkey 验证记录](passkey-verification.md)，下文的未实现范围以首次迁移时点为准。

## 实现范围

- Better Auth 与官方 Drizzle 适配器固定为 1.7.7，Argon2id 保留；会话生成、密码验证、Cookie 签名和请求 Cookie 解析由库负责。
- 关闭公开注册，不挂载通用认证接口；现有表单响应、同源检查、请求限制和持久化限流保留。
- 新增四张认证表，迁移原管理员与密码哈希，撤销旧会话；创建/重置 CLI、PostgreSQL 导入及备份恢复同步适配。
- 项目保留同步事务内的业务会话复核及哈希存储适配。适配器每条写 SQL 使用 IMMEDIATE 事务，登录替换和密码竞态复核与插入会话原子执行；不宣称任意未来插件具备异步多语句事务支持。
- CLI 使用独立的同步会话读取模块，避免运维文件追踪加载完整 Web 认证框架。OpenTelemetry API 固定为 1.9.1，补齐框架可选导入的打包依赖；未启用外部遥测。
