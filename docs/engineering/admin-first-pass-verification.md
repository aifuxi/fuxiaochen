# 后台首轮调整验收记录

日期：2026-10-07。对应[后台场景规范](../design/admin.md)与[产品行为](../product/behavior.md)。本轮保留手动保存，不升级依赖，不修改数据库 contract 或执行业务库迁移；未推送或部署。

## 已实现

- 文章与系统设置按真实字段变化保护编辑，统一处理侧栏、返回、快捷入口、全局搜索、退出、浏览器历史及原生离开提醒。保存进行中拒绝离开。
- 文章筛选、排序和分页持久化到 URL；编辑返回地址限定为本站文章列表。全局搜索和通知定位具体记录，分页模块支持精确 ID，媒体自动预览，目标不存在有明确反馈。
- 媒体引用 API、结构化 URL 识别、强删勾选门槛、事务内指纹复核及新增引用拦截。保留失败删除的重试状态和强删留下的原有链接。
- 工作台优先新建、最近三篇草稿和待办；侧栏按内容、互动、数据、系统分组。备份使用独立鉴权页面，分类与发布计划复用完整管理页。
- 工作台保留流量摘要，详细图表集中到数据分析。采集前值为 `null`，折线不跨缺失日期连接；开关沿用可见标签作为可访问名称。

## 运行通过

### 独立数据库与自动测试

测试创建并清理独立 PostgreSQL 数据库，真实业务库未用于写入回归。

- PostgreSQL 集成测试：结构化图片及链接、站点配置、停用社交配置和友情链接引用；查询参数与片段忽略；草稿、排期覆盖；无强删授权拒绝；指纹变化拒绝；强删后原链接保留；新引用及重复增加引用拒绝；模拟 OSS 删除异常后重试；共享写锁串行保护。
- 精确定位查询绕过原筛选，通知与搜索返回具体地址；文章统计、最近三篇草稿和采集前空值／覆盖期零值验证。
- 登录、SEO 单元测试，以及独立库 HTTP SEO 集成回归通过。
- 返回地址校验与趋势几何测试覆盖空集、全部不可用、零值、单点和缺口，坐标与路径无 `NaN`／`Infinity`。
- 类型检查、lint、全仓库格式检查和生产构建通过。构建复用已安装的 Prisma 8 RC 与 Next.js 16.3.7，数据库 contract 未变化。

### 浏览器操作

使用本地已有开发服务进行只读检查；保存、发布计划、备份和退出在临时独立数据库的开发实例执行，结束后清理实例、数据库和测试备份。

- 空白新文章不提醒；文章修改后侧栏、返回触发提醒，取消后标题和正文保留。
- 连续后退、前进、取消恢复、确认放弃均保持当前编辑直到确认；确认后进入目标一次。新建成功使用地址替换，后退直接回到列表，未增加新建页历史条目。
- 保存成功后离开不提示；字段校验失败和服务端版本冲突均保留输入与未保存状态。系统设置跨分组修改、取消离开、保存后进入备份页通过。
- 退出前提醒可取消；确认放弃后真实退出，回到登录页。
- 原列表关键词写入 URL，编辑再返回保留条件。媒体搜索定位到单条记录并自动预览，返回全部恢复列表。分类类型定位与目标不存在反馈通过。
- 引用删除弹窗展示实际文章引用，未勾选时不能强删，勾选后允许提交；实际媒体对象未删除。
- 独立库即时备份生成完成记录；执行到期计划发布一篇文章；取消未来排期后回到草稿箱。
- 390px 工作台、移动端分组导航和 Escape 关闭通过；关闭完成后焦点回到导航按钮，页面无横向溢出。自动备份开关的名称为“每日自动备份数据库”。
- 数据分析全部不可用趋势没有伪造零点，日期按钮读出“暂无可用数据”，SVG 路径无非有限坐标。

## 仅源码核对

- 不支持 Navigation API 时，项目 history 索引保留 Next.js 原 state，后退后的新分支从当前索引递增；未插入占位历史。
- 保存／后台操作进行中对历史事件和程序跳转的阻止；媒体引用查询失败时禁止删除。
- 其余定位模块（标签、评论、友情链接、更新日志）的高亮、滚动、缺失提示，以及通知历史地址兼容；服务端精确查询已有独立库验证。
- 共享交互状态与 `prefers-reduced-motion` 沿用本地 Base UI 和现有设计系统；本轮未新增共享 token。

## 未验证与不适用

- 未逐一运行 Safari、Firefox、无 Navigation API 的旧浏览器；历史兼容分支需后续跨浏览器实测。
- IAB 刷新请求被阻止且输入保留，但工具未暴露原生提醒界面；真实关闭标签页、关闭窗口与跨文档跳转的原生确认界面未逐一验收。
- OSS 删除在独立库测试中模拟 SDK 响应，未对实际远端对象执行强删；自动调度器和线上部署不在本轮验证范围内。
- 未逐一覆盖所有操作系统的中文输入法、粗指针、减少动态效果偏好及屏幕阅读器组合；不能将截图或类型检查视为这些交互已经通过。
- 草稿字段放宽、分类编辑、更新日志编辑与撤回按计划留到下一轮。
