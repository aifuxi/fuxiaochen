# UI 参考采集与回归

本文件规定参考站对齐和 UI 修改的执行、验证与交付方式。共享视觉规则由 [DESIGN.md](../../DESIGN.md) 负责，页面规格由 [前台](../design/frontend.md) / [后台](../design/admin.md) 场景负责，业务行为由 [产品行为](../product/behavior.md) 负责；本文件不另设 token 或业务规则。

## 实现前：把参考行为变成可核对的目标

先列出本次范围：页面、组件、共享规则、已有数据与保留的业务行为。逐项读取相关规范，并实际操作参考页面；截图用于记录构图，不能替代交互采集。记录来源 URL、日期、视口、缩放、滚动位置及观察到的状态；源码或 computed style 用于核对数值，无法观察的值明确标为未知。

每个受影响交互至少记录适用的以下信息：

| 信息     | 要记录的内容                                                   |
| -------- | -------------------------------------------------------------- |
| 默认状态 | 内容、可见名称、材质、可操作范围、是否自动播放                 |
| 触发     | 鼠标移入、按下、移出、键盘进入/激活、触屏操作或真实业务状态    |
| 响应     | 哪个对象变化，位移、材质、图形、展开内容及过渡参数             |
| 结束     | 松开、移出、关闭、取消、暂停、切换页签或离开页面后的复位与焦点 |
| 特殊状态 | 选中、禁用、错误、加载，按实际用途选择；静态内容不补虚假状态   |
| 适配     | 窄屏、粗指针、减少动态效果、长内容及焦点可见性                 |
| 结果     | 真实跳转、值变化、提交反馈或其他可观察结果                     |

为参考特征逐项声明“采用”“项目适配”或“不在本次范围”，并给出既有授权或规范依据。缺失的规格不等于交互可以省略；先补全采集，再按职责修订规范。不要把漏实现的行为事后改写成有意差异，也不因参考新增功能扩大业务范围。

## 实现中：先复用，再检查完整状态

先查本地基础组件和已安装依赖。涉及 Libraries.dev 的效果，读取 `libraries-dev` skill、具体库参考和安装版本类型，使用公开参数控制效果、主题、尺寸与生命周期；不重新实现库已有的渲染效果，不覆盖内部实例标识或 keyframes。普通按钮、焦点、禁用、展开语义由本地 Base UI 组件承担，不为了使用效果而引入无关装饰。

交互实现应覆盖完整过程，不能只实现进入状态。检查稳定命中区、叠层遮挡、伪元素事件、真实链接或按钮、焦点恢复，以及样式层和选择器优先级。Base UI 的禁用可能通过 `aria-disabled` / `data-disabled` 表示，不能只依赖原生 `:disabled` 或 `:enabled`。

自动或持续效果有真实启停条件；按规范处理减少动态效果、离开可见舞台、隐藏页面与卸载，清理 observer、listener 和计时器。共享状态改动要列出消费者，页面不重复实现共享状态。

## 交付前：按清单实际回归

以本次范围生成逐项记录，不以“页面打开了”作为全部通过：

| 项目                      | 目标/有意差异      | 已实现 | 运行结果                | 证据或未验证原因                       |
| ------------------------- | ------------------ | ------ | ----------------------- | -------------------------------------- |
| 页面或组件的具体状态/流程 | 对应场景条目或来源 | 是/否  | 通过/失败/未验证/不适用 | 路由、操作、可观察结果、截图或源码位置 |

先运行核心流程和适用状态：移入→按压/激活→移出复位、键盘 Tab/Enter/Space/方向键/Escape、展开关闭与回焦、选择和禁用无操作。特别检查跨断点、切换页签及停止后重新操作；在桌面和窄屏核对布局与真实命中区。粗指针或减少动态效果无法运行时，保留源码核对和未验证标记。

共享组件的回归选择本次受影响消费者和可操作的展示页示例。使用已有数据或隔离数据；不为截图向常用数据库写入演示记录。修改后先重测失败项及关联流程，再执行适合该变化的类型、lint、格式与构建检查；不为了覆盖率新增镜像实现的测试。

验收发现问题时修复实现和规格，重测后记录。运行结果与源码检查分别记载；旧截图、他人的完成报告和历史验收不能证明当前版本。独立复查可以发现遗漏，主执行者仍须检查实际改动和运行结果。

最终交付列出做完的内容、实际通过的验证、仍未验证的边界。核心操作失败或仅有静态相似时，继续修复，不能宣称全面对齐。一次修复只更新当次验证记录，不覆盖历史事实。记录保存在 [验证历史](verification-history.md) 中。
