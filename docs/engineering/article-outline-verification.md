# 文章元信息与目录修正（2026-10-18）

## 来源与实现

用户在文章详情标注作者／日期未对齐，并指出缺少目录。参考为当前项目的飞书风格编辑器目录；主开发服务继续复用 `localhost:3000`，本次没有启动其他服务或写入数据库。

实际复现文章：`/posts/use-shell-script-to-implement-the-automatic-packaging-of-the-front-end-project-and-upload-it-to-the-cloud-server?returnTo=%2Fposts`。修改前，更新时间独有 `margin-top: 16px`，flex 居中后其文字框比作者与发布日期低 8px；前台正文标题没有 ID，也没有目录。

移除更新时间外距，详情元信息改为 20px 行高与基线对齐，修改时间使用 time 语义。新增前台目录：1024px 以上左侧常显，1023px 以下为 sticky 44px 入口和 Base UI Dialog。正文最大宽度仍为 896px；目录与正文之间为 32px。文章长标题使用均衡换行，避免新增侧栏后末行仅剩一个汉字。

前后台共用 `lib/posts/outline.ts` 的标题提取方法。前台从已校验的同一节点树生成目录及静态标题 ID，同名和空标题可独立定位；ID 不进入持久化文档。目录只向客户端传递标题条目，阅读页不加载编辑器 NodeView。
