# 前台重构独立预览与验证

本轮按已确认方案交付交互 HTML，供前台改版评审使用。正式页面、路由、数据库、API、SEO、共享 token 和现行设计规范均未调整。

## 交付与重建

- 交付文件：`public/previews/frontend.html`，约 2.2 MB，开发服务地址为 [前台预览](http://localhost:3000/previews/frontend.html)。默认首页、默认深色。
- 源码为 `previews/frontend-preview.tsx`、`frontend-sections.tsx` 及同名 CSS；`frontend-data.ts` 提供明确标记的本地示例。
- 直接复用当前 Base UI 本地 Button、Dialog、InputGroup、CardLink、MotionProvider 与 Lucide，没有新增依赖或修改 lockfile。
- 内嵌运行时、样式、Source Sans Pro、Inter、头像、两张生成图片、光标、favicon 和许可证。CSP 禁止连接网络、加载外部资源及提交表单；外部网站由用户主动点击普通链接打开。
- 主题使用独立的 `fuxiaochen-frontend-preview-theme`，不读写正式站点偏好；存储不可用时仍可切换当前页面。

```bash
# 从当前共享样式和本地资产重建 HTML，不读取业务配置或连接数据库。
node scripts/build-frontend-preview.mjs
```

图片与最终 prompt 见 [生成记录](../../previews/assets/image-prompts.md)。图片来自内置 image_gen，属于预览视觉资产，不代表作者真实桌面的摄影记录。

## 与正式站点的差异

- 导航只保留首页、文章、日志、友链、关于，另提供文章详情；分类与标签进入文章组合筛选。正式 `/categories`、`/tags` 和 sitemap 保持现状，重定向留待正式实施。
- 首页改为作者介绍与写作主题图，下方增加三篇近期示例文章。这是提案，不代表已增加生产查询。
- 搜索匹配示例标题、摘要、正文段落、分类和标签；每类单选，分类与标签数量显示示例总量。条件变化移除页码，分页保留条件。详情地址携带返回列表条件，刷新详情后仍能返回原筛选与页码；未刷新的往返同时恢复离开列表时的滚动位置。
- 文章、日志、友链为内存示例；关于沿用公开姓名、身份、头像及简介。当前公开社交资料为空，按既有规则省略联系区域。
- 继承 Semi default + modern 深浅色、Source Sans Pro 页面字体、Inter 控件、圆角和尺寸。仅在预览作用域将深色实心主 CTA 与“最新”徽标的文字组合改用现有背景色，解决浅字在亮蓝底上的对比不足；不改共享颜色值或正式组件。
- 页面切换仅内容整体入场；筛选、分页、主题切换不重播。减少动态效果时取消非必要运动，不增加循环或滚动劫持。

页脚“预览说明”提供文章空集合、加载中、加载失败样例，均可操作恢复正常列表。

## 未验证与不适用

- 内置浏览器仅允许 HTTP/HTTPS，直接打开 `file://` 被协议策略拒绝，未绕过。已核对资源完全内嵌和无业务服务依赖，但不把 HTTP 运行和源码检查写成离线文件运行通过。
- 系统 `prefers-reduced-motion`、真实触屏与粗指针、复制权限拒绝、localStorage 禁用、屏幕阅读器及其他浏览器仅源码核对或未运行；窄视口不等于真实手机设备验收。
- 未运行 Lighthouse 或生产构建，不将独立预览采样视为生产 Core Web Vitals 结论。
- 关于社交区域因公开资料为空未运行，没有编造联系账号。生产查询、分类标签重定向和 SEO 迁移不在本轮范围。
