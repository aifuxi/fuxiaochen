# 前台改版实施与验证（2026-10-17）

用户批准[前台独立 HTML 预览](../../public/previews/frontend.html)后，本轮将其阅读导向布局应用到正式前台。当前记录区分已实现、自动检查通过、仅源码核对与未验证；预览的历史截图和交互结果不作为正式页面通过的证据。目标规则见[共享规范](../../DESIGN.md)、[前台场景](../design/frontend.md)和[产品行为](../product/behavior.md)。

## 实现范围与预览适配

- 已实现：首页改为作者资料、真实介绍摘要与写作图的双列 Hero，下方读取最近三篇已发布文章，保持发布时间排序，独立于文章归档的每页条数。标题优先副标题、为空回退站名；简介取真实个人介绍首段，压缩空白后最多保留 72 个 Unicode 字符，超出追加省略号。关于页保留完整介绍，未将截取结果回写设置。
- 已实现：文章页统一承载搜索、直接分类与可展开标签，显示完整公开集合的真实计数；已选条件可逐项移除或全部清除。搜索、分类和标签组合保存于 URL，条件变化回到第一页，保留真实加载、无匹配、参数错误和查询失败反馈。
- 已实现：详情保留真实 Tiptap 正文、摘要、分类标签与时间，增加底部继续浏览入口。`returnTo` 只接受站内 `/posts` 和校验后的 `q`、`categoryId`、`tagId`、`page`，非法返回地址回退 `/posts`；返回上下文不进入 canonical、OG URL 或 JSON-LD。列表位置只在离开文章链接时记录，返回时尝试恢复，不注册连续 scroll 监听；存储不可用仍保留普通导航。
- 已实现：关于页横向身份区、真实简介按空行分段、真实社交入口；友链保留公开条件、真实分类 URL、结果数量、图片失败回退及唯一外链；日志保留真实版本、类型颜色、“最新”条件和分页，采用开放时间线。普通栏目 760px、详情 896px，手机按场景单列。
- 已实现：导航收敛为首页、文章、日志、友链、关于；删除独立分类／标签页面，并从 sitemap 移除。`/categories`、`/tags` 通过 HTTP 308 永久跳转 `/posts`，透传原查询参数，目标页继续执行参数规范化与索引规则。分类标签管理、关系和数据保留。
- 已实现：继续使用 Semi default + modern、Source Sans Pro 页面字体、Inter 控件、FC 字标、Lucide、共享指针及 Base UI 本地组件。首页 CTA 改用普通桌面 40px／触屏 44px；前台深色首页 CTA 与“最新”徽标使用现有 background 作为文字色，精选采用 primary-light 与 focus-text，灰色日志徽标文字采用 foreground-reading，不改共享色值或后台皮肤。
- 预览适配：仅将预览生成的首页写作图作为正式静态资产，通过 Next Image 导入并优先加载；它是站点视觉，不是作者真实桌面的摄影记录。文章示例插图、虚构文章和日志、hash 路由、独立主题偏好、诊断入口及预览说明均不进入正式页面。正式主题继续使用全站偏好，页脚保留真实作者、备案与后台入口。

以上实现关系已源码核对；实际视觉、触发反馈、结束与复位需由下方浏览器记录分别证明。

### 发现、修复与重测

- 新增 HTTP 返回链接断言初版误用正则，将 URL 的 `?`、`+` 当作表达式符号导致检查误报；改为字面匹配后整条隔离集成重跑通过，页面行为未因此调整。
- ArticleFilters 的复合 children 经 Base UI render 传入 Next Link 时出现 React key 警告。为子元素提供稳定 key 后，重新加载、组合筛选与逐项清除不再产生该警告。
- 开发严格模式重放 layout effect，先消费恢复标记再取消动画帧，会丢失列表位置和焦点恢复。改为真正执行恢复后消费标记，并只查找当前列表范围；刷新详情后从顶部、底部返回均实测恢复第二页、1432.5px 原滚动位置及对应文章焦点。
- 浅色日志灰色“修复”徽标初始文字对比为 4.44:1，改用现有 foreground-reading 后重采通过；最终日志正常文字最低 4.68:1。

## 当前边界

- 仅源码核对：最大资料边界、请求期间防重复与禁用、减少动态效果、粗指针、存储不可用降级、非空社交区域、超宽表格和图片失败回退。CSS 只限前台场景，未修改共享 token 或后台皮肤。
- 未验证：真实触屏、系统 reduced-motion、屏幕阅读器、跨浏览器、200% 文本缩放、查询故障重试、复制失败、外站真实可用性及生产环境。
- 不适用：本轮没有数据库 schema 或数据迁移，没有引入预览示例内容及新依赖；没有推送、部署、生产切换或第三方统计真实收数验证。正式页面是联网应用，离线自包含承诺仍只适用于此前交付的 HTML 预览。
