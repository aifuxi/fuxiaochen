# 前台文章正文对齐验证（2026-10-18）

## 依据与实施范围

用户批准将当前飞书风格编辑器的全部正文样式同步到前台，保留前台导航、文章标题信息区和 896px 阅读列。参考为本仓库当前编辑器；此前飞书采集保留在[编辑器验收记录](feishu-editor-verification.md)，本次不将历史截图作为当前运行证据。

正文的字号、行高、标题与列表间距、行内代码、代码块、表格和图片圆角归入 `app/article-prose.css`。移除前后台重复覆盖；编辑器继续独立维护表格操作条留白、选区、拖动和缩放。没有修改 API、正文 schema、依赖或数据库结构，也没有批量转换历史文章。

| 特征                                               | 处理与依据                                                     |
| -------------------------------------------------- | -------------------------------------------------------------- |
| 16px／26px 正文、H1–H6、8px 段落及 4px 条目间距    | 采用当前编辑器基线，改用等值 rem 和无单位行高                  |
| 代码 input 底、outline 边线、8px 圆角、16px 内边距 | 前后台共用，前台语言名称只读，复制和语法高亮保留               |
| 表格折叠边线、8px 单元格内边距、fill-0 表头        | 前后台共用，前台保留占满阅读列的最小宽度与键盘滚动入口         |
| 图片 4px 圆角、尺寸、裁剪、图注和对齐              | 内容属性保留；独立图片使用普通段落间距，文字内图片保持行内语义 |
| 编辑器空白处理、NodeView、表格选择条及语言选择器   | 编辑场景适配；前台不加载编辑器运行逻辑，任务 checkbox 保持只读 |
| 导航、文章主标题、摘要、元信息、阅读宽度           | 不在正文同步范围，保持现有前台布局                             |
