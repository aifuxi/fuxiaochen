# 定时发布移除验证

日期：2026-10-14。仅验证当前代码与独立测试环境，未修改已有开发库、生产库、服务器调度或部署。

## 已实现

- 文章仅保留草稿和已发布状态；工作台为两项指标，宽屏两列、≤900px 单列，其后为最近草稿和常用操作。
- 删除编辑器排期字段、列表发布计划和取消排期操作、工作台计划、手动执行 API 与 `posts:publish-due` 命令，清理专属样式、计时器、通知逻辑、辅助说明和页面 metadata。
- 文章请求、响应与汇总不再包含排期字段。旧状态页面链接清除无效状态与页码，保留关键词等其他筛选；API 拒绝旧排期状态。
- `operations:run` 仅记录备份调度时间并按开关执行每日自动备份，保留 `schedulerLastRunAt`、手动备份和独立文件恢复。
- 新迁移 `0004_remove_post_scheduling.sql` 将全部排期文章转为草稿，保留正文、关联和其他元数据，清理排期通知及已读关联，删除时间列和索引。已提交的旧迁移与 PostgreSQL 源 contract 保持原状。
- PostgreSQL 归档保留源排期数据；目标映射转换草稿并过滤退役字段与通知，逐字段报告区分 source、planned、target。
