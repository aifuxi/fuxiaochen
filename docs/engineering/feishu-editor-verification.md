本轮按已批准方案重构文章新建与编辑页，保留本站字体、Semi 深浅主题、Base UI、手动保存及现有文章 API。正文封装仍为 `fuxiaochen-tiptap` / `version: 1`，没有数据库结构迁移或历史文章批量转换。

- 已采集顶部操作、820px 文档画布、标题、目录、选区工具、类型／颜色菜单、块手柄与表格入口。实际输入 `/` 后查看建议菜单，搜索、插入高亮块并撤销；高亮块观察到书籍标识、16px 内边距、8px 圆角。
- 图片补采经过选择文件、上传、选中、四角等比拖动和撤销：AVIF 被参考站明确拒绝；改用项目公开的 `og-default.png` 后上传成功，从 820px 宽调整到 558px 宽，比例保持。此结果只证明飞书参考操作，不证明本站 OSS 上传成功。
- 表格补采经过单元格进入、行选择、浮动工具、合并整行和撤销；原表格最终恢复为 **2 行、6 个单元格**。
- 临时高亮块、图片和表格修改均已撤销。图片数量回到 0，测试插入位置前缀与操作前相同，用户已有的段落及提及保留。撤销正文引用不代表删除飞书已上传的底层文件。
- 图片上传与缩放的完整补采在实现过程中完成，早期采集仅覆盖入口和选中态；没有把早期静态观察当作完整交互通过。

## 实现与兼容

新增 `TextStyle/Color`、`Highlight`、`TextAlign` 扩展，精确锁定为 3.31.4；颜色、callout、对齐及图片尺寸由编辑器、服务端 schema 和前台静态渲染共用定义。合法 mark 最多 8 个且不得重复；任意 CSS、非法属性、未知节点、非法表格及超限内容被拒绝。

旧文章无需迁移。目录 ID、当前目录项和菜单状态不持久化；初始正文不合法时显示错误并阻止保存，不以空正文覆盖。保存、主题切换和设置开关不重新创建 Editor。

回归中修复并复测了以下问题：快速斜杠输入后立即 Enter 的 React 提交时序、对齐误触及上一标题闭合边界、表格选区变化后命令禁用状态陈旧、图片数字尺寸与撤销未同步到官方 NodeView，以及目录锚点被离开保护错误拦截。真实窄屏还发现目录抽屉关闭时滚动锁恢复旧位置，现等待 Base UI 解除锁后再定位，实测目标章节 top 为 144px。Dialog 关闭通过 Base UI `finalFocus` 回到正文。

## 剩余验证边界

- 真实 380×844 和桌面已运行；1100px 断点附近的连续拖动、手机横屏及真实触屏硬件尚未验证。

- 真实 OSS 成功上传、上传中取消与真实网络失败恢复尚未验证。隔离浏览器只验证缺配置失败及重试，自动媒体测试使用模拟网络；飞书的 PNG 上传属于参考采集。
- 没有测试多人、AI、评论、历史、公式、分栏、折叠、视频或附件，这些功能没有进入本轮实现。

本轮实现、桌面核心流程与真实窄屏有上述运行证据；在完成剩余边界前，不宣称触屏硬件、真实输入法及真实 OSS 全面验收通过。

## 交互重叠修正（同日后续）

用户截图指出空段落出现多个插入／块操作入口、正文底部还有常驻“＋／更多”。前一轮验收遗漏了这些入口的组合状态；不能将“功能可用”当成“交互已对齐”。本节覆盖上文中旧的块入口布局结论，保留其他已运行的历史证据。

重新操作参考后确认：空行只有单个“＋”，非空块为类型图标＋拖拽手柄，正文底部没有常驻工具组。点击插入时为“基础”类型网格＋“常用”内容条目，块菜单为类型网格、对齐／颜色子菜单及分组操作。实际输入 `/` 后则为分组文字列表，不能把插入网格直接套到斜杠菜单。临时 `/` 已撤销，原空段落和 `1111` 均保留。

本轮删除可见占位文案、块侧多余插入／省略号和末尾工具组；字数独立放在右下角。点击类型或手柄选择整块并打开菜单；右键定位指针所在块，Shift+F10 定位光标所在块，触屏长按由 Base UI ContextMenu 提供。上下方添加选择实际块类型，媒体弹窗取消不制造空段落。H4–H6、创建副本及上下移动仍是已批准的项目能力；协作、AI、翻译等继续不在范围。

复用 `localhost:3000`，本轮只使用未保存的新建页临时内容，没有向常用数据库新增文章。实际通过空行入口、插入 H2、分级目录、斜杠 Enter、Escape、整块选择、对齐、颜色、右键目标、Shift+F10、副本撤销、原生拖拽及撤销／重做、图片添加取消。共享 RowActions 的展开／关闭回焦也已回归。发现并修复了旧位置越界和窄屏菜单溢出，并重测关联流程。

最终桌面参考和本地均实测为 **1222×953**；窄屏实测为 **390×844**，页面滚动宽度为 390px，最终菜单右边界为 374px，触点为至少 44px，深浅主题均已截图。空行展开菜单时选中整行，取消恢复输入点，选择 H2 后正常继续输入；取消表格选择没有改变正文。完整同屏与局部比较、截图绝对路径及适配差异见 [本轮设计 QA](../../design-qa.md)。本轮没有真实触屏硬件、中文输入法组合过程和真实 OSS 验证，原有边界仍然成立。

重新运行类型、lint、构建及编辑器 8、主题 5、导航 1、SQLite 31、SEO 9、媒体 4 项测试，全部通过。改动文件格式通过；全仓格式检查仍只报告未修改的 `design-spec.html`。原引用边线的已有设计例外保持不变，本轮未增加忽略项。
