本文件规定前台页面、登录页和 `/design-spec` 的视觉布局与组件组合。共享颜色、字体、圆角、材质、基础控件及通用交互状态以 [DESIGN.md](../../DESIGN.md) 为准；数据来源、筛选、分页、发布、评论、权限及错误处理等业务约定见 [产品行为](../product/behavior.md)。页面只定义组合和场景差异，不重复基础组件的状态样式。

2026-10-06 已实施全站 Inter 加中文系统字体、普通导航与当前项局部胶囊、原生指针、首页居中文案与五个栏目微卡入口、组件展示页新网格。实际验收范围由根设计规范的同步记录和[视觉实施记录](../engineering/verification-history.md#视觉基线实施2026-10-06)追踪；其他场景规则继续有效，不将其迁移或字体接入视为全部业务场景已重新验收。

## 前台共同布局

前台沿用共享暗色主题。外框最大宽度 1200px，桌面内容区最大 1136px；导航、首页和页脚内容边线对齐。文章列表、分类和标签共用最大 760px 的居中栏目列，友链双列使用最大 880px，文章正文、关于和日志使用最大 720px 的阅读列。

导航、主内容与页脚共用场景变量 `--site-gutter`：600px 及以下两侧至少 20px，600–900px 之间连续增加，900px 及以上至少 32px，对应 `clamp(20px, calc(4vw - 4px), 32px)`。横向边距不随控件、导航或首页构图断点跳变。前台根滚动容器使用 `scrollbar-gutter: stable`，为经典滚动条预留空间，避免长短页面切换时内容位移；覆盖式滚动条与不支持该属性的浏览器沿用原生行为。该规则仅在前台壳存在时生效。

长站名、标题、链接及资料自然换行，页面高度随内容增长；只有代码、表格及确有需要的局部区域横向滚动。

2026-10-07 已统一上述栏目宽度、连续边距与前台滚动条预留；96项布局检查、弹窗与导航回归的实际范围见[前台布局宽度统一记录](../engineering/verification-history.md#前台布局宽度统一2026-10-07)。友链当前为空态，有数据的双列卡片与跨浏览器场景未在本轮运行验证。

前台、登录和组件展示页共用 Inter 优先、中文使用系统字体的无衬线栈。数字、版本、参数和代码继续使用等宽字体。字体栈及全站字号角色统一维护在 [DESIGN.md](../../DESIGN.md)，本文件仅定义场景尺寸。

全站使用原生指针。链接、按钮与可编辑文本保持浏览器的语义和原生指针反馈，不挂载替换系统指针的装饰层；键盘焦点由共享组件提供。

页面和容器默认使用共享灰阶基底；栏目识别、分类和重点信息可通过共享颜色作用于文字、图标、边线或局部底色。静态徽标可按信息重要性使用品牌强调，采用明确、稳定的映射，保留文字并核对实际对比度；控件状态与焦点继续遵循共享规范。2026-10-07 先扩展用色许可，随后按逐页审计实施下文明确的局部映射；规范扩展的历史范围见[用色规范优化记录](../engineering/verification-history.md#用色规范优化2026-10-07)。实现不能代替运行验收，新增场景的实际证据另行记录。

文章、分类、标签、友链、关于和日志的栏目标题统一使用共享 heading；首页使用 display，文章详情保留阅读标题变体。分类链接、标签胶囊、友链卡片与普通导航链接的按下底色在 sRGB 中由 surface 50% 与 background 50% 混合，压暗悬停表面；已选导航和友链分类使用已有 raised / input-hover / input 状态组合。页脚和关于联系入口按下时回到 background，文字和独立焦点仍按共享规则反馈。

文章不存在和前台加载失败使用最大 720px 的紧凑阅读列与共享 heading，保留真实返回或重试操作。加载失败的重试重新获取页面内容，不向读者展示内部异常。

## 首页

### 内容与桌面构图

首页继续使用现有公开设置提供的站点名称、副标题与作者资料；名称为唯一 `h1`。页面保持“阅读文章”入口与作者身份，不新增文章列表、计数、筛选数据或额外请求。五个微卡只链接既有栏目。

桌面以居中文案为视觉中心，五个微卡环绕其外侧，给标题、副标题、阅读 CTA 和作者资料保留完整阅读区域。文字直接位于页面底色上，不套介绍卡片或装饰面板。标题使用共享 `display` 角色：640px 及以上为 42px / 45px、500 字重、`-0.005em` 字距；小于 640px 为 30px / 34px，字重和字距保持一致。标题不使用渐变填字。

副标题为 16px muted 文字，距标题 16px；“阅读文章”距副标题 24px，使用 primary Button 链接至 `/posts`，作为唯一 primary 操作。桌面 CTA 使用 32px 胶囊；600px 及以下或粗指针至少高 44px。作者资料距入口 48px，以 56px 头像、14px 姓名和 13px muted 身份说明辅助识别，居中组合；完整个人介绍由关于页承载。空副标题或身份说明按既有业务规则省略。

### 五个微卡入口

| 桌面位置 | 可见名称 | 路由          | 图形含义     |
| -------- | -------- | ------------- | ------------ |
| 上方中央 | 分类     | `/categories` | 分类或文件夹 |
| 左侧     | 文章     | `/posts`      | 书籍或文档   |
| 右侧     | 标签     | `/tags`       | 标签或井号   |
| 左下     | 日志     | `/changelog`  | 历史记录     |
| 右下     | 关于     | `/about`      | 作者或人物   |

每个入口是一个真实链接，复用现有 Lucide 图标库，包含常显文字名称；名称提供可访问名称，装饰图标从辅助技术中隐藏。整块链接提供点击区域，内部不嵌套其他操作。不能仅靠悬停出现的 tooltip 告知去向。

图形单元采用约 130×130px 的 Hero variant，使用 surface 外壳、24px 外圆角、14px 内舞台圆角与 11px 舞台 inset。文字位于图形单元下方，保持可读且不遮住图标。此处 11px 只作用于 Hero 微卡，不覆盖普通 Card 的 12px 舞台间距。各图形共用 surface 材质；文章、分类和标签的阅读／探索图标固定使用 focus，日志和关于图标默认 muted。颜色只作用于图标，名称和表面保持灰阶；通过常显文字明确入口，不将识别色误作业务状态。既有触发反馈保持，不增加持续装饰动画。

精细指针 hover 与键盘 focus-visible 时，内部卡片按共享 expressive 时长和 lift-ease 曲线上浮至 6px，图标上移 2px，并按栏目轻微旋转或缩放；名称下方展开 raised 底色的胶囊及方向箭头，名称与箭头使用 foreground。阅读／探索图标保留 focus，日志和关于图标提亮为 foreground。名称始终可见，链接命中框固定，周围布局不移动。active 使用 micro 时长将卡片压回 1px、图标复位；键盘焦点环跟随内部卡片。胶囊自身提供完整点击区域，门户层级不被中央文案的透明区域遮挡。

触屏不依赖 hover 获得名称或进入栏目，点击反馈和焦点状态沿用上述规则。`prefers-reduced-motion` 下卡片、图标和名称的位移、缩放与旋转均为零，隐藏方向箭头；保留即时的材质、文字与焦点反馈。

### 窄屏构图

760px 及以下将五微卡排在文案上方，采用两张、一张、两张的 2–1–2 队列，随后呈现标题、副标题、阅读 CTA 与作者资料。入口按可读顺序组织，DOM 焦点顺序与窄屏视觉顺序一致，不使用正数 `tabindex` 改变顺序。

两侧沿用前台共同布局的连续边距，卡片间距与尺寸在可用宽度内适配，名称自然换行。整段 Hero 自然增高；不以固定高度裁切五微卡、长站名或资料，也不让微卡与文案交叠。760/761px 核对构图切换，639/640px 核对标题尺寸切换。

## 顶部导航

顶部导航采用普通文字链接，仅当前栏目使用局部 raised 胶囊和 foreground 文字；普通项使用 muted 文字。导航整体无胶囊外框、描边或常驻填充，当前项不添加蓝色短线。桌面导航独立居中，品牌与右侧操作不参与导航中心计算，宽度随栏目内容增长。

桌面与移动端栏目保持：首页、文章、分类、标签、日志、友链、关于。链接桌面高 36px、水平内边距 16px，字号 14px / 20px、500 字重，栏目间距 8px。粗指针点击目标至少高 44px，空间不足时折叠为本地 Base UI 菜单，不压缩字号或造成页面横向溢出。

导航使用语义化 `nav` 和真实链接；首页精确匹配根路径，文章详情高亮文章栏目，当前链接提供恰当的 `aria-current`。布局与文字位置不随状态变化。状态反馈沿用共享规范，折叠菜单保留完整栏目文字及既有关闭与焦点行为。

## 文章列表、筛选与分页

`/posts` 沿用共同布局的最大 760px 居中栏目列，与分类、标签页首对齐。页首以 `h1`“文章”与真实结果数量同排，不展示默认“全部文章”栏。列表文章标题为 `h2`。

页首下方 32px 为搜索框与筛选按钮，使用 compact 尺寸，桌面高 36px、600px 及以下或粗指针高 44px，同排对齐；搜索复用 InputGroup，包含有可访问名称的提交操作，附加图标操作沿用共享尺寸。分类与标签在本地 Base UI Dialog 内组合，最大宽度 440px，手机两侧至少 20px，内容独立滚动，字段有可见标签；字段、取消和应用采用共享 form 尺寸。已应用数量、当前筛选说明及清除入口按业务条件显示，条件说明距搜索栏 12px 并允许换行。提交反馈和关闭后的焦点恢复沿用既有行为，详见 [产品行为](../product/behavior.md)。

筛选区与列表间距 32px，文章间距 28px。各宽度保持单列，标题、摘要和元信息左对齐，直接排在页面底色上，无行分割线、外框、卡片底色或装饰阴影。日期不单独占列。

文章标题桌面 24px、600px 及以下 22px，500 字重、行高 1.5，长标题自然换行。摘要为 15px、行高 1.75、muted 文字，距标题 8px，各宽度最多两行。标题与摘要共用文章链接，并由标题关联可访问名称；摘要来源及截取规则在产品行为中维护。

摘要下方 8px 显示日期、精选、分类和标签，元信息间距 16px、允许换行，文字 13px。日期使用 subtle；分类和标签文字使用 muted。分类名称前使用已有用户分类色的 8px 圆点，带 1px subtle 边线，距名称 8px；分类索引、文章列表与详情共用该标识，异常颜色回退 muted，不覆盖主题、文字或焦点色。圆点为装饰，完整名称继续承担识别。精选与日期保持同组，采用 primary 实心底色、foreground 文字，12px / 18px、500 字重、上下 2px／左右 8px 内边距和 pill 圆角，无按钮阴影或独立交互。日期自身不设交互目标高度；分类与标签链接各自可操作，点击目标至少高 44px。交互只反馈标题或当前元信息，不让整行上浮。

文章与日志共用居中的紧凑分页组，gap 16px。上一页、下一页复用 secondary Button，带 16px 方向箭头，高 44px、水平内边距 16px；可用项保持链接语义，不可用项使用真实 disabled 按钮。中间以 13px muted 文字和共享 `--font-mono` 等宽字体显示“1 / 3”，辅助技术读取“第 1 页，共 3 页”。文章分页距列表 48px，日志为 32px；分页不增加外框、容器背景或装饰动画。隐藏条件、查询条件保留和页码处理见产品行为。

空库、无匹配、加载和查询失败保留明确文字与相关操作；状态不改变列表的阅读宽度，不加入填满页面的演示记录。

## 文章正文、代码与表格

正文页最大宽度 720px。文章标题自然换行，正文 16px、行高 1.8，主内容使用 foreground；发布时间与修改时间分别呈现，修改时间采用辅助元信息。正文头部分类与标签的真实链接目标至少 44×44px，分类色点沿用列表映射，日期不随之扩大。正文链接、标题、列表、任务列表、引用、图片及分隔线继续使用既有阅读层级。图片不超出阅读列，代码和表格只在自身容器中横向滚动。

前台代码块使用 surface 底色、14px 圆角和 20px 代码内边距，代码使用等宽字体。顶部工具栏常驻：左侧语言名称、右侧“复制代码”，工具栏不随代码横向滚动，使用 muted 文字与 outline 底边线。工具栏控件桌面高 32px，600px 及以下或粗指针至少 44px。复制状态以文字表达，未知语言和纯文本显示、复制原文及反馈时长见产品行为。

语法高亮引用共享 syntax token，关键字、字符串、数字、函数与注释各自对应根规范中的角色；其他代码使用 foreground。颜色只用于代码区，不改变正文内容或复制文本。

正文表格由滚动容器提供 1px outline 外框和 14px 圆角裁切。表格单元格保留折叠边线，表格自身外边线隐藏，避免与容器外框叠加；表头底色和内容随圆角裁切。单元格上下 12px、左右 16px 内边距；直接段落不继承正文的首尾 20px 外距，连续段落之间保留 8px，避免单行内容产生过高行距。长表格不撑宽页面。容器可聚焦时使用共享焦点提示。

## 公开评论

评论保持平铺列表，回复明确标明对象昵称，不做多层缩进。管理员昵称前展示 32px 圆形公开博主头像，缺失或加载失败显示人物图标；普通评论保持既有昵称展示。身份仍只由服务端管理员标记决定，保留“博主”文字：focus 文字与 sRGB 中 focus 12% / surface 88% 淡底，12px / 18px、500 字重、上下 2px／左右 8px 内边距和 pill 圆角，不附加按钮状态。评论正文保留换行，长昵称与内容自然换行。评论次序、审核可见性和每页数量见产品行为。

评论表单使用可见标签和现有本地控件，昵称、邮箱与提交操作采用共享 form 尺寸；Textarea 保留既有高度与纵向调整能力，内边距沿用共享规范。昵称、邮箱与正文的布局适应窄屏，操作与状态文字可换行。审核、纯文本及长度限制等必要说明使用 muted。字段错误就近显示并关联控件，通用错误位于表单顶部，成功反馈保留文字。失败草稿、提交状态及关闭评论后的呈现遵循产品行为与共享状态规范。

## 更新日志

`/changelog` 使用最大 720px 的居中阅读区与语义化时间线，内容直接位于连续页面底色上。页首 `h1` 使用共享 heading：30px、500 字重、行高 1.16、`-0.01em` 字距；说明使用共享 body：14px、行高 1.6、muted 文字。页首与时间线间距 32px。日志布局与排版使用页面作用域，不改变其他前台页标题、文章元信息或后台时间线。

每条顶部以版本号为主要锚点，采用 foreground、18px、500 字重、行高 1.5 和共享等宽字体。日期使用 subtle、12px 和共享等宽字体，桌面靠右，600px 及以下独立一行。

类型胶囊采用共享日志分类色：`feature` 新功能使用 focus 蓝色、`fix` 修复使用 muted 灰色、`performance` 性能使用 success 绿色、`security` 安全使用 danger 红色；未知类型回退 muted，并保留实际类型文字。各胶囊底色均在 sRGB 中由对应文字色 12% 与 surface 88% 混合。“最新”使用 primary 实心底色与 foreground 文字，与版本和类型同组排列；仍仅第一页第一条显示，历史页不显示。类型与“最新”胶囊统一采用 12px、500 字重、18px 行高、上下 2px／左右 8px 内边距和 pill 圆角。空间不足时可整枚换行，胶囊内部不拆字；两者均为静态标记，不使用按钮阴影、虚假交互状态或动画。

主题独立成行，距版本行 12px，采用 foreground、20px、500 字重和行高 1.5。逐条清单距主题 12px，采用 muted、14px 和行高 1.8，相邻清单条目间距 8px。版本、主题与清单完整呈现并自然换行，不裁切长文案，也不产生页面级横向溢出。

时间线使用 9px 的 subtle 灰阶节点和 1px outline 连线；连线只连接相邻版本，末项后不继续延伸，末项无多余底部内边距。条目间距 32px，桌面时间线左缩进 24px、清单缩进 20px；600px 及以下分别为 12px 与 16px。节点与内容保持静态，不添加虚假交互状态或装饰动画。分页沿用前台分页组，数字使用共享等宽字体。

无效页码沿用正常阅读区与页首标题，显示“页码无效，请返回更新日志。”，提供本地 Button 与真实链接构成的“返回更新日志”入口，指向不带查询参数的 `/changelog`，目标至少高 44px。

## 站点资料与页脚

关于页简介使用正文 foreground；联系入口采用纵向图文列表，图标 20px、图文间距 10px、链接 14px，真实点击高度至少 44px，长文案自然换行。Lucide 联系图标使用 focus，图片图标保留原图颜色；名称使用 muted，交互与独立焦点遵循共享规则。没有启用联系账号时省略整个区域。

前后台友链统一采用 Link2 作为空图标或图片加载失败的占位；此 variant 仅由友链显式选择，不改变社交图片的通用 Globe 回退或个人头像的 UserRound 回退。公开条件与外链属性遵循产品行为。

站点名称是返回首页的普通文本链接，为 24px、500 字重，不作为页面标题。副标题为 14px muted 文字，最大宽度 360px，空值时省略。分组标题为 13px、500 字重，链接 14px；站内入口保持文章、友链、关于，分别进入 `/posts`、`/friends-links`、`/about`。

## 登录页

登录页采用居中单列布局，表单最大宽度 360px，页面四周留白在桌面为纵向 48px、横向 24px，600px 及以下横向缩为 20px。内容随短屏或错误提示增长，可正常纵向滚动。表单直接置于共享 background 上，不套卡片；只保留站名返回首页入口、24px 的“后台登录”标题、用户名、密码和“登录”按钮，不显示装饰图形、编号、口号、欢迎文案或重复占位提示。

键盘焦点按返回首页、用户名、密码、登录按钮的顺序移动。用户名、密码采用 Input，提交使用 primary Button，两者统一采用共享 form 尺寸：桌面高 40px、600px 及以下或粗指针高 44px，圆角引用 form；输入文字为 14px / 20px，水平内边距 12px。字段保留可见标签，错误使用 danger 和文字；状态反馈及减少动态效果引用共享规范。认证与安全约束见 [AGENTS 鉴权约定](../../AGENTS.md#后台鉴权与登录范围)。

站名入口采用 muted，悬停提亮并保留独立焦点轮廓；窄屏或粗指针下实际高度至少 44px。页面不增加额外动效，输入与按钮沿用共享状态。

渐进增强表单在当前页显示字段或通用错误，失败保留输入。字段错误通过 `aria-invalid` / `aria-describedby` 关联输入并聚焦首个错误字段；凭据、请求、限流、服务与网络错误使用可聚焦文字提示。提交期间文字显示“登录中…”，禁止重复提交并暂时只读输入；成功执行完整导航进入后台。无 JavaScript 时保留原生表单契约，行为与边界见[登录行为](../product/behavior.md#登录)。

## 组件展示页

`/design-spec` 保留开发环境的组件演示用途，环境限制与入口守卫见 [部署指南](../deployment.md#镜像构建)。展示区直接采用居中介绍与下方组件网格；旧版左文右图、渐变大字与侧面装饰 Hero 不再作为强制布局。

展示区最大宽度 1008px，网格 gap 24px，桌面页面两侧至少 32px，窄屏至少 20px。宽屏大于 1100px 时，先呈现一行两个较大案例，后续案例采用三列；641–1100px 为两列，640px 及以下为单列。卡片内容决定高度，不固定高度裁切演示、标题或说明。章节之间保留约 72px 留白，章节入口清楚表达当前章节。

普通展示 Card 由外壳、内舞台、标题、说明和可选操作组成，舞台离外缘 12px。说明区位于舞台下方，保持稳定；首页微卡的 11px inset 不用于这里。复杂控件保持可操作，代码和 token 注释只承担辅助说明。

保留 Button、Card、Tabs、Accordion、Dialog、Switch、Select、Combobox 与 InputGroup 等基础演示，组合方式如下：

- Button 展示 primary、secondary、ghost 及既有默认尺寸；基础材质和状态引用根规范。
- 可点击 Card 使用整块链接或按钮；含独立操作的 Card 不再嵌套外层点击。
- Tabs 演示选中胶囊移动、面板切换和禁用状态，Accordion、Dialog 和 Switch 展示展开、关闭及切换；行为由本地组件承担。Switch 的通知预览是独立的本地开关，有开启/关闭文字反馈，不控制已卸载或屏外的效果舞台。
- Select 展示固定选项，Combobox 展示输入筛选；两者都有可见标签，并保留选中标记。
- InputGroup 展示图标、输入、附加文本或操作的组合，背景与输入焦点由外框统一承载，内部不重复焦点环；附加按钮保留独立焦点。
- 表单预览组合 Input、Textarea、Select、Combobox、Switch 与 Button，单行控件与提交操作采用共享 form 尺寸，并展示默认、错误和禁用状态。Textarea 保留既有高度与纵向调整能力，错误以文字和语义关联表达；预览提交仅反馈本地状态。
- 动效演示保留 `border-beam` 边框流光、`thinking-orbs` 光球与本地 CSS 悬停效果，不因布局迁移增加效果库。按 `libraries-dev` skill 复用 BorderBeam 的 `active` 和 ThinkingOrb 的 `paused`，不重写库效果或覆盖其内部动画。相邻演示一次只播放一个效果，重播保留所选效果；离开可见舞台、切换离开相关面板或隐藏页面时停止，返回后等待显式播放。暂停保留静态内容，流光按库原生生命周期淡出，光球保留静态帧；动画层不截获事件。减少动态效果时使用静态预览并禁用播放。原有指针预览可保留普通区域、按钮和输入框三个目标，用于核对原生指针与基础状态，不再演示替换系统指针。

组件演示使用同一本地基础组件，不用页面级样式重复实现基础状态。循环动画只存在于明确的效果舞台；减少动态效果下停止循环及位移，保留可理解的静态内容。生产前台不因组件演示而引入持续装饰动画。

视觉基础补充三类静态用色示例：精选／最新的 primary 强调，栏目图标、分类色点及 PV／UV 文字图例的稳定识别，成功／错误状态文字与独立输入焦点。示例不写入业务数据、不新增 token，分类色与状态色不替代焦点轮廓。效果舞台的外围状态点以 focus 表示实际播放、muted 表示暂停或减少动态效果下的静态预览，同时保留对应状态文字；不改库效果、库 API 或播放生命周期。
