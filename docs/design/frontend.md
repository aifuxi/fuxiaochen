# 前台、登录与组件展示页

本文件规定前台、登录页与 `/design-spec` 的布局和组件组合。共享颜色、字体、圆角、材质、控件与状态以 [DESIGN.md](../../DESIGN.md) 为准；公开条件、查询和排序见[产品行为](../product/behavior.md)。页面不另建共享 token。

## 当前依据与实施范围

2026-10-17 用户批准 [前台 HTML 预览](../../public/previews/frontend.html)，授权落实到正式前台并移除独立分类、标签页。当前前台以该预览为构图依据，沿用 Semi default + modern、FC 字标、Source Sans Pro 与中文系统兜底、Inter 控件、Lucide 和已有指针。旧 Libraries.dev 五微卡与 2–1–2 首页仅是历史方案，当前不再采用；旧采集见[验证历史](../engineering/verification-history.md)。

正式页面读取真实公开资料、文章、友链和日志，不移植预览的 hash 路由、示例内容、诊断入口、独立主题偏好或预览说明。两张预览生成图片中，仅首页写作图作为站点视觉使用；文章插图仍只属于预览，不写入任何真实正文。正式实施范围与运行证据见[前台改版验证](../engineering/frontend-rollout-verification.md)。

## 前台共同布局

默认深色，主题行为统一见根规范。外框最大 1200px、导航和页脚内容最大 1136px；首页最大 1008px，普通栏目最大 760px，文章详情最大 56rem（默认 896px）。普通栏目共享阅读边线，详情标题与正文边线对齐。页面主内容直接排在背景上，只有友链等独立信息链接使用 CardLink。

连续横边距使用 `--site-gutter: clamp(20px, calc(4vw - 4px), 32px)`；根滚动容器仅在前台壳存在时启用 `scrollbar-gutter: stable`。主内容桌面距导航后 60px、底部 88px，767px 及以下改为 36px／64px。长标题、名称和资料自然换行，不裁切或撑宽页面；代码和表格局部滚动。

普通栏目标题使用共享 heading（30px），说明 15px／1.7、caption。前台保留共同跳转正文入口。页面 Motion 仅在已提交的路径变化时让 main 整体入场，首次 SSR、刷新、查询、分页及 hash 不重播；导航和页脚静止，无列表错峰、自动循环或滚动劫持。减少动态效果及能力不可用时静态显示。

## 首页

桌面首页上方为双列：左侧作者身份、标题、简介和“阅读文章”，右侧为已批准的冷灰蓝写作图片。两列比例约 1:1.03，间距 72px；1023px 及以下间距 40px。首页内容顶部 46px，介绍不套卡片，照片使用共享 lg 圆角并保留 4:3 比例；通过 Next Image 静态导入、尺寸提示和 preload 预留空间并优先加载。

身份区使用现有作者姓名、角色及 48px 头像，间距 12px，距标题 30px。标题为唯一 h1，优先公开副标题、为空回退站名；使用共享 display（42px／45px，640px 以下 30px／34px），视觉最多两行，完整内容保留在标题属性中。简介取真实个人介绍首段并压缩空白，最多 72 个 Unicode 字符、超出追加省略号，视觉最多三行；为空省略，16px／1.75，桌面约 28ch；不加虚构身份、统计或履历。CTA 使用共享普通 40px、form 圆角，触屏 44px，图标与文字间距 18px。

767px 及以下严格按身份与介绍、图片、近期文章顺序单列，Hero 间距 32px，身份距标题 24px，简介不设窄列。保留连续边距，内容自然增高，不用固定视口高度裁切。

Hero 下方 76px 为最大 760px 的“近期文章”区域，手机为 44px；章节标题桌面 24px、手机 22px。展示最近三篇真实公开文章，标题 h3（21px，手机 20px），摘要 14px、最多两行，保留日期、精选和分类，不重复全部标签。空库显示明确文字。文章获取及排序规则由产品文档负责。

## 顶部导航

导航为“首页 / 文章 / 日志 / 友链 / 关于”，普通文字链接，仅当前栏目使用局部填充与 modern light 阴影。当前项默认 fill-0、hover fill-1、active fill-2；普通项默认透明、hover fill-0、active fill-1，焦点始终独立。整组不套外框或常驻底色。

FC 透明字标 32×32px，距站名 10px，由品牌链接名称表达返回首页。桌面导航独立居中，链接 compact 36px、水平内边距 16px、间距 8px；导航常规最小高度 80px、手机 72px，右侧保留 ThemeToggle。长品牌按内容换行；空间不足或 767px 及以下折叠为 Base UI Dialog，不压缩字号或让导航折行。

当前项用 `aria-current="page"`；详情归属文章，首页精确匹配根路径。手机菜单名称为“浏览栏目”，保留完整栏目、关闭按钮、Escape 和回焦；跨回桌面时关闭，收窄不会自动重开。主题切换不清空查询、不关闭当前菜单、不重播动画。

## 文章列表、筛选与分页

`/posts` 是唯一文章探索中心。页首 h1“文章”和真实文章总量同排，下方说明；文章结果使用无框单列，标题 h2 23px（600px 以下 22px），500 字重、1.5 行高。摘要 15px／1.75、最多两行，距标题 8px；文章间距 34px、手机 28px，不绘制整行分隔线、卡片背景或上浮。

搜索采用 InputGroup、可见“搜索文章”标签与具名提交按钮，普通桌面 40px、触屏 44px。下方 20px 直接显示“全部”和各分类及真实公开篇数，复用 compact Button 链接；空间不足换行。分类和标签以完整名称识别，用户分类色不覆盖控件焦点与主题。

分类下方为“按标签浏览”展开按钮，提供 `aria-expanded` 和内容关联。标签区域为可换行文字链接，显示标签及总篇数，选中使用共享 primary-light 底色和 focus-text，不套第二层容器。桌面点击高度至少 36px，窄屏和粗指针为 44px；已选标签在载入时展开，也可主动折叠。搜索、分类、标签的异步禁用及参数行为见产品文档，不保留旧筛选 Dialog。

结果栏位于列表前，无条件显示“全部文章”，有条件显示匹配数和清除入口。已选条件逐项展示可移除链接，允许长关键词换行；使用共享淡蓝和 form 圆角，桌面至少 36px、触屏 44px。提交状态有可读反馈，空库、无匹配、参数错误、加载失败分别说明并提供适用恢复操作。

元信息保留日期、精选、分类和标签，字号 12px，日期 11px 等宽；分类／标签独立链接目标至少 44px。精选为静态淡蓝标记（primary-light 底、focus-text 字、11px／18px、pill 圆角），不带按钮阴影或虚假交互。首页近期条目同源复用，隐藏标签但保留分类。

文章与日志共享紧凑分页，上一页／下一页为 secondary Button 链接，44px 高、16px 方向图标，失效时为真正 disabled。中间以等宽字体显示“当前页 / 总页数”，辅助技术读取完整语句。文章列表距分页 48px，日志 36px；筛选、页码规范化及返回行为见产品文档。

## 文章详情、代码与表格

详情保留 896px 阅读列和真实 Tiptap 正文。页首先显示“返回文章列表”，再呈作者、发布时间与文章标题；标题为 30-36px、600 字重、1.35 行高，摘要 16px／1.75；分类与标签合成同组独立链接，更新时间另行保留。正文后提供“继续浏览文章”返回入口。

从列表进入详情时保留筛选和页码；刷新详情后返回仍有效，安全边界与 canonical 规则见产品文档。同一标签页存在列表快照时，使用返回入口恢复列表位置及对应链接焦点，详情刷新不清空快照；浏览器历史保留原生滚动恢复，不逐帧监听 scroll。文章不存在、加载失败沿用相同阅读边界和真实返回／重试入口，不暴露内部异常。

正文与飞书风格编辑器共用根规范及 `article-prose` 的 1rem／1.625 排版基线，标题、段落、列表、强调、引用与链接均消费共享规则。实际正文不补造段落或插图。代码与表格只在自身容器横向滚动，图片不超出阅读列，保留真实比例。

编辑器保存的文字颜色、高亮、段落／标题对齐、高亮块、图片尺寸及表格合并和列宽在前台一致渲染；使用共享正文语义色随深浅模式切换。前台不加载编辑器 NodeView、菜单或拖拽逻辑，阅读页宽度和文章标题信息区保持。

代码块、行内代码、图片和表格外观统一使用根规范的共享正文规则，不在前台覆盖底色、内边距、圆角或单元格排版。语言及复制工具栏纳入同一代码容器，工具栏不随代码横滚；前台语言名称只读，复制使用 compact 36px、form 圆角，触屏 44px，成功与失败反馈遵循产品规则。语法高亮只使用共享 syntax 颜色；未包装的 pre 同样采用共享代码表面，代码区保留内侧键盘焦点环。

表格容器只负责横向滚动，不加圆角外框；表格保留保存的列宽、合并关系与单元格背景，最小宽度占满阅读列。可聚焦滚动容器保留独立焦点，表头可自然换行。图片及裁剪视口保持共享 4px 圆角，裁剪、图注、对齐与真实比例均保留。

本次样式同步的实际验证、截图与边界见[前台正文对齐验证](../engineering/article-prose-alignment-verification.md)。

## 关于与页脚

关于页头像 56px，姓名 24px 与角色 14px 组成横向身份区；简介按真实空行分段，段内换行保留，17px／1.85。社交区域只展示启用的真实资料，图标与长文字链接保留独立焦点和外链说明；空资料省略，不制造占位联系入口。

页脚保持作者、已填写备案和弱化的后台登录入口，不搬入预览说明，不重复栏目或社交列表。最大 1200px、连续横边距、上下 20px；caption 12px，链接目标至少 44px，长备案自然换行，无装饰边线、背景反转或循环动效。GA4／百度采集失败不阻碍阅读。

## 登录页

2026-10-13 认证迁移保持本节布局不变；临时副本实际验证了错误密码反馈与聚焦、成功登录导航、后台数据加载、退出及退出后的后台重定向。具体运行证据与未覆盖范围见 [Better Auth 验证记录](../engineering/better-auth-verification.md)。

登录页采用居中单列布局，表单最大宽度 360px，页面四周留白在桌面为纵向 48px、横向 24px，600px 及以下横向缩为 20px。内容随短屏或错误提示增长，可正常纵向滚动。表单直接置于共享 background 上，不套卡片；保留站名返回首页入口、24px 的“后台登录”标题、用户名、密码和 primary「密码登录」按钮。下方追加等宽 secondary「使用通行密钥」按钮及 13px caption 首次添加说明，不显示装饰图形、编号、口号、欢迎文案或重复占位提示。

登录主题切换放在现有站名返回入口的操作区，不改变居中单列表单和控件顺序。切换不清空用户名、密码或错误说明，不改变增强提交状态。新增切换入口可用键盘操作；原有返回首页、用户名、密码、密码登录、通行密钥仍保持相对焦点顺序。用户名、密码采用 Input，两种登录采用 Button，统一使用共享 form 尺寸：桌面高 40px、600px 及以下或粗指针高 44px，圆角引用共享 form；输入文字为 14px / 20px，水平内边距 12px。字段保留可见标签，错误图标与标记使用 danger，关联错误文字使用 danger-text；状态反馈及减少动态效果引用共享规范。认证与安全约束见 [AGENTS 鉴权约定](../../AGENTS.md#后台鉴权与登录范围)。通行密钥的桌面及 390px 布局、虚拟认证器操作证据见 [Passkey 验证记录](../engineering/passkey-verification.md)。

站名入口采用 caption，悬停提亮并保留独立焦点轮廓；窄屏或粗指针下实际高度至少 44px。页面整体切换遵循共享动效，表单内部不增加额外动效，输入与按钮沿用共享状态。

渐进增强表单在当前页显示字段或通用错误，失败保留输入。字段错误通过 `aria-invalid` / `aria-describedby` 关联输入并聚焦首个错误字段；凭据、请求、限流、服务与网络错误使用可聚焦文字提示。提交期间文字显示“登录中…”，禁止重复提交并暂时只读输入；成功执行完整导航进入后台。无 JavaScript 时保留原生表单契约，行为与边界见[登录行为](../product/behavior.md#登录)。

2026-10-07 已实施上述精简布局。运行核对通过：1440×1000 桌面、390×844 窄屏、390×320 短屏及错误提示布局，桌面 40px / 窄屏 44px 控件，必填校验、Tab 顺序与可见焦点、返回首页、Enter 提交、请求失败后的输入保留与错误聚焦、再次编辑清除错误。增强表单在 `login.localhost:3000` 验证，提交被现有同源校验按预期返回 403；`127.0.0.1` 不属于 Next.js 默认允许的开发资源来源，仅用于布局观察。18 项登录 API 与客户端测试、类型、lint 和格式检查通过。提交中的只读与防重复仅源码核对；成功登录、限流、字段错误和无 JavaScript 的浏览器流程本轮未验证，既有测试不代替这些运行验收。

## 组件展示页

`/design-spec` 是仅开发环境开放的设计工作台，环境守卫保持不变。2026-10-14 按已批准方案实施目录与单项工作区，先作为局部试验；同日用户将已预览的深浅色色盘与模式切换推广至前台、登录页和后台。当时的局部圆角、密度与去描边变体仅用于工作台。2026-10-15 用户授权统一为 Semi 默认主题叠加 modern 后，该页与业务页共用基础组件皮肤，不再保留另一套局部圆角、密度或无描边规则。

### 结构与布局

- 桌面顶栏固定高 64px，包含 Design spec、设计试验区、全站模式切换与返回网站；说明该页用于组件预览。左侧固定 200px 目录，内容最大宽度 1100px，左右内边距 32px；当前目录项使用灰底和明确文字。
- 桌面目录使用 Base UI ScrollArea 原生滚动视口和覆盖式竖向滚动条，轨道不占内容宽度；内容左右保留16px。沿用共享滚动条颜色与10px轨道／6px滑块，悬停、滚动或目录内有焦点时显示，不绘制轨道底色或分割线。保留滚轮、键盘和滑块拖动，目录滚动不连带主内容。
- 900px 及以下将目录收进弹窗，顶部保留目录按钮和当前位置；内容左右内边距 20px。菜单可滚动，选择后关闭并将焦点移入工作区，取消后返回目录按钮。
- 每次只显示一个条目，默认「基础 → 颜色」。URL hash 保存当前展示条目，支持刷新和历史返回；旧 overview/foundations、components、forms、motion 链接分别映射到颜色、按钮、联系表单和效果舞台。切换条目重置该项本地演示。
- 目录分为基础（颜色、排版、圆角与间距）、组件（按钮、卡片、输入、选择、开关、标签页、折叠面板、弹窗）、组合场景（联系表单、搜索与组合输入、错误与恢复）、动效（反馈节奏、效果舞台、指针）和使用说明（原则与来源）。
- 内容顺序为标题与简述、真实样本、适用状态或尺寸、简短规则。取消营销 Hero、大面积介绍及重复原则卡片；原则集中到使用说明。普通舞台最小高度 200px，表单等内容自然增长。
- 颜色页先呈现「颜色表达信息」的语义样本，再进入按用途分组的色板；色值读取与复制说明紧邻色板入口。语义样本与色板大组之间留 32px，色板大组内部留 24px，先观察用途再核对具体值。
- 基础色板在桌面使用三列、1100px 及以下两列；其他样本双列，600px 及以下单列。不通过固定高度裁切表单、文案或浮层。

### 样本与交互

基础色板按用途分组，色块、文案与复制读取当前模式的实际 CSS token；复制失败给出文字反馈。排版、圆角、间距与密度均有对应样本。静态状态与可操作样本明确标注。字段标签、控件与错误说明之间统一留 8px，使用布局 gap，隐藏表单字段不参与间距计算。

Button、Card、Tabs、Accordion、Dialog、Switch、Select、Combobox、InputGroup、ColorInput 等继续复用本地共享组件或其 Base UI 基础部件，外观继承全站共享皮肤。Tabs 保留禁用项和键盘切换；弹窗保留 Escape、关闭与回焦；选择器可选择，Combobox 可搜索、清空与展示无匹配状态。通知开关只控制本地文字反馈。

Select／Combobox 下拉列表、普通弹窗和移动目录弹窗统一使用本页 Base UI ScrollArea 包装，与桌面目录共用覆盖式滚动条。下拉列表最高为 240px 与浮层可用高度的较小值，内容上下内边距 4px、左右为 0；列表和 Viewport 组合成同一个 DOM 节点，保留键盘导航时选项自动滚入视口。筛选缩短后同步调整高度并隐藏不必要的滑块；无匹配提示的 live region 始终保留。弹窗内边距 24px，视口最高为 `100dvh - 40px`，内容较少时自然收缩，超出时内部滚动；标题、关闭按钮和操作区随内容一起滚动。主页面与多行文本仍使用自身原生滚动，不扩展到其他页面。

联系表单明确标出必填／选填，沿用原生必填校验；提交只显示本地成功反馈，不写入业务数据。搜索演示支持 Enter、搜索和清空，清空后回焦输入。错误恢复演示继续提供「显示错误」「禁用控件」两个独立开关，覆盖 Input、Textarea、Select、InputGroup、Combobox 和 ColorInput，错误文字与 ARIA 属性同步。

动效集中于独立页面。四档节奏可主动触发；BorderBeam 使用公开 `active`，ThinkingOrb 使用 `paused`，不重写库内部效果。默认暂停，一次只运行一个循环效果，重播保留选择；离屏、隐藏页面或离开条目时暂停，返回后等待显式播放。减少动态效果时禁用循环播放并保持静态样本；本地悬停舞台取消位移。指针保留现有 Afterglow 三态 SVG 样本和真实按钮、禁用按钮及文本输入。
