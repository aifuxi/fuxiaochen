# 前台、登录与组件展示页

本文件规定前台页面、登录页和 `/design-spec` 的视觉布局与组件组合。共享颜色、字体、圆角、材质、基础控件及通用交互状态以 [DESIGN.md](../../DESIGN.md) 为准；数据来源、筛选、分页、发布、权限及错误处理等业务约定见 [产品行为](../product/behavior.md)。页面只定义组合和场景差异，不重复基础组件的状态样式。

2026-10-06 已实施全站 Inter 加中文系统字体、普通导航与当前项局部胶囊、原生指针、首页居中文案与五个栏目微卡入口、组件展示页新网格。实际验收范围由根设计规范的同步记录和[视觉实施记录](../engineering/verification-history.md#视觉基线实施2026-10-06)追踪；其他场景规则继续有效，不将其迁移或字体接入视为全部业务场景已重新验收。

## 前台共同布局

导航品牌使用共享 FC 内联 SVG logo，背景透明，字标颜色继承品牌链接文字；显示尺寸为 32×32px，与站名间距保持 10px。SVG 使用 `aria-hidden="true"` 与 `focusable="false"`，由相邻站名提供返回首页链接的可访问名称；品牌链接沿用共享 hover、active 和 focus-visible 状态。

前台沿用共享深浅主题，默认深色；模式偏好与切换行为由 [DESIGN.md](../../DESIGN.md#深浅模式) 统一维护。外框最大宽度 1200px，桌面内容区最大 1136px；导航、首页和页脚内容边线对齐。文章列表、分类、标签、友链、关于和日志使用最大 760px 的居中内容列；文章详情采用最大 56rem（默认根字号下为 896px）的阅读列，页首与正文左右边线对齐。友链仍在同一内容列内使用双列布局，不另设更宽的容器；文章不存在、加载失败与无效页码状态沿用相同宽度。

导航、主内容与页脚共用场景变量 `--site-gutter`：600px 及以下两侧至少 20px，600–900px 之间连续增加，900px 及以上至少 32px，对应 `clamp(20px, calc(4vw - 4px), 32px)`。横向边距不随控件、导航或首页构图断点跳变。前台根滚动容器使用 `scrollbar-gutter: stable`，为经典滚动条预留空间，避免长短页面切换时内容位移；覆盖式滚动条与不支持该属性的浏览器沿用原生行为。该规则仅在前台壳存在时生效。

长站名、标题、链接及资料自然换行，页面高度随内容增长；只有代码、表格及确有需要的局部区域横向滚动。

前台、登录与组件展示页沿用共享 Motion 页面切换：仅在已提交的路径变化时让现有 main 整体入场（登录页使用现有 login-panel，避免全屏 main 的位移增加滚动溢出），导航与页脚静止；首次 SSR 与 hydration 直接显示。首页与展示分区随页面一起显示，不增加分区、卡片或列表错峰。筛选、分页、hash 和刷新不重播，既有 hover、Dialog、Tabs、Accordion 动效保留；减少动态效果及能力不可用时静态显示。实际验收范围见动效接入记录，不将源码实现视为所有环境运行通过。

2026-10-07 先统一连续边距与前台滚动条预留，随后按栏目切换的对齐要求取消 720px 阅读列和 880px 友链列，将首页之外的内容统一为 760px。该次验证范围见[前台内容边线对齐记录](../engineering/verification-history.md#前台内容边线对齐2026-10-07)；此前三种列宽的验收只作为历史证据。2026-10-09 根据中文长文阅读反馈，仅文章详情调整为 56rem；本次范围见[文章阅读列加宽记录](../engineering/verification-history.md#文章阅读列加宽2026-10-09)。

前台、登录和组件展示页共用 Inter 优先、中文使用系统字体的无衬线栈。数字、版本、参数和代码继续使用等宽字体。字体栈及全站字号角色统一维护在 [DESIGN.md](../../DESIGN.md)，本文件仅定义场景尺寸。

前台、登录及展示页沿用共享 Afterglow CSS SVG 指针，造型、主题颜色、按下与系统回退规则统一由 [DESIGN.md](../../DESIGN.md#通用交互与文案) 维护；可编辑文本和键盘焦点保持各自语义。`/design-spec` 提供三态静态样例、真实按钮、禁用按钮和文本输入，触屏也能查看造型。

页面和容器默认使用共享灰阶基底；栏目识别、分类和重点信息可通过共享颜色作用于文字、图标、边线或局部底色。静态徽标可按信息重要性使用品牌强调，采用明确、稳定的映射，保留文字并核对实际对比度；控件状态与焦点继续遵循共享规范。2026-10-07 先扩展用色许可，随后按逐页审计实施下文明确的局部映射；规范扩展的历史范围见[用色规范优化记录](../engineering/verification-history.md#用色规范优化2026-10-07)。实现不能代替运行验收，新增场景的实际证据另行记录。

文章、分类、标签、友链、关于和日志的栏目标题统一使用共享 heading；首页使用 display，文章详情保留阅读标题变体。分类链接、标签胶囊、友链卡片与普通导航链接的按下底色在 sRGB 中由 surface 50% 与 background 50% 混合，压暗悬停表面；已选导航和友链分类使用已有 raised / input-hover / input 状态组合。页脚和关于联系入口按下时回到 background，文字和独立焦点仍按共享规则反馈。

文章不存在和前台加载失败使用共同布局的最大 760px 内容列与共享 heading，保留真实返回或重试操作。文章不存在页复用文章详情的返回链接组件。加载失败的重试重新获取页面内容，不向读者展示内部异常。

## 首页

### 内容与桌面构图

首页继续使用现有公开设置提供的站点名称、副标题与作者资料；名称为唯一 `h1`。页面保持“阅读文章”入口与作者身份，不新增文章列表、计数、筛选数据或额外请求。五个微卡只链接既有栏目。

桌面以居中文案为视觉中心，五个微卡环绕其外侧，给标题、副标题、阅读 CTA 和作者资料保留完整阅读区域。文字直接位于页面底色上，不套介绍卡片或装饰面板。标题使用共享 `display` 角色：640px 及以上为 42px / 45px、500 字重、`-0.005em` 字距；小于 640px 为 30px / 34px，字重和字距保持一致。标题不使用渐变填字。

副标题为 16px caption 文字，距标题 16px；“阅读文章”距副标题 24px，使用 primary Button 链接至 `/posts`，作为唯一 primary 操作。桌面 CTA 使用 32px 胶囊；600px 及以下或粗指针至少高 44px。作者资料距入口 48px，以 56px 头像、14px 姓名和 13px caption 身份说明辅助识别，居中组合；完整个人介绍由关于页承载。空副标题或身份说明按既有业务规则省略。

### 五个微卡入口

| 桌面位置 | 可见名称 | 路由          | 图形含义     |
| -------- | -------- | ------------- | ------------ |
| 上方中央 | 分类     | `/categories` | 分类或文件夹 |
| 左侧     | 文章     | `/posts`      | 书籍或文档   |
| 右侧     | 标签     | `/tags`       | 标签或井号   |
| 左下     | 日志     | `/changelog`  | 历史记录     |
| 右下     | 关于     | `/about`      | 作者或人物   |

每个入口是一个真实链接，复用现有 Lucide 图标库，包含常显文字名称；名称提供可访问名称，装饰图标从辅助技术中隐藏。整块链接提供点击区域，内部不嵌套其他操作。不能仅靠悬停出现的 tooltip 告知去向。

图形单元采用约 130×130px 的 Hero variant，使用 surface 外壳、24px 外圆角、14px 内舞台圆角与 11px 舞台 inset。文字位于图形单元下方，保持可读且不遮住图标。此处 11px 只作用于 Hero 微卡，不覆盖普通 Card 的 12px 舞台间距。各图形共用 surface 材质；文章、分类和标签的阅读／探索图标固定使用 focus，日志和关于图标默认 caption。颜色只作用于图标，名称和表面保持灰阶；通过常显文字明确入口，不将识别色误作业务状态。既有触发反馈保持，不增加持续装饰动画。

精细指针 hover 与键盘 focus-visible 时，内部卡片按共享 expressive 时长和 lift-ease 曲线上浮至 6px，图标上移 2px，并按栏目轻微旋转或缩放；名称下方展开 raised 底色的胶囊及方向箭头，名称与箭头使用 foreground。阅读／探索图标保留 focus，日志和关于图标提亮为 foreground。名称始终可见，链接命中框固定，周围布局不移动。active 使用 micro 时长将卡片压回 1px、图标复位；键盘焦点环跟随内部卡片。胶囊自身提供完整点击区域，门户层级不被中央文案的透明区域遮挡。

触屏不依赖 hover 获得名称或进入栏目，点击反馈和焦点状态沿用上述规则。`prefers-reduced-motion` 下卡片、图标和名称的位移、缩放与旋转均为零，隐藏方向箭头；保留即时的材质、文字与焦点反馈。

### 窄屏构图

760px 及以下将五微卡排在文案上方，采用两张、一张、两张的 2–1–2 队列，随后呈现标题、副标题、阅读 CTA 与作者资料。入口按可读顺序组织，DOM 焦点顺序与窄屏视觉顺序一致，不使用正数 `tabindex` 改变顺序。

两侧沿用前台共同布局的连续边距，卡片间距与尺寸在可用宽度内适配，名称自然换行。整段 Hero 自然增高；不以固定高度裁切五微卡、长站名或资料，也不让微卡与文案交叠。760/761px 核对构图切换，639/640px 核对标题尺寸切换。

## 顶部导航

顶部导航采用普通文字链接，仅当前栏目使用局部 raised 胶囊和 foreground 文字；普通项使用 caption 文字。导航整体无胶囊外框、描边或常驻填充，当前项不添加蓝色短线。导航右侧现有操作区加入共享 `ThemeToggle`，登录页也提供同一入口；保持品牌、栏目与现有移动菜单的布局及操作。切换时保持当前栏目、查询、滚动与焦点，不重建导航。桌面导航独立居中，品牌与右侧操作不参与导航中心计算，宽度随栏目内容增长。

桌面与移动端栏目保持：首页、文章、分类、标签、日志、友链、关于。链接桌面高 36px、水平内边距 16px，字号 14px / 20px、500 字重，栏目间距 8px。粗指针点击目标至少高 44px，空间不足时折叠为本地 Base UI 菜单，不压缩字号或造成页面横向溢出。

导航使用语义化 `nav` 和真实链接；首页精确匹配根路径，文章详情高亮文章栏目，当前链接提供恰当的 `aria-current`。布局与文字位置不随状态变化。状态反馈沿用共享规范，折叠菜单保留完整栏目文字及既有关闭与焦点行为。

## 文章列表、筛选与分页

`/posts` 沿用共同布局的最大 760px 居中栏目列，与分类、标签页首对齐。页首以 `h1`“文章”与真实结果数量同排，不展示默认“全部文章”栏。列表文章标题为 `h2`。

页首下方 32px 为搜索框与筛选按钮，使用 compact 尺寸，桌面高 36px、600px 及以下或粗指针高 44px，同排对齐；搜索复用 InputGroup，包含有可访问名称的提交操作，附加图标操作沿用共享尺寸。分类与标签在本地 Base UI Dialog 内组合，最大宽度 440px，手机两侧至少 20px，内容独立滚动，字段有可见标签；字段、取消和应用采用共享 form 尺寸。已应用数量、当前筛选说明及清除入口按业务条件显示，条件说明距搜索栏 12px 并允许换行。提交反馈和关闭后的焦点恢复沿用既有行为，详见 [产品行为](../product/behavior.md)。

筛选区与列表间距 32px，文章间距 28px。各宽度保持单列，标题、摘要和元信息左对齐，直接排在页面底色上，无行分割线、外框、卡片底色或装饰阴影。日期不单独占列。

文章标题桌面 24px、600px 及以下 22px，500 字重、行高 1.5，长标题自然换行。摘要为 15px、行高 1.75、caption 文字，距标题 8px，各宽度最多两行。标题与摘要共用文章链接，并由标题关联可访问名称；摘要来源及截取规则在产品行为中维护。

摘要下方 8px 显示日期、精选、分类和标签，元信息间距 16px、允许换行，文字 13px。日期使用 metadata；分类和标签文字使用 caption。分类名称前使用已有用户分类色的 8px 圆点，带 1px subtle 边线，距名称 8px；分类索引、文章列表与详情共用该标识，异常颜色回退 muted，不覆盖主题、文字或焦点色。圆点为装饰，完整名称继续承担识别。精选与日期保持同组，采用 primary 实心底色、primary-foreground 文字，12px / 18px、500 字重、上下 2px／左右 8px 内边距和 pill 圆角，无按钮阴影或独立交互。日期自身不设交互目标高度；分类与标签链接各自可操作，点击目标至少高 44px。交互只反馈标题或当前元信息，不让整行上浮。

文章与日志共用居中的紧凑分页组，gap 16px。上一页、下一页复用 secondary Button，带 16px 方向箭头，高 44px、水平内边距 16px；可用项保持链接语义，不可用项使用真实 disabled 按钮。中间以 13px caption 文字和共享 `--font-mono` 等宽字体显示“1 / 3”，辅助技术读取“第 1 页，共 3 页”。文章分页距列表 48px，日志为 32px；分页不增加外框、容器背景或装饰动画。隐藏条件、查询条件保留和页码处理见产品行为。

空库、无匹配、加载和查询失败保留明确文字与相关操作；状态不改变列表的阅读宽度，不加入填满页面的演示记录。

## 文章正文、代码与表格

正文页采用最大 56rem 的居中阅读列，默认根字号下为 896px，约可容纳 53 个当前字号的汉字；标题与正文左右边线对齐。窄屏沿用共同布局连续边距，不设置最小宽度；文章列表保留 760px。文章标题自然换行，正文引用[共用文章正文排版](../../DESIGN.md#共用文章正文排版)，由 `article-prose` 提供相对字号、标题、列表及块间距，普通正文使用 foreground-reading，标题、强调与代码配色引用共用规则；发布时间与修改时间分别呈现，修改时间采用辅助元信息。正文头部分类与标签的真实链接目标至少 44×44px，分类色点沿用列表映射，日期不随之扩大。正文链接、标题、列表、任务列表、引用、图片及分隔线共用上述规则；文章主标题与头部间距保持现有阅读标题变体。图片不超出阅读列，代码和表格只在自身容器中横向滚动。

文章返回入口复用本地 Button 与 Next Link 的链接组合：ghost、compact、16px 左箭头与“返回文章列表”，保留真实 `/posts` 链接和 link 角色；桌面高36px，600px及以下或粗指针高44px。返回控件外边线与阅读列起始边线对齐，距后续内容24px；字号、圆角、hover、active、focus-visible及减少动态效果引用共享按钮规则，不单独维护裸链接样式。文章详情与文章不存在页使用同一 `ArticleBackLink`。

前台代码块使用 surface 底色、14px 圆角和 20px 代码内边距，代码字号与容器上下间距引用共用正文规则。顶部工具栏常驻：左侧语言名称、右侧“复制代码”，工具栏不随代码横向滚动，使用 caption 文字与 outline 底边线。工具栏控件桌面高 32px，600px 及以下或粗指针至少 44px。复制状态以文字表达，未知语言和纯文本显示、复制原文及反馈时长见产品行为。

语法高亮引用共享 syntax token，关键字、字符串、数字、函数与注释各自对应根规范中的角色；其他代码使用 foreground。颜色只用于代码区，不改变正文内容或复制文本。

正文表格由滚动容器提供 1px outline 外框和 14px 圆角裁切。表格单元格保留折叠边线，表格自身外边线隐藏，避免与容器外框叠加；表头底色和内容随圆角裁切。单元格上下 12px、左右 16px 内边距；直接段落不继承普通正文外距，连续段落间距引用共用正文规则，避免单行内容产生过高行距。长表格不撑宽页面。容器可聚焦时使用共享焦点提示。

- 采用当前全站深浅色色盘与蓝色主要操作。工作台页面标题 24/32、600 字重，章节标题 18/26、600，分组标题 16/24、500；正文与控件 14px，简短注释 12/18。排版页的 display 样本保留原 42/45、移动 30/34 的比例。
- 独立按钮、输入、选择触发器与浮层、标签组外壳统一使用 radius-form 的 12px；页头返回与跳过入口按独立操作处理。Select／Combobox 浮层与 Tabs 的内部留白均为 4px，内外轮廓保持一致的嵌套关系。
- 导航列表项、折叠面板标题、选择选项、标签项与指示器，以及 InputGroup／Combobox 内嵌图标操作使用 radius-sm 的 8px。不能仅因使用 button 标签就把内部操作也改为外壳圆角。
- 样本、色板卡片、对话框与反馈浮层使用 radius-lg 的 16px；色板采用 raised 实色卡片，独立色块与卡片顶部、两侧保留 12px，色块使用 radius-sm，近黑色样也由外层表面明确包围。开关、徽标、状态圆点与运动示意保留胶囊／圆形，ColorInput 内部微型色样保留原有 4px 细节，不作为独立操作控件。布局样式引用局部 token，不重复写圆角数值。
- 灰阶实色表面取消多层内高光；普通卡片靠底色和留白分组，浮层仅保留一个柔和阴影，遮罩不做背景模糊。
- 共享色盘按页面 background、内容 surface、舞台 stage、操作与浮层 raised 分工，stage 随当前模式切换。次级按钮与导航反馈使用 raised-hover／raised-pressed，独立于输入表面。具体颜色数值仅维护在共享规范及 `app/globals.css`，本页不保留另一套颜色覆盖。
- 2026-10-14 用户明确禁止常驻浅色描边和装饰分割线。输入、选择、组合输入、卡片、色板、标签与通知均无常驻描边，顶栏、侧栏、分组说明和页脚不画分隔线；禁止用 inset 阴影、伪元素或透明边框加高光变相恢复。层级由底色、间距和字重表达。
- 错误通过字段文字、`aria-invalid` 和 `aria-describedby` 表达，保持填充表面；操作焦点仍使用按需出现的独立轮廓。主按钮使用 primary-foreground，悬停使用 primary-hover-foreground；占位与必要说明使用 caption，元信息使用 metadata，不在较浅输入表面使用 subtle。
- 工具栏高 36px，表单高 40px；600px 及以下或粗指针下，操作目标至少 44px，图标复制按钮同时保留 44px 宽度。
- 单行按钮、输入与选择使用 14px / 20px，文字与图标垂直居中。输入和选择的文字起点距左侧 12px；文字按钮水平 16px，小型按钮 12px，多行文本保持 24px 行高。InputGroup 首图标距左侧 12px，与文字相隔 8px；文字至尾部操作区留 4px，末端距外壳 4px。Select、Combobox 与 InputGroup 的末端图标区统一桌面宽 32px、窄屏／粗指针宽 44px，避免相邻控件箭头错位。密度样本按普通表单／紧凑工具栏分行，输入、选择和按钮同排等高，窄屏转为单列。

### 样本与交互

基础色板按用途分组，色块、文案与复制读取当前模式的实际 CSS token；复制失败给出文字反馈。排版、圆角、间距与密度均有对应样本。静态状态与可操作样本明确标注。字段标签、控件与错误说明之间统一留 8px，使用布局 gap，隐藏表单字段不参与间距计算。

Button、Card、Tabs、Accordion、Dialog、Switch、Select、Combobox、InputGroup、ColorInput 等继续复用本地共享组件或其 Base UI 基础部件，外观由本页覆盖。Tabs 保留禁用项和键盘切换；弹窗保留 Escape、关闭与回焦；选择器可选择，Combobox 可搜索、清空与展示无匹配状态。通知开关只控制本地文字反馈。

Select／Combobox 下拉列表、普通弹窗和移动目录弹窗统一使用本页 Base UI ScrollArea 包装，与桌面目录共用覆盖式滚动条。下拉列表最高为 240px 与浮层可用高度的较小值，内容内边距 4px；列表和 Viewport 组合成同一个 DOM 节点，保留键盘导航时选项自动滚入视口。筛选缩短后同步调整高度并隐藏不必要的滑块；无匹配提示的 live region 始终保留。弹窗内边距 24px，视口最高为 `100dvh - 40px`，内容较少时自然收缩，超出时内部滚动；标题、关闭按钮和操作区随内容一起滚动。主页面与多行文本仍使用自身原生滚动，不扩展到其他页面。

联系表单明确标出必填／选填，沿用原生必填校验；提交只显示本地成功反馈，不写入业务数据。搜索演示支持 Enter、搜索和清空，清空后回焦输入。错误恢复演示继续提供「显示错误」「禁用控件」两个独立开关，覆盖 Input、Textarea、Select、InputGroup、Combobox 和 ColorInput，错误文字与 ARIA 属性同步。

动效集中于独立页面。四档节奏可主动触发；BorderBeam 使用公开 `active`，ThinkingOrb 使用 `paused`，不重写库内部效果。默认暂停，一次只运行一个循环效果，重播保留选择；离屏、隐藏页面或离开条目时暂停，返回后等待显式播放。减少动态效果时禁用循环播放并保持静态样本；本地悬停舞台取消位移。指针保留现有 Afterglow 三态 SVG 样本和真实按钮、禁用按钮及文本输入。

### 展示页设计试验区

- [preview.module.css](<../../app/(showcase)/design-spec/preview.module.css>) 的 `.scope` 是非颜色草稿入口，只覆盖本页已批准的局部视觉变量与样式；颜色继承统一 `html[data-theme]`。本页局部覆盖不得使用裸 `:root`、`html`、`body`、`@theme` 或不带作用域的全局规则。
- 页面根与 [preview-components.tsx](<../../app/(showcase)/design-spec/preview-components.tsx>) 包装的 Dialog、Select、Combobox Portal 共用 CSS Module 类，浮层仍挂到 `body` 避免裁切。移动目录也使用此包装器。Portal 颜色同步全站模式，本页样式作用域继续承载局部无描边与圆角变体；全站组件颜色由共享角色维护。
- 布局在带 `.design-showcase` 前缀的 `showcase.css` 内维护；页面模型、基础和演示分别位于本路由内。本页局部视觉试验不得修改共享非颜色规则；本轮获准的全站色盘与模式接入在共享样式、根布局和主题组件中维护。
- 本页不是共享组件冻结副本。第三方效果与指针资产沿用当前实现；CSS 动效只在作用域内调整。共享 `MotionProvider` 继续从根读取 JavaScript 动效参数。
- 不提供 token 编辑、保存、版本、发布或空的对照控制。本轮授权推广色盘与模式到业务页面，其他局部视觉变体继续保留隔离范围。
