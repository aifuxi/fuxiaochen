# 后台场景规范

本文件维护后台页面的布局、信息密度、容器职责和场景交互。共享颜色、字体、材质、基础组件状态、动效与可访问性要求以[根设计系统](../../DESIGN.md)为准；字段约束、查询、业务状态、保存条件和统计口径以[产品行为](../product/behavior.md)为准。数据库、上传及调度机制分别见[数据库维护](../maintenance.md)、[媒体存储](../media-storage.md)和[部署指南](../deployment.md)。

下列尺寸与组合延续现有后台布局。2026-10-06 已接入共享无衬线字体与原生指针，2026-10-09 字体加载切换为 jsDelivr CDN，2026-10-15 字体统一更新为 Source Sans Pro。具体字体栈与加载方式由根设计系统维护；仪表盘字体与页面标题的历次运行抽查、完整业务页与编辑字号回归仍按验收记录区分范围。数值、参数和代码继续使用共享等宽字体。

2026-10-07 首次用色规范优化明确默认材质与文字 token，并允许按品牌重点、数据类别和真实状态建立视觉层次；当时仅调整规范，未修改 token 数值或页面效果，范围见[用色规范优化记录](../engineering/verification-history.md#用色规范优化2026-10-07)。后续逐页整改按本文件的场景要求实施，实际运行范围另见[历史验收记录](../engineering/verification-history.md)，未执行场景不记为通过。

2026-10-15 用户授权将后台色盘与基础组件视觉统一为 Semi UI Vue 默认主题叠加 modern；边框、高光、阴影、圆角和完整状态由根设计系统维护。Base UI 行为、后台布局及业务流程保留；显式的 Dock、写作工具、分页与触屏目标尺寸继续按场景声明，普通 form / compact 控件引用新的共享尺寸。历史验收不代表本轮迁移已运行通过。

2026-10-16 用户明确恢复普通桌面表单与按钮 40px、compact 工具栏 36px、form 圆角 12px，窄屏与粗指针保持 44px；配色、边框、高光和状态继续采用 Semi default + modern。Dock、分页、写作工具的显式尺寸以及 Card、弹层、菜单和 Switch 保持既有约定，不因共享表单密度变化扩大。

后台沿用共享 Afterglow CSS SVG 指针；编辑器的 text、块手柄 grab／grabbing、禁用控件 not-allowed 保留原生语义，表格排序、菜单与媒体操作复用共享操作指针，具体规则见根设计规范。

## 容器与工作区

后台沿用共享深浅主题，默认深色；模式偏好由 [DESIGN.md](../../DESIGN.md#深浅模式) 统一维护。文章、友情链接与更新日志采用连续工作区；设置采用页面级 Tabs 与平铺 Section。分类与标签按独立业务模块组织，不合并成一个整页数据容器。

展示 Card 用于效果舞台；后台业务 Card 使用共享 Card 的 surface、md 圆角、边框与 modern 边缘材质，不把普通字段或说明套进舞台。连续工作区保留既有 14px 圆角与连续布局；设置 Section 不加外卡。后台与前台沿用共享页面切换节奏，仅在路径提交后让 admin-content main 整体入场，Dock 和页脚静止。业务 Card、表格行与字段分组不单独入场、上浮或循环；筛选、分页、刷新及轮询不触发页面动画，草稿保护与编辑器 sticky 布局保留。

| 层级     | 职责与边界                                                                         |
| -------- | ---------------------------------------------------------------------------------- |
| 页面     | 标题、必要说明与主要操作直接位于页面底色上；页首不加外卡、英文眉题或装饰标题图标。 |
| 工具栏   | 筛选和搜索与表头、数据、空状态、分页共用连续边界，不另套筛选卡。                   |
| 数据     | 表头、行和分页保持对齐，横向滚动限制在表格容器内。                                 |
| 字段分组 | 通过 Section 标题、标签对齐与留白分组；相邻开关和重复编辑项之间保留淡线。          |
| 独立模块 | 运营任务和服务摘要可使用后台业务 Card；内部普通内容不套舞台。                      |
| 浮层     | 业务编辑、确认与通知使用本地 Base UI 控件；文章写作使用独立页面。                  |

页首主要操作采用 primary，新建文章只保留在文章页面内。筛选与刷新控制放在对应工作区。保留记录图像、分类色点和操作图标，文案只说明操作、业务状态及影响管理决策的限制。

## 后台框架

桌面导航使用左侧居中的悬浮 Dock，宽 72px、距视口左侧 16px，内容列为导航预留 104px。Dock 使用共享 surface、lg 圆角与 popup 阴影；支持 backdrop-filter 时采用 surface 90% 与透明混合底色及 16px 模糊，其他环境使用不透明 surface。不新增装饰分割线、自动隐藏、图标放大、弹跳或位移反馈；承载共享浮层阴影时保留其中的 modern 边缘效果。高度随内容，最大为视口高度减 32px，矮视口内部可滚动，保持所有入口可达。

Dock 顶部使用共享 FC 内联 SVG logo，显示尺寸 32×32px，透明背景并继承前景色；品牌文字仅供辅助技术读取。导航沿用内容、互动、系统分组，组名桌面隐藏、移动端显示，桌面以 12px 组间留白区分。导航与首页入口为 44×44px、md 圆角，图标 20px；组内间距 4px。当前项以 sRGB 中 primary 16% 与 surface 84% 混合的底色及 focus-text 图标标识，并提供 aria-current。新建与编辑文章仍高亮文章管理。移除展开／收起按钮及其状态，不再提供宽侧栏。

桌面图标悬停 250ms 或键盘聚焦时，名称通过本地 Base UI Tooltip 显示在右侧；相邻提示复用 Provider 的即时切换，Escape、移出、失焦或点击关闭。名称始终通过 aria-label 提供，不依赖提示才能理解；导航保留真实链接、Tab／Enter 和未保存保护。hover、active、focus-visible、disabled 与减少动态效果沿用共享规则，图标与点击区域尺寸始终固定。首页入口与业务入口以留白区分，分类和备份继续跳转各自管理页。

<=900px 隐藏 Dock 和内容预留，由左下角 44×44px 的悬浮导航按钮打开文字抽屉。入口距视口左、下各至少 16px，并避开安全区；页脚底部预留 80px 加安全区，避免挡住末尾操作。抽屉内提供相同的主题、通知与账户操作，显示文字；这些文字 utility 按钮使用共享 form 圆角 12px、至少 44px 高的移动目标，桌面 Dock 的 44×44px、md 圆角 16px 仍为独立场景。长内容可在抽屉内部滚动。抽屉内 logo 32×32px、业务图标 18px，品牌名与分组名可见，关闭按钮、遮罩和导航成功后都能关闭。品牌 SVG 使用 aria-hidden 与 focusable=false，不单独成为焦点目标。抽屉保留浮层边缘和遮罩，品牌与底部操作区不画分隔线。

后台不再渲染顶部栏或保留顶部占位，内容区直接从页面内边距开始，使用 background。主题切换、通知与账户菜单统一放在 Dock 下部，按钮与导航同为固定 44×44px；账户显示圆形头像，通知只在有未读、数量未知或读取失败时显示角标，完整数量与错误说明通过可访问名称和 Tooltip 提供。新建文章只保留文章页面内的按钮。Dock、按钮、名称提示和弹窗随全站模式切换，切换不改变筛选、浮层、草稿、专注模式、光标、滚动或撤销历史；页脚不画分隔线。

通知与账户使用既有业务 Dialog，关闭后焦点回到对应 Dock 入口；从手机抽屉打开时，先关闭抽屉，再打开业务 Dialog，关闭后回到悬浮导航按钮，不向已隐藏的抽屉控件回焦。

后台壳和含数据列表的后台浮层提供局部分隔变量 `--admin-divider: color-mix(in srgb, var(--color-outline) 60%, transparent)`，不修改全局 outline。表格、连续列表、分页和重复编辑项之间使用 1px 淡线；业务 Card 标题下不画横线。时间线、浮层边缘、焦点与错误提示保留各自所需的对比度。

工具栏和页面操作通过 compact 语义选择共享尺寸，复用本地 Button、TabsList、SelectTrigger 与 InputGroup 的 `size="compact"`。设置 Switch 使用 `touchTarget`，视觉轨道采用 Semi 默认尺寸与状态，真实按钮目标保留 44×44px。单元格不固定高度，不裁剪中文长标题，触屏目标不随视觉密度压缩。

普通编辑表单、分类添加和确认操作沿用共享 form 尺寸；文字确认按钮保留正常水平内边距与按文案决定的宽度，不复用图标操作的固定宽度。弹窗不统一强制所有后代按钮高 44px，内部图标或紧凑操作保留各自尺寸语义。写作栏的保存操作沿用 compact，文章设置抽屉的底部操作沿用 form，与所在操作组或单行字段同高。

Dock 中的主题切换提供目标模式的可访问名称，沿用共享 ThemeToggle，支持键盘、可见焦点和名称提示，不改变原有全站偏好与同步机制。

## 数据表格与行菜单

文章、友情链接和分类使用本地 TanStack Table，保留 caption、列头和带 `scope="row"` 的行标题。文章标题、友链名称与分类名称分别作为对应记录的行标题；行标题采用正文材质与排版，不继承列头的 stage 底色。可排序列头使用文字、方向箭头、`aria-sort` 和真实键盘按钮，排序按钮引用共享 form 圆角 12px；不可排序列不显示箭头。排序及分页规则见产品行为，界面保留条数范围、当前页 / 总页数、上一页、下一页与每页条数 Select。列头使用 stage、正文单元格和行标题的分隔使用后台 divider；行悬停默认使用 surface-hover，不覆盖数据类别或状态标识。

更新日志时间线的分页同样显示结果范围、总条数与当前页 / 总页数，范围按当前服务端响应计算，空结果保留 `0–0`。每页数量沿用产品行为的固定值，不增加每页条数 Select。

| 表格               | 最小宽度     | 列顺序与宽度                                                           |
| ------------------ | ------------ | ---------------------------------------------------------------------- |
| 文章               | 850px        | 标题与摘要及标签 38%、分类 12%、状态 10%、精选 12%、时间 18%、操作 10% |
| 友情链接           | 960px        | 站点信息 32%、链接与简介 34%、分类 12%、审核与展示状态 14%、操作 8%    |
| 分类、热门文章排行 | 不强制 850px | 保持紧凑表格；排行保留 PV 排名与前三名标记                             |

文章六列宽度仅在本表维护，标签与摘要归入标题列。正文自然换行，表格容器内部横向滚动，分页可换行；禁止把表格最小宽度传递为页面级溢出。

有业务操作的行采用「…」按钮点击打开 Base UI Menu，不通过 hover 展开。触发按钮为 36px 圆形 ghost，打开时采用 raised；<=600px 或粗指针为 44px。菜单宽 200px、最大宽度为视口减 24px，表面、md 圆角、边缘、投影与内边距引用共享 Menu。菜单位于按钮下方右对齐，间距 6px、边缘碰撞留白 12px，空间不足时自动翻转，Portal 避免被表格裁切。

菜单项图标 16px、文字 14px / 20px，圆角、填充、默认与危险操作状态引用共享 Menu，触屏至少高 44px；普通、审核、删除操作之间用淡线分组。菜单支持方向键、Enter、Escape 和外部点击；关闭菜单和取消弹窗后回到行按钮，触发按钮已消失时回到搜索或新增入口。行操作名称应包含对应记录的可读标识。

## 后台入口

后台不再提供工作台页面与导航项。登录后直接进入文章管理 `/admin/posts`；旧地址 `/admin` 在服务端鉴权后重定向至文章管理。文章状态数量与草稿入口保留在文章列表，分类与备份通过侧栏访问，新建文章仅使用文章页面内的入口。

## 文章列表与写作工作区

文章列表复用后台框架，页首放“文章管理”、简短说明和新建操作。状态 Tabs、分类 Select、精选 Select 与关键词 Input 组成工具栏，直接连接表头、行和分页；不增加独立筛选卡或额外面板留白。桌面控件并排，空间不足时换行；390px 下状态栏局部横向滚动，筛选控件纵向排列。

标题自然换行，空标题使用“未命名草稿”、空分类使用“未分类”；摘要预览一行，标签留在标题列。状态同时使用文字和明确颜色：已发布图标与标记使用 success、状态小字使用 success-text，草稿必要说明使用 caption，精选使用文字标记。行操作菜单提供包含文章标题的可读名称，空状态保留重置筛选或创建入口。

新建和编辑使用独立文章页，继续高亮文章管理导航。写作页默认保留后台框架，不重复页标题、说明与底部操作区。sticky 写作栏滚动后贴视口顶部，top 为 0，background 底色、最小高度 56px、控件间距 12px，放返回、保存状态、文章设置、专注模式和保存按钮；写作栏所有按钮使用共享 compact 的 36px，文章设置抽屉的底部操作使用共享 form 的 40px，与单行字段同高；<=600px 或粗指针时两组操作均高 44px。窄屏操作可换行，状态与按钮不能撑宽页面。专注模式隐藏 Dock、手机悬浮导航入口和页脚，写作栏贴顶，退出时恢复布局；模式的初始化规则见产品行为。

标题和正文构成居中、最大宽度 960px 的连续画布。标题采用共享 display 字体，桌面 32px / 44px、手机 28px / 40px，自动增高、无常驻边框和填充，保留可访问标签及清晰焦点。标题输入是普通表单表面的显式例外：保持透明背景、无圆角，错误采用 2px danger 直线底标记，hover、active 和 focus 不清除该标记；focus-visible 保留 2px focus 外轮廓与原有 4px 外距，与错误底标记共存。错误属性移除后恢复当前正常状态。正文引用[共用文章正文排版](../../DESIGN.md#共用文章正文排版)，与前台共用相对字号、标题、列表、块间距及正文颜色层级，普通正文使用 foreground-reading，无外卡底色、圆角、边框或装饰高光；工具条和字符状态仅保留后台 divider。正文通过文本插入光标表达聚焦，不增加焦点边框或高亮分隔线；标题和工具条按钮保留键盘焦点提示。正文错误使用工具条下方 danger 指示线及 danger-text 关联字段文字，关联实际 contenteditable。块左侧保留手柄空间，窄屏不产生页面横向溢出。

文章设置收纳产品定义的字段。内容区可用宽度至少 1100px 时采用 320px 右侧面板、间距 24px；更窄时用 Base UI Dialog 右侧抽屉，宽 360px、不超过视口宽度，高不超过 100dvh，内容独立滚动。抽屉提供关闭和保存；关闭后焦点回到文章设置按钮，不使用入场位移。摘要采用 Textarea 并显示字符计数，精选采用 Switch，排序采用数字 Input；字段约束与禁用条件只在产品行为维护。

文章状态保留原生 radio 的分组、键盘选择与禁用语义；<=600px 或粗指针时，包含 radio 与状态文字的整个 label 点击目标至少 44×44px。

设置入口用“待完善”或“有错误”表达隐藏字段状态；校验错误时打开对应面板并定位首个相关字段，标题与正文错误留在画布内。写作栏以可读文字表达未保存、保存中和已保存。保存及重新载入规则见产品行为，视觉核对必须检查光标、滚动和撤销历史不因布局或状态反馈被清空。

### 块编辑器

代码块使用 input 底色、1px outline 边线、8px 圆角和 16px 内边距，代码字号与块间距引用共用正文规则，长代码仅在块内横向滚动。顶部工具栏常驻，语言位于左侧、复制操作位于右侧，不随代码横向滚动；使用 caption 文字与 outline 底边线。语言控件为本地 Base UI Select，与复制按钮统一使用共享 compact 高 36px、form 圆角 12px，窄屏或粗指针高 44px；语法高亮复用共享 syntax token，颜色只作用于代码区。

正文表格的字号、段落与容器上下间距引用共用正文规则，滚动容器提供 1px outline 外框与 8px 圆角裁切；单元格保留折叠边线，表格自身隐藏外边线，避免双重边框。表头底色和内容随容器圆角裁切，仅在容器内横向滚动。前台正文的场景圆角另见[前台规范](frontend.md)。

格式菜单、链接和图片插入使用本地 Base UI Popover、Dialog。编辑器的块操作、插入与斜线菜单项采用共享 compact 桌面高 36px、窄屏或粗指针高 44px，保留 0 圆角的连续菜单行形态。斜线菜单不夺取正文输入焦点，以 listbox、`aria-activedescendant` 和文字提示表达选择，支持方向键、Enter、Escape，并保留中文输入法组合输入的处理要求。选中文字出现浮动格式栏；块手柄支持拖拽，同时提供复制、删除、上移和下移的键盘与触屏入口。工具条只在自身范围内横向滚动，触屏目标至少 44px，图片替代文字具有可见输入入口。

Markdown 导入 Dialog 使用共享表面、lg 圆角与 24px 内边距，最大宽 640px、最大高 88dvh，内容内部滚动，输入与提交操作复用共享 form 尺寸，窄屏或粗指针目标至少 44px。关闭后焦点回到正文。导入格式、大小、插入规则及保存条件见产品行为；复制结果以可访问状态文字反馈。

链接与图片插入 Dialog 的字段标签位于输入框上方，采用共享 label 字号、caption、20px 行高，标签与控件间距 8px，字段上下间距 16px；输入框占满字段宽度。

图片插入 Dialog 最大宽 560px、最大高 88dvh，内容内部滚动。依次放替代文字、上传按钮与进度、图片 URL、错误反馈和取消／插入操作。上传区使用纵向布局，不显示媒体网格、搜索或分页。文件名和错误自然换行，进度使用原生 progress 与可读状态；窄屏和粗指针沿用共享 44px 控件目标。关闭及插入规则见产品行为。

## 分类与标签

宽屏采用分类、标签双列业务 Card，窄屏纵向排列，标题使用简短名称与数量徽标，徽标默认使用 raised 底色与 caption 文字。分类包含可见名称标签、颜色选择、添加入口和紧凑语义化表格；标签包含输入、添加入口及直接平铺、可换行的胶囊标签云。标签云无内层容器、底色或边缘，标签胶囊保留 raised 填充、无描边，不设置人为最小高度。

分类颜色是用户数据，可用于该分类的色点、文字或淡底标识，不改变全局主题、不覆盖控件的焦点、错误等状态色。颜色控件使用 input 表面、form 圆角和清晰焦点，宽高共用 form 尺寸，与名称输入和添加按钮同排对齐；选择、筛选和确认使用现有 Select、Combobox、Dialog 与 Button，基础状态与视觉 token 遵循共享定义。长名称自然换行，390px 不产生页面级横向溢出。分类行操作提供编辑与删除；编辑 Dialog 复用名称 Input、ColorInput 和表单按钮，提交中禁用关闭与重复保存，失败保留输入，关闭后焦点回到行操作。删除取消后回到触发按钮，完成后回到新增分类输入；移除标签后聚焦相邻移除按钮或新增标签输入。

## 友情链接与更新日志

友情链接使用连续工作区，分类、审核、展示状态和关键词排列于工具栏，390px 纵向排列。图标 36px，图片失败显示 Link2。审核状态保留文字，通过图标用 success、文字用 success-text，拒绝图标用 danger、文字用 danger-text，待审核必要文字用 caption，展示开关独立显示文字。表单使用可见字段标签与本地控件，删除取消回到触发按钮，成功回到搜索框；列宽及目标尺寸沿用通用表格。

## 系统设置

资料与站点、SEO、系统偏好、备案、社交账号、访问统计使用页面级 Base UI Tabs。字段和 Section 尺寸沿用基线，390px 标签栏局部横向滚动；重新载入作为分组旁的 ghost 次要操作。字段错误切换到对应分组，在面板已挂载、控件可用后聚焦，不以隐藏分组掩盖错误。社交账号整体约束错误关联组标题并聚焦该标题，具体账号字段错误仍定位到对应输入；错误定位不能依赖可能禁用的新增按钮。

访问统计分组由 GA4 和百度两个平铺 Section 组成，保留启用开关、站点 ID 和既有字段错误反馈；不提供本地统计设置。

SEO 分组分为“搜索与分享”和“站长平台验证”两个平铺 Section。搜索描述使用四行 Textarea，分享图片链接与三个验证码使用单行 Input；保留可见标签、用途说明和字段错误。与其他分组共用顶部“保存所有变更”，不增加独立保存入口。

## 通知与备份管理

通知使用本地 Base UI Dialog，列表行使用 foreground 正文与 caption 辅助文字，允许长标题和备份摘要换行；筛选和批量操作的三个按钮采用共享 compact 高 36px、form 圆角 12px，窄屏或粗指针高 44px。“全部”和“未读”保留 `aria-pressed`，“本页全部已读”保留真实操作与禁用语义。通知数量或读取异常、已读与已处理状态使用清晰文字反馈，操作规则见产品行为。

通知和备份共用独立分页布局，不复用表单操作容器。桌面分页靠右，按钮与统计垂直居中，gap 12px；统计使用共享 label 字号、20px 行高、caption 文字与等宽字体，按钮使用 ghost / compact。<=600px 统计独占首行，上一页与下一页在第二行等宽排列；窄屏或粗指针按钮沿用共享 44px 高度，长统计自然换行，不造成横向溢出。

`/admin/backups` 采用连续工作区，沿用列表、Button 和 Switch，提供真实调度时间、执行记录及影响用户决策的备份范围说明。处理中状态保留可读反馈，重复提交和关闭条件由产品行为定义。执行备份时禁止重复提交，使用本地组件管理基础状态。调度机制与备份内容见部署指南。

共享 hover、active、focus-visible、disabled 和 `prefers-reduced-motion` 规则只在根设计系统维护，本文件的业务容器与浮层都须继承。深浅色、填充、边框、高光、阴影及基础组件尺寸统一采用 Semi 默认主题叠加 modern；工作台与后台使用同一套共享皮肤，不再保留旧去描边或胶囊覆盖。既有表格结构、连续工作区布局、显式场景尺寸和业务流程保持，页面不新增装饰描边。说明、计数、日期、表格辅助文字与状态小字使用共享 caption、metadata、success-text、danger-text，原始分类色及业务数据色保留其职责。
