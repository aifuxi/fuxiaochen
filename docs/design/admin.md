# 后台场景规范

本文件维护后台页面的布局、信息密度、容器职责和场景交互。共享颜色、字体、材质、基础组件状态、动效与可访问性要求以[根设计系统](../../DESIGN.md)为准；字段约束、查询、业务状态、保存条件和统计口径以[产品行为](../product/behavior.md)为准。数据库、上传及调度机制分别见[数据库维护](../maintenance.md)、[媒体存储](../media-storage.md)和[部署指南](../deployment.md)。

下列尺寸与组合延续现有后台布局。2026-10-06 已接入 Inter 与原生指针，2026-10-09 字体加载切换为 jsDelivr CDN，具体字体栈与加载方式由根设计系统维护；仪表盘字体与页面标题已运行抽查，完整业务页与编辑字号回归仍按验收记录区分范围。数值、参数和代码继续使用共享等宽字体。

2026-10-07 首次用色规范优化明确默认材质与文字 token，并允许按品牌重点、数据类别和真实状态建立视觉层次；当时仅调整规范，未修改 token 数值或页面效果，范围见[用色规范优化记录](../engineering/verification-history.md#用色规范优化2026-10-07)。后续逐页整改按本文件的场景要求实施，实际运行范围另见[历史验收记录](../engineering/verification-history.md)，未执行场景不记为通过。

后台沿用共享 Afterglow CSS SVG 指针；编辑器的 text、块手柄 grab／grabbing、禁用控件 not-allowed 保留原生语义，表格排序、菜单与媒体操作复用共享操作指针，具体规则见根设计规范。

## 容器与工作区

后台沿用共享暗色主题。文章、评论、友情链接、访客日志、媒体库与更新日志采用连续工作区；设置采用页面级 Tabs 与平铺 Section。仪表盘、分析、访客摘要、分类与标签按独立业务模块组织，不合并成一个整页数据容器。

展示 Card 用于效果舞台；后台业务 Card 默认使用 surface、24px 圆角和一层淡边线，无顶部高光，不把普通字段或说明套进舞台。连续工作区使用 14px 圆角；设置 Section 不加外卡。后台与前台沿用共享页面切换节奏，仅在路径提交后让 admin-content main 整体入场，侧栏、顶栏和页脚静止。业务 Card、表格行与字段分组不单独入场、上浮或循环；筛选、分页、刷新及轮询不触发页面动画，草稿保护与编辑器 sticky 布局保留。

| 层级     | 职责与边界                                                                         |
| -------- | ---------------------------------------------------------------------------------- |
| 页面     | 标题、必要说明与主要操作直接位于页面底色上；页首不加外卡、英文眉题或装饰标题图标。 |
| 工具栏   | 筛选和搜索与表头、数据、空状态、分页共用连续边界，不另套筛选卡。                   |
| 数据     | 表头、行和分页保持对齐，横向滚动限制在表格容器内。                                 |
| 字段分组 | 通过 Section 标题、标签对齐与留白分组；相邻开关和重复编辑项之间保留淡线。          |
| 独立模块 | 图表、运营任务和服务摘要可使用后台业务 Card；内部普通内容不套舞台。                |
| 浮层     | 业务编辑、确认与全局搜索使用本地 Base UI 控件；文章写作使用独立页面。              |

页首主要操作采用 primary；顶栏全局新建采用 secondary。分析范围、数据来源和刷新控制放在对应工作区。保留记录图像、分类色点、图表图例和操作图标，文案只说明操作、业务状态及影响管理决策的限制。

## 后台框架

桌面使用常驻固定侧栏，宽 220px，收起为 68px；导航当前项以 sRGB 中 primary 16% 与 surface 84% 混合的选中底色和 focus 文字标识。收起后，品牌 logo、导航图标、首页入口和展开按钮沿侧栏内容区中心线居中，图标左右留白相等，选中背景尺寸与颜色不变。移动端抽屉保持图标与文字的展开布局。工作台为独立入口，其余导航按内容、互动、数据、系统分组；收起时保留图标名称，分组标题供辅助技术读取。分类、备份与定时发布快捷入口跳转统一管理页面，不再提供重复业务弹窗。

普通待审核数量徽标以 sRGB 中 primary 18% 与 surface 82% 混合的淡底和 focus 文字提示待办，不作为风险告警；保留实际数量，危险色仍按共享规则表达真实错误或风险。

侧栏使用 surface，内容区和不透明 sticky 顶栏使用 background。侧栏右侧、品牌区底部、底部操作区、顶栏底部和后台页脚不画分隔线。移动抽屉同样去掉品牌与底部操作区分隔，保留浮层边缘和遮罩；由顶栏按钮打开，遮罩与关闭按钮都能退出。页面内容保持可滚动，顶栏不添加滚动监听或动态阴影。

后台壳和含数据列表的后台浮层提供局部分隔变量 `--admin-divider: color-mix(in srgb, var(--color-outline) 60%, transparent)`，不修改全局 outline。表格、连续列表、分页和重复编辑项之间使用 1px 淡线；业务 Card 标题下不画横线。图表网格、时间线、浮层边缘、焦点与错误提示保留各自所需的对比度。

普通编辑表单、分类添加和确认操作沿用共享 form 尺寸；文字确认按钮保留正常水平内边距与按文案决定的宽度，不复用图标操作的固定宽度。弹窗不统一强制所有后代按钮高 44px，内部图标或紧凑操作保留各自尺寸语义。写作栏的保存操作沿用 compact，文章设置抽屉的底部操作沿用 form，与所在操作组或单行字段同高。

顶栏搜索入口复用本地 Base UI Button，采用 InputGroup 的 input 表面、form 圆角、16px 搜索图标和 12px 左留白，无常驻描边。桌面高 36px、宽 260px，提示为 14px / 20px 的 muted 文字；快捷键为 stage 底色、outline 细边线的等宽键帽。可用空间不足时入口收缩并省略提示文字，<=600px 收为 44×44px 图标按钮，粗指针入口至少高 44px；纵向滚动条出现后仍不得造成页面横向溢出。入口悬停用 input-hover，按下用 raised，其他状态复用共享 Button。

## 数据表格与行菜单

文章、评论、友情链接、访客日志、分类和热门文章排行使用本地 TanStack Table，保留 caption、列头和带 `scope="row"` 的行标题。文章标题、评论者、友链名称与分类名称分别作为对应记录的行标题；行标题采用正文材质与排版，不继承列头的 stage 底色。可排序列头使用文字、方向箭头、`aria-sort` 和真实键盘按钮；不可排序列不显示箭头。排序及分页规则见产品行为，界面保留条数范围、当前页 / 总页数、上一页、下一页与每页条数 Select。列头使用 stage、正文单元格和行标题的分隔使用后台 divider；行悬停默认使用 surface-hover，不覆盖数据类别或状态标识。

媒体网格和更新日志时间线的分页同样显示结果范围、总条数与当前页 / 总页数，范围按当前服务端响应计算，空结果保留 `0–0`。每页数量沿用产品行为的固定值，不增加每页条数 Select。

文章六列宽度仅在本表维护，标签与摘要归入标题列。正文自然换行，表格容器内部横向滚动，分页可换行；禁止把表格最小宽度传递为页面级溢出。

有业务操作的行采用「…」按钮点击打开 Base UI Menu，不通过 hover 展开。触发按钮为 36px 圆形 ghost，打开时采用 raised；<=600px 或粗指针为 44px。菜单宽 200px、最大宽度为视口减 24px，surface 底色、24px 外圆角、1px outline 边线、6px 内边距。菜单位于按钮下方右对齐，间距 6px、边缘碰撞留白 12px，空间不足时自动翻转，Portal 避免被表格裁切。

菜单项内圆角 14px、图标 16px、文字 14px / 20px，桌面至少高 36px、触屏至少 44px。hover 与键盘高亮采用 surface-hover、按下采用 raised、删除项采用 danger；普通、审核、删除操作之间用淡线分组。菜单支持方向键、Enter、Escape 和外部点击；关闭菜单和取消弹窗后回到行按钮，触发按钮已消失时回到搜索或新增入口。行操作名称应包含对应记录的可读标识。

## 工作台与数据分析

工作台按内容指标、继续编辑、评论审核与排期、访问摘要组织。统计卡宽屏四列、窄屏两列，卡片是进入对应筛选列表的真实链接；最近三篇草稿宽屏并排、窄屏堆叠。评论与排期保留并列业务模块，空状态使用一行说明，不占大型空白卡。访问摘要只显示近 30 天 PV、UV 与阅读时长，详细趋势与来源集中在数据分析页。新建文章为页首 primary，上传、分类和备份为平铺快捷操作。长排期标题和评论自然换行。

仪表盘的评论者使用 14px / 20px、500 字重，文章与时间元数据使用 12px / 18px。排期标签通过文字区分“已排期”和“等待执行”：已排期采用 focus 文字与 sRGB 中 focus 12% / surface 88% 的淡底；等待执行采用 muted 文字与 raised 底色，两者不借成功色暗示已完成发布。

仪表盘、数据分析与访客日志的采集限制合并为一个紧凑状态区，不让每条说明独占页面网格行。状态区使用共享 surface、后台 divider 和 md 圆角，桌面内边距上下 16px、左右 20px，图标、内容、操作间距 12px；标题 14px / 20px、500 字重，说明 13px / 20px，数据起点 12px / 18px、时间使用等宽字体。关闭采集、当前环境不采集与区间覆盖不足按实际状态组合，数据起点保留北京时间；正常采集且覆盖完整时不显示。采集关闭或当前环境不采集时提供 secondary / compact 的“统计设置”真实链接，直接进入访问统计分组。<=600px 内边距 16px，操作移至内容下方并保留共享 44px 点击高度，文字自然换行。状态区无装饰动画，加载和失败仍使用独立查询反馈。

图表范围使用本地紧凑 Tabs，图表和进度条默认沿用 primary、success 和 muted，可使用现有共享 token 为实际系列或数据类别建立稳定的颜色映射。图例与系列对应，同一类别跨查询区间保持一致；danger 用于实际警示，不把一般数据类别或波动表达为告警。颜色服务于信息区分，不新增场景颜色 token。查询区间、数据来源及产品定义的缺失、错误和关闭采集状态须有可读文字。图表数据点为实际按钮，支持鼠标、触屏和键盘焦点；窄屏或粗指针通过后台作用域变量 `--admin-chart-touch` 扩展图表宽度，保证每个目标至少 44px，仅图表容器横向滚动。

数据分析页标题为“数据分析”；时间范围与当前区间同列，空间不足时换行，随后连接指标和独立图表模块。统计卡宽屏四列、窄屏两列；双指标趋势与设备分布宽屏约 2:1，窄屏堆叠。PV 默认使用 primary 实线，UV 默认使用 success 虚线，图例同时显示对应线型与文字，数值相等或全为零时仍可区分两条系列；平板比例默认使用 muted，设备类别可按上述稳定映射区分。改善方向默认使用 success，持平、不可比较和普通不利环比使用 muted，持平不附上升或下降箭头；允许通过 foreground 对比、字重或适度强调提高辨识，不强制使用红色、不新增告警状态。区间、统计口径、环比和查询数据点的必要说明使用 12px / 18px 的 muted 文字，保留真实方向、数值与周期去重说明。

折线图保持比例，数据点提示显示日期与双指标数值；设备比例直接展示，不加重复建议舞台。排行榜使用语义化表格和淡行线，排名默认使用 stage 底色与 muted 文字的胶囊；前三名使用 focus 文字与 sRGB 中 focus 12% / surface 88% 的淡底形成层次，完读率采用 success。数值用等宽字体，零值和单点趋势仍保持有限坐标。数据指标、范围、去重及提示内容见产品行为。

## 文章列表与写作工作区

文章列表复用后台框架，页首放“文章管理”、简短说明和新建操作。状态 Tabs、分类 Select、精选 Select 与关键词 Input 组成工具栏，直接连接表头、行和分页；不增加独立筛选卡或额外面板留白。桌面控件并排，空间不足时换行；390px 下状态栏局部横向滚动，筛选控件纵向排列。

标题自然换行，空标题使用“未命名草稿”、空分类使用“未分类”；摘要预览一行，标签留在标题列。状态同时使用文字和明确颜色：已发布使用 success、排期使用 focus、草稿默认使用 muted，精选使用文字标记。行操作菜单提供包含文章标题的可读名称，空状态保留重置筛选或创建入口。文章访问表现由数据分析页承载，不挤入文章表格。

新建和编辑使用独立文章页，继续高亮文章管理导航。写作页默认保留后台框架，不重复页标题、说明与底部操作区。sticky 写作栏位于后台顶栏下方，background 底色、最小高度 56px、控件间距 12px，放返回、保存状态、文章设置、专注模式和保存按钮；写作栏所有按钮使用 compact，桌面高 36px，文章设置抽屉的底部操作使用 form，桌面高 40px，与单行字段同高；<=600px 或粗指针时两组操作均高 44px。窄屏操作可换行，状态与按钮不能撑宽页面。专注模式隐藏侧栏、全局顶栏和页脚，写作栏贴顶，退出时恢复布局；模式的初始化规则见产品行为。

标题和正文构成居中、最大宽度 960px 的连续画布。标题采用共享 display 字体，桌面 32px / 44px、手机 28px / 40px，自动增高、无常驻边框和填充，保留可访问标签及清晰焦点。标题输入是普通表单表面的显式例外：保持透明背景、无圆角，错误采用 2px danger 直线底标记，hover、active 和 focus 不清除该标记；focus-visible 保留 2px focus 外轮廓与原有 4px 外距，与错误底标记共存。错误属性移除后恢复当前正常状态。正文引用[共用文章正文排版](../../DESIGN.md#共用文章正文排版)，与前台共用相对字号、标题、列表、块间距及正文颜色层级，普通正文使用 foreground-reading，无外卡底色、圆角、边框或装饰高光；工具条和字符状态仅保留后台 divider。正文通过文本插入光标表达聚焦，不增加焦点边框或高亮分隔线；标题和工具条按钮保留键盘焦点提示。正文错误使用工具条下方 danger 指示线及关联字段文字，关联实际 contenteditable。块左侧保留手柄空间，窄屏不产生页面横向溢出。

文章设置收纳产品定义的字段。内容区可用宽度至少 1100px 时采用 320px 右侧面板、间距 24px；更窄时用 Base UI Dialog 右侧抽屉，宽 360px、不超过视口宽度，高不超过 100dvh，内容独立滚动。抽屉提供关闭和保存；关闭后焦点回到文章设置按钮，不使用入场位移。摘要采用 Textarea 并显示字符计数，精选采用 Switch，排序采用数字 Input；字段约束与禁用条件只在产品行为维护。

文章状态保留原生 radio 的分组、键盘选择与禁用语义；<=600px 或粗指针时，包含 radio 与状态文字的整个 label 点击目标至少 44×44px。

设置入口用“待完善”或“有错误”表达隐藏字段状态；校验错误时打开对应面板并定位首个相关字段，标题与正文错误留在画布内。写作栏以可读文字表达未保存、保存中和已保存。保存及重新载入规则见产品行为，视觉核对必须检查光标、滚动和撤销历史不因布局或状态反馈被清空。

### 块编辑器

代码块使用 input 底色、1px outline 边线、8px 圆角和 16px 内边距，代码字号与块间距引用共用正文规则，长代码仅在块内横向滚动。顶部工具栏常驻，语言位于左侧、复制操作位于右侧，不随代码横向滚动；使用 muted 文字与 outline 底边线。语言控件为本地 Base UI Select，桌面高 32px、窄屏或粗指针至少 44px；语法高亮复用共享 syntax token，颜色只作用于代码区。

正文表格的字号、段落与容器上下间距引用共用正文规则，滚动容器提供 1px outline 外框与 8px 圆角裁切；单元格保留折叠边线，表格自身隐藏外边线，避免双重边框。表头底色和内容随容器圆角裁切，仅在容器内横向滚动。前台正文的场景圆角另见[前台规范](frontend.md)。

格式菜单、链接和素材选择使用本地 Base UI Popover、Dialog。斜线菜单不夺取正文输入焦点，以 listbox、`aria-activedescendant` 和文字提示表达选择，支持方向键、Enter、Escape，并保留中文输入法组合输入的处理要求。选中文字出现浮动格式栏；块手柄支持拖拽，同时提供复制、删除、上移和下移的键盘与触屏入口。工具条只在自身范围内横向滚动，触屏目标至少 44px，图片替代文字具有可见输入入口。

Markdown 导入 Dialog 使用 surface、24px 圆角、24px 内边距，最大宽 640px、最大高 88dvh，内容内部滚动，输入与提交操作复用共享 form 尺寸，窄屏或粗指针目标至少 44px。关闭后焦点回到正文。导入格式、大小、插入规则及保存条件见产品行为；复制结果以可访问状态文字反馈。

链接与图片选择 Dialog 的字段标签在输入框上方，采用共享 label 字号、muted、20px 行高，标签与控件间距8px，字段上下间距16px；输入框占满字段宽度。图片选择的加载与空结果说明沿用同一辅助文字排版。图片分页居中排列，gap16px；页码使用13px label字号、20px行高、muted和等宽字体，与compact按钮垂直居中，窄屏或粗指针按钮沿用44px目标。页码保留完整可访问名称与状态更新，翻页行为见产品行为。

图片选择工具栏在窄屏或粗指针条件下纵向排列，搜索输入不伸缩，保留共享form高度44px，上传按钮同高；不能将桌面横向伸展的flex规则沿用为纵向高度分配。

## 评论管理

页首直接展示标题和简短说明。状态 Tabs 与关键词 Input 连接表格、分页，共用 14px 连续工作区；不另套筛选卡或列表卡。桌面筛选并排，空间不足时换行；窄屏标签局部横向滚动、搜索占满宽度。工具栏密度沿用基线。

评论者使用 32px 首字头像与邮箱，首字头像默认使用 raised 底色与 muted 文字，博主回复采用品牌头像。正文与评论者使用 14px / 20px，文章、时间和邮箱使用 12px / 18px；正文自然换行，评论内容和时间独立成列。审核状态通过文字和小圆点共同表达：通过用 success、拒绝用 danger、待审核默认用 muted。回复对象与管理员身份单独标明。

回复 Dialog 展示原评论、文章和带可见标签的 Textarea。字段错误就近关联，产品定义的冲突或失败反馈不能遮住输入。回复关闭或删除取消后焦点返回触发按钮，按钮消失时回到搜索框；删除完成后回到搜索框。

## 媒体库

页首放媒体资产库标题、必要说明和上传入口。搜索、类型 Select、结果数量、网格、反馈和分页共用连续工作区；工具栏底部以后台 divider 连接结果区。搜索宽 300px、窄屏占满宽度，窄屏上传入口占满宽度。清空搜索后焦点回到输入框，空状态保留清空搜索与上传入口。

素材网格宽屏四列、中屏两至三列、390px 单列，内边距和 gap 均为 16px。素材单元 24px 圆角、缩略图 14px 圆角；去掉素材单元轮廓阴影、缩略图内边线和时间操作区横线。缩略图 stage 底色、高约 176px，随后显示文件名、分辨率与体积、时间和删除操作；长文件名自然换行。预览与复制按钮在 hover 或 focus-within 时出现，触屏常显；减少动态效果时取消图片缩放。

预览与删除确认使用本地 Base UI Dialog。图片完整显示并附体积、分辨率、时间和格式，附件显示文件图标与下载操作；格式许可和下载条件见产品行为。上传队列用后台 divider 淡分隔，逐文件进度采用语义化 progress 和可读状态文字；后台切换与处理中状态的业务要求见产品行为。删除与查询错误各有独立反馈位置，不把成功写入后的刷新错误呈现为写入失败。

## 分类与标签

宽屏采用分类、标签双列业务 Card，窄屏纵向排列，标题使用简短名称与数量徽标，徽标默认使用 raised 底色与 muted 文字。分类包含可见名称标签、颜色选择、添加入口和紧凑语义化表格；标签包含输入、添加入口及直接平铺、可换行的胶囊标签云。标签云无内层容器、底色或边缘，标签胶囊保留 raised 填充、无描边，不设置人为最小高度。

分类颜色是用户数据，可用于该分类的色点、文字或淡底标识，不改变全局主题、不覆盖控件的焦点、错误等状态色。颜色控件使用 input 表面、form 圆角和清晰焦点，宽高共用 form 尺寸，与名称输入和添加按钮同排对齐；选择、筛选和确认使用现有 Select、Combobox、Dialog 与 Button，基础状态与视觉 token 遵循共享定义。长名称自然换行，390px 不产生页面级横向溢出。分类行操作提供编辑与删除；编辑 Dialog 复用名称 Input、ColorInput 和表单按钮，提交中禁用关闭与重复保存，失败保留输入，关闭后焦点回到行操作。删除取消后回到触发按钮，完成后回到新增分类输入；移除标签后聚焦相邻移除按钮或新增标签输入。

## 访客日志

页首提供采集口径说明。三项摘要采用独立 24px 业务 Card，宽屏三列、窄屏单列，保留数量与业务说明，去掉装饰图标舞台。更新状态、暂停 / 恢复与搜索连接连续数据表格和分页；旧快照及加载、采集关闭、空集合、无匹配等产品状态须有可读反馈。

无搜索词的空记录说明与上方采集状态一致：关闭采集时提供设置引导；采集开启但当前环境不采集时说明历史记录仍可查询；正常采集时说明尚无记录。关键词无匹配时提供调整关键词与清空搜索，只有存在搜索词时才显示清空操作，不把已开启的采集误写成待启用。

表格采用 stage 表头、后台 divider、surface-hover 行反馈，列宽见通用表格。正文 14px / 20px，系统信息和停留时长 12px / 18px；长路径和地域自然换行。IP 使用 focus，停留时长默认使用 raised 底色与 muted 文字的胶囊，数值与路径用等宽字体。状态点不循环动画；清空搜索保持输入焦点，390px 仅表格容器横向滚动。采集、轮询、脱敏和时间口径见产品行为。

友情链接使用连续工作区，分类、审核、展示状态和关键词排列于工具栏，390px 纵向排列。图标 36px，图片失败显示 Link2。审核状态保留文字，通过用 success、拒绝用 danger、待审核默认用 muted，展示开关独立显示文字。表单使用可见字段标签与本地控件，删除取消回到触发按钮，成功回到搜索框；列宽及目标尺寸沿用通用表格。

## 系统设置

资料与站点、SEO、系统偏好、备案、社交账号、访问统计使用页面级 Base UI Tabs。字段和 Section 尺寸沿用基线，390px 标签栏局部横向滚动；重新载入作为分组旁的 ghost 次要操作。字段错误切换到对应分组，在面板已挂载、控件可用后聚焦，不以隐藏分组掩盖错误。社交账号整体约束错误关联组标题并聚焦该标题，具体账号字段错误仍定位到对应输入；错误定位不能依赖可能禁用的新增按钮。

SEO 分组分为“搜索与分享”和“站长平台验证”两个平铺 Section。搜索描述使用四行 Textarea，分享图片链接与三个验证码使用单行 Input；保留可见标签、用途说明和字段错误。与其他分组共用顶部“保存所有变更”，不增加独立保存入口。

社交账号编辑项直接平铺，仅相邻条目之间用后台 divider，无独立装饰卡。排序与删除有可读名称，操作后聚焦相邻条目或新增按钮，图片失败显示通用图标。业务说明应与实际前台行为一致，不出现未接入的 AI 服务、开发信息或自动备份占位项；备份入口由独立备份管理页承载。

## 全局检索、通知与备份管理

检索和通知使用本地 Base UI Dialog，列表行默认使用 foreground 正文与 muted 辅助文字，允许长标题、评论摘要和备份摘要换行。范围筛选采用带 `aria-pressed` 的紧凑按钮。通知数量或读取异常、已读与已处理状态使用清晰文字反馈，具体范围和操作规则见产品行为。

检索、通知和备份共用独立分页布局，不复用表单操作容器。桌面分页靠右，按钮与统计垂直居中，gap 12px；统计使用共享 label 字号、20px 行高、muted 文字与等宽字体，按钮使用 ghost / compact。<=600px 统计独占首行，上一页与下一页在第二行等宽排列；窄屏或粗指针按钮沿用共享 44px 高度，长统计自然换行，不造成横向溢出。

`/admin/backups` 采用连续工作区，沿用列表、Button 和 Switch，提供真实调度时间、执行记录及影响用户决策的备份范围说明。处理中状态保留可读反馈，重复提交和关闭条件由产品行为定义。执行备份时禁止重复提交，使用本地组件管理基础状态。调度机制与备份内容见部署指南。

## 场景核对

共享 hover、active、focus-visible、disabled 和 `prefers-reduced-motion` 规则只在根设计系统维护，本文件的业务容器与浮层都须继承。所有操作图标有可读名称，字段有可见标签，错误与字段关联；不能只靠颜色、动画、图标或截图证明状态正确。

视觉核对固定为 1440×1000、390×844，浏览器缩放 100%。记录路由、数据快照、筛选条件、侧栏状态、滚动位置和截图范围；等待字体、图片、布局及动画稳定，对照使用相同条件。字号、行高、内边距和最大宽度用 computed style 核对，设备密度未知的参考图像素不能直接作为 CSS 尺寸，也不以固定高度裁切内容。

核对 900 / 901px、600 / 601px 的布局交界，桌面侧栏展开 / 收起、移动抽屉关闭、sticky 顶栏、全局搜索收缩，以及表格、图表、标签和编辑工具条的局部滚动。分别检查长标题、长文件名、空集合、无匹配和字段错误；触屏检查真实 44px 目标。使用已有数据或隔离临时数据，不为填满截图向常用数据库写演示记录。

筛选、排序、分页回退、保存各分组、隐藏字段定位、失败草稿、版本冲突、删除确认及浮层关闭后的焦点恢复需独立验证。文章另核对专注模式恢复、设置面板 / 抽屉切换、保存后的光标 / 滚动 / 撤销保留、斜线菜单键盘和中文输入法、块操作的触屏入口。媒体另核对触屏常显操作、进度语义与切页后的反馈。访客另核对旧快照与暂停状态反馈。

截图只支持已观察的视觉状态。基础状态、粗指针与系统减少动态效果偏好区分源码检查和运行验证；未执行场景不记为通过。历史结果与未验证范围见[历史验收记录](../engineering/verification-history.md)，本轮实现与验证见[后台首轮调整验收](../engineering/admin-first-pass-verification.md)，不把历史截图或演示数据当作当前规范。
