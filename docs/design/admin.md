# 后台场景规范

本文件维护后台页面的布局、信息密度、容器职责和场景交互。共享颜色、字体、材质、基础组件状态、动效与可访问性要求以[根设计系统](../../DESIGN.md)为准；字段约束、查询、业务状态、保存条件和统计口径以[产品行为](../product/behavior.md)为准。数据库、上传及调度机制分别见[数据库维护](../maintenance.md)、[媒体存储](../media-storage.md)和[部署指南](../deployment.md)。

下列尺寸与组合延续现有后台布局。2026-10-06 已接入共享无衬线字体与原生指针，2026-10-09 字体加载切换为 jsDelivr CDN，2026-10-15 字体统一更新为 Source Sans Pro。具体字体栈与加载方式由根设计系统维护；仪表盘字体与页面标题的历次运行抽查、完整业务页与编辑字号回归仍按验收记录区分范围。数值、参数和代码继续使用共享等宽字体。

2026-10-07 首次用色规范优化明确默认材质与文字 token，并允许按品牌重点、数据类别和真实状态建立视觉层次；当时仅调整规范，未修改 token 数值或页面效果，范围见[用色规范优化记录](../engineering/verification-history.md#用色规范优化2026-10-07)。后续逐页整改按本文件的场景要求实施，实际运行范围另见[历史验收记录](../engineering/verification-history.md)，未执行场景不记为通过。

历史记录：2026-10-15 用户授权将后台色盘与基础组件视觉统一为 Semi UI Vue 默认主题叠加 modern；边框、高光、阴影、圆角和完整状态由根设计系统维护。Base UI 行为、后台布局及业务流程保留；显式的 Dock、写作工具、分页与触屏目标尺寸继续按场景声明，普通 form / compact 控件引用新的共享尺寸。历史验收不代表本轮迁移已运行通过。

2026-10-16 用户明确恢复普通桌面表单与按钮 40px、compact 工具栏 36px、form 圆角 12px，窄屏与粗指针保持 44px；配色、边框、高光和状态继续采用 Semi default + modern。Dock、分页、写作工具的显式尺寸以及 Card、弹层、菜单和 Switch 保持既有约定，不因共享表单密度变化扩大。

后台沿用共享 Afterglow CSS SVG 指针；编辑器的 text、块手柄 grab／grabbing、禁用控件 not-allowed 保留原生语义，表格排序、菜单与媒体操作复用共享操作指针，具体规则见根设计规范。

## 2026-10-16 预览方案正式接入

文章与友链采用开放列表，分类采用顶部 Tabs 与紧凑分类块，日志通过留白区分条目，备份采用三个业务 Card 与开放执行记录；设置分组、两段 Dock 和真实 Tiptap 编辑器的字段分组同步调整。各页的具体布局与通用表格例外在对应章节声明，不把预览的示例数据或模拟操作作为正式行为。

[独立预览验证记录](../engineering/admin-preview-verification.md#第二版布局重做2026-10-16)保留方案演进历史。正式接入的源码、运行证据及本轮未验证范围见[后台预览方案实施验证](../engineering/admin-preview-rollout-verification.md)。已实现不等于全部业务场景均已运行通过。

## 容器与工作区

后台沿用共享深浅主题，默认深色；模式偏好由 [DESIGN.md](../../DESIGN.md#深浅模式) 统一维护。文章、友情链接、分类与更新日志采用连续工作区；分类与标签通过顶部 Tabs 切换全宽内容，设置采用分组 Tabs 与平铺 Section。备份摘要、自动备份和范围说明各自使用独立业务 Card。

展示 Card 用于效果舞台；后台业务 Card 使用共享 Card 的 surface、md 圆角、边框与 modern 边缘材质，不把普通字段或说明套进舞台。连续工作区保留既有 14px 圆角与连续布局；设置 Section 不加外卡。后台与前台沿用共享页面切换节奏，仅在路径提交后让 admin-content main 整体入场，Dock 和页脚静止。业务 Card、表格行与字段分组不单独入场、上浮或循环；筛选、追加、翻页、刷新及轮询不触发页面动画，草稿保护与编辑器 sticky 布局保留。

| 层级     | 职责与边界                                                                                 |
| -------- | ------------------------------------------------------------------------------------------ |
| 页面     | 标题、必要说明与主要操作直接位于页面底色上；页首不加外卡、英文眉题或装饰标题图标。         |
| 工具栏   | 筛选、搜索与数据、空状态、条件追加共用连续边界，不另套筛选卡；保留表格的场景继续连接表头。 |
| 数据     | 开放列表通过留白组织条目；保留表格的场景将表头、行和分页对齐，横向滚动限制在自身容器内。   |
| 字段分组 | 通过 Section 标题、标签对齐与留白分组；相邻开关和重复编辑项之间保留淡线。                  |
| 独立模块 | 运营任务和服务摘要可使用后台业务 Card；内部普通内容不套舞台。                              |
| 浮层     | 业务编辑、确认与通知使用本地 Base UI 控件；文章写作使用独立页面。                          |

页首主要操作采用 primary，新建文章只保留在文章页面内。筛选与刷新控制放在对应工作区。保留记录图像、分类色点和操作图标，文案只说明操作、业务状态及影响管理决策的限制。

## 后台框架

桌面导航使用左侧居中的悬浮 Dock，宽 72px、距视口左侧 16px，内容列为导航预留 104px。Dock 拆为业务导航与全局操作两段胶囊，段间 12px；每段独立使用共享 surface、lg 圆角与 popup 阴影，段间保持透明。支持 backdrop-filter 时采用 surface 90% 与透明混合底色及 16px 模糊，其他环境以及 `prefers-reduced-transparency: reduce` 使用不透明 surface。不新增装饰分割线、自动隐藏、图标放大、弹跳或位移反馈；承载共享浮层阴影时保留其中的 modern 边缘效果。高度随内容，最大为视口高度减 32px，矮视口内部可滚动，保持所有入口可达。

Dock 顶部使用共享 FC 内联 SVG logo，显示尺寸 32×32px，透明背景并继承前景色；Logo 同时作为首页链接，完整名称供辅助技术读取，不再单列桌面首页图标。导航沿用内容、互动、系统分组，组名桌面隐藏、移动端显示，桌面以 12px 组间留白区分。导航与首页入口为 44×44px、md 圆角，业务入口由 20px 图标和 12px/18px 短名称组成；组内间距 4px。当前项以 sRGB 中 primary 16% 与 surface 84% 混合的底色及 focus-text 图标标识，并提供 aria-current。新建与编辑文章仍高亮文章管理。移除展开／收起按钮及其状态，不再提供宽侧栏。

桌面图标悬停 250ms 或键盘聚焦时，名称通过本地 Base UI Tooltip 显示在右侧；相邻提示复用 Provider 的即时切换，Escape、移出、失焦或点击关闭。名称始终通过 aria-label 提供，不依赖提示才能理解；导航保留真实链接、Tab／Enter 和未保存保护。hover、active、focus-visible、disabled 与减少动态效果沿用共享规则，图标与点击区域尺寸始终固定。首页入口与业务入口以留白区分，分类和备份继续跳转各自管理页。

<=900px 隐藏 Dock 和内容预留，由左下角 44×44px 的悬浮导航按钮打开文字抽屉。入口距视口左、下各至少 16px，并避开安全区；页脚底部预留 80px 加安全区，避免挡住末尾操作。抽屉内提供相同的主题、通知与账户操作，显示文字；这些文字 utility 按钮使用共享 form 圆角 12px、至少 44px 高的移动目标，桌面 Dock 的 44×44px、md 圆角 16px 仍为独立场景。长内容可在抽屉内部滚动。抽屉内 logo 32×32px、业务图标 18px，品牌名与分组名可见，关闭按钮、遮罩和导航成功后都能关闭。品牌 SVG 使用 aria-hidden 与 focusable=false，不单独成为焦点目标。抽屉保留浮层边缘和遮罩，品牌与底部操作区不画分隔线。

后台不再渲染顶部栏或保留顶部占位，内容区直接从页面内边距开始，使用 background。主题切换、通知与账户菜单统一放在 Dock 下部，按钮与导航同为固定 44×44px；账户显示圆形头像，通知只在有未读、数量未知或读取失败时显示角标，完整数量与错误说明通过可访问名称和 Tooltip 提供。新建文章只保留文章页面内的按钮。Dock、按钮、名称提示和弹窗随全站模式切换，切换不改变筛选、浮层、草稿、专注模式、光标、滚动或撤销历史；页脚不画分隔线。

通知与账户使用既有业务 Dialog，关闭后焦点回到对应 Dock 入口；从手机抽屉打开时，先关闭抽屉，再打开业务 Dialog，关闭后回到悬浮导航按钮，不向已隐藏的抽屉控件回焦。

后台壳和含数据列表的后台浮层提供局部分隔变量 `--admin-divider: color-mix(in srgb, var(--color-outline) 60%, transparent)`，不修改全局 outline。保留表格、通知分页和重复编辑项的场景使用 1px 淡线；本轮文章、友链、分类、日志与备份记录是显式例外，不添加工具栏底线或条目分割线。业务 Card 标题下不画横线；浮层边缘、焦点与错误提示保留各自所需的对比度。

工具栏和页面操作通过 compact 语义选择共享尺寸，复用本地 Button、TabsList、SelectTrigger 与 InputGroup 的 `size="compact"`。设置 Switch 使用 `touchTarget`，视觉轨道采用 Semi 默认尺寸与状态，真实按钮目标保留 44×44px。单元格不固定高度，不裁剪中文长标题，触屏目标不随视觉密度压缩。

普通编辑表单、分类添加和确认操作沿用共享 form 尺寸；文字确认按钮保留正常水平内边距与按文案决定的宽度，不复用图标操作的固定宽度。弹窗不统一强制所有后代按钮高 44px，内部图标或紧凑操作保留各自尺寸语义。写作栏的保存操作沿用 compact，文章设置抽屉的底部操作沿用 form，与所在操作组或单行字段同高。

Dock 中的主题切换提供目标模式的可访问名称，沿用共享 ThemeToggle，支持键盘、可见焦点和名称提示，不改变原有全站偏好与同步机制。

## 开放列表、数据表格与行菜单

文章、友情链接、分类、更新日志与备份记录使用语义列表，是通用表格构图的显式例外：不显示表头、条目横线或常驻页码；可调整的排序使用具名 Select，日志保留服务端固定排序。分类继续用本地 TanStack 排序模型；文章、友链、日志和备份对完整服务端结果排序后按批读取。存在后续批次时显示追加入口，追加后聚焦首条新记录并播报已显示数量；失败保留已加载结果并提供重试。批次规则和旧页码深链见产品行为。

仍使用表格的其他场景继续使用本地 TanStack Table 与可访问表格语义，保留 caption、列头和带 `scope="row"` 的行标题。行标题采用正文材质与排版，不继承列头的 stage 底色。可排序列头使用文字、方向箭头、`aria-sort` 和真实键盘按钮，排序按钮引用共享 form 圆角 12px；不可排序列不显示箭头。列头使用 stage，正文单元格与行标题的分隔使用后台 divider；行悬停使用 surface-hover，不覆盖数据类别或状态标识。表格自身可按业务保留条数范围、当前页／总页数、上一页、下一页与每页条数 Select。

表格单元格上下 12px、左右 16px，正文自然换行；最小宽度和列宽由具体业务声明，不将历史文章 850px、友链 960px 的最小宽度应用于当前开放列表。横向滚动限制在表格容器内，分页允许换行，禁止造成页面级溢出。

有业务操作的行采用「…」按钮点击打开 Base UI Menu，不通过 hover 展开。触发按钮为 36px 圆形 ghost，打开时采用 raised；<=600px 或粗指针为 44px。菜单宽 200px、最大宽度为视口减 24px，表面、md 圆角、边缘、投影与内边距引用共享 Menu。菜单位于按钮下方右对齐，间距 6px、边缘碰撞留白 12px，空间不足时自动翻转，Portal 避免被表格裁切。

菜单项图标 16px、文字 14px / 20px，圆角、填充、默认与危险操作状态引用共享 Menu，触屏至少高 44px；普通、审核、删除操作之间用淡线分组。菜单支持方向键、Enter、Escape 和外部点击；关闭菜单和取消弹窗后回到行按钮，触发按钮已消失时回到搜索或新增入口。行操作名称应包含对应记录的可读标识。

## 后台入口

后台不再提供工作台页面与导航项。登录后直接进入文章管理 `/admin/posts`；旧地址 `/admin` 在服务端鉴权后重定向至文章管理。文章状态数量与草稿入口保留在文章列表，分类与备份通过侧栏访问，新建文章仅使用文章页面内的入口。

## 文章列表与写作工作区

文章列表复用后台框架，页首放“文章管理”、简短说明和新建操作。所有宽度都使用顶部横向状态 Tabs，右侧显示真实筛选结果数；下一行承载关键词、分类、精选、排序与每次加载条数选择，随后为全宽开放列表。不使用局部侧栏、表头、工具栏底线、条目横线或常驻分页。桌面控件并排，空间不足时换行；<=600px 状态栏局部横向滚动，重复结果数隐藏，筛选控件纵向排列。

标题自然换行，空标题使用“未命名草稿”、空分类使用“未分类”；条目间距 24px，标题 16px/24px、摘要 14px/20px、元信息 12px/18px；分类、标签和日期作为元信息，行末保留操作菜单。状态同时使用文字和明确颜色：已发布图标与标记使用 success、状态小字使用 success-text，草稿必要说明使用 caption，精选使用文字标记。行操作菜单提供包含文章标题的可读名称，空状态保留重置筛选或创建入口。

新建和编辑文章使用独立文档工作区，进入 `/admin/posts/new` 或文章编辑地址即隐藏 Dock、手机悬浮导航与页脚，离开后恢复；不调用浏览器全屏。顶部写作栏 sticky top 0、最小高 64px，左右内边距 24px，承载返回、真实标题、保存状态、主题切换、更多操作、文章设置与保存。保留共享 compact 36px 按钮，窄屏与粗指针至少 44px。空标题显示“未命名草稿”，尚未创建显示“新草稿”；保存状态来自真实输入和请求。

文档主体为 200px 目录与最大 820px 正文两列，列间距 32px，整体最大 1100px，左右内边距 24px、距写作栏 48px。目录 sticky top 96px，可独立滚动，按 H1–H6 缩进，每级 12px；当前章节使用 primary，并提供可读当前项语义。可用视口不超过 1100px 时隐藏目录列，通过写作栏按钮打开 Base UI 目录抽屉。目录不修改正文或路由历史。文章设置在所有宽度统一使用右侧 360px 抽屉，保留三组真实字段、关闭与保存、错误定位及关闭回焦。

## 场景核对

共享 hover、active、focus-visible、disabled 和 `prefers-reduced-motion` 规则只在根设计系统维护，本文件的业务容器与浮层都须继承。深浅色、填充、边框、高光、阴影及基础组件尺寸统一采用 Semi 默认主题叠加 modern；工作台与后台使用同一套共享皮肤，不再保留旧去描边或胶囊覆盖。通用表格基础继续适用于保留表格的场景；文章、友链、分类、日志与备份采用本轮开放列表例外。显式场景尺寸、真实业务流程和共享状态保持，页面不新增装饰描边。说明、计数、日期、表格辅助文字与状态小字使用共享 caption、metadata、success-text、danger-text，原始分类色及业务数据色保留其职责。
