# 后台场景规范

本文件维护后台页面的布局、信息密度、容器职责和场景交互。共享颜色、字体、材质、基础组件状态、动效与可访问性要求以[根设计系统](../../DESIGN.md)为准；字段约束、查询、业务状态、保存条件和统计口径以[产品行为](../product/behavior.md)为准。数据库、上传及调度机制分别见[数据库维护](../maintenance.md)、[媒体存储](../media-storage.md)和[部署指南](../deployment.md)。

下列尺寸与组合延续现有后台布局。2026-10-06 已在根布局接入本地 Inter 与原生指针，具体字体栈由根设计系统维护；仪表盘字体与页面标题已运行抽查，完整业务页与编辑字号回归仍按验收记录区分范围。数值、参数和代码继续使用共享等宽字体。

## 容器与工作区

后台沿用共享暗色主题。文章、评论、友情链接、访客日志、媒体库与更新日志采用连续工作区；设置采用页面级 Tabs 与平铺 Section。仪表盘、分析、访客摘要、分类与标签按独立业务模块组织，不合并成一个整页数据容器。

展示 Card 用于效果舞台；后台业务 Card 使用中性表面、24px 圆角和一层淡边线，无顶部高光，不把普通字段或说明套进舞台。连续工作区使用 14px 圆角；设置 Section 不加外卡。后台工作区和业务 Card 不使用入场、上浮或持续装饰动画。

| 层级     | 职责与边界                                                                         |
| -------- | ---------------------------------------------------------------------------------- |
| 页面     | 标题、必要说明与主要操作直接位于页面底色上；页首不加外卡、英文眉题或装饰标题图标。 |
| 工具栏   | 筛选和搜索与表头、数据、空状态、分页共用连续边界，不另套筛选卡。                   |
| 数据     | 表头、行和分页保持对齐，横向滚动限制在表格容器内。                                 |
| 字段分组 | 通过 Section 标题、标签对齐与留白分组；相邻开关和重复编辑项之间保留淡线。          |
| 独立模块 | 图表、运营任务和服务摘要可使用后台业务 Card；内部普通内容不套舞台。                |
| 浮层     | 业务编辑、确认与全局搜索使用本地 Base UI 控件；文章写作使用独立页面。              |

页首主要操作采用 primary；顶栏全局新建采用 secondary。分析范围、数据来源和刷新控制放在对应工作区。保留记录图像、分类色点、图表图例和操作图标，文案只说明操作、业务状态及影响管理决策的限制。

## 后台框架

桌面使用常驻固定侧栏，宽 220px，收起为 68px；导航当前项以少量 primary 和中性提亮标识。收起后，品牌 logo、导航图标、首页入口和展开按钮沿侧栏内容区中心线居中，图标左右留白相等，选中背景尺寸与颜色不变。移动端抽屉保持图标与文字的展开布局。

侧栏使用 surface，内容区和不透明 sticky 顶栏使用 background。侧栏右侧、品牌区底部、底部操作区、顶栏底部和后台页脚不画分隔线。移动抽屉同样去掉品牌与底部操作区分隔，保留浮层边缘和遮罩；由顶栏按钮打开，遮罩与关闭按钮都能退出。页面内容保持可滚动，顶栏不添加滚动监听或动态阴影。

后台壳和含数据列表的后台浮层提供局部分隔变量 `--admin-divider: color-mix(in srgb, var(--color-outline) 60%, transparent)`，不修改全局 outline。表格、连续列表、分页和重复编辑项之间使用 1px 淡线；业务 Card 标题下不画横线。图表网格、时间线、浮层边缘、焦点与错误提示保留各自所需的对比度。

紧凑尺寸只用于后台工具栏和页面操作，复用本地 Button、TabsList、SelectTrigger 与 InputGroup 的 `size="compact"`。设置 Switch 使用 `touchTarget`，视觉轨道保持 44×24px，真实按钮目标为 44×44px。单元格不固定高度，不裁剪中文长标题，触屏目标不随视觉密度压缩。

普通编辑表单、分类添加和确认操作沿用共享 form 尺寸；弹窗不统一强制所有后代按钮高 44px，内部图标或紧凑操作保留各自尺寸语义。写作栏的保存操作沿用 compact，文章设置抽屉的底部操作沿用 form，与所在操作组或单行字段同高。

顶栏搜索入口复用本地 Base UI Button，采用 InputGroup 的 input 表面、form 圆角、16px 搜索图标和 12px 左留白，无常驻描边。桌面高 36px、宽 260px，提示为 14px / 20px 的 muted 文字；快捷键为 stage 底色、中性细边线的等宽键帽。可用空间不足时入口收缩并省略提示文字，<=600px 收为 44×44px 图标按钮，粗指针入口至少高 44px；纵向滚动条出现后仍不得造成页面横向溢出。入口悬停用 input-hover，按下用 raised，其他状态复用共享 Button。

## 数据表格与行菜单

文章、评论、友情链接、访客日志、分类和热门文章排行使用本地 TanStack Table，保留 caption、表头和行标题。可排序表头使用文字、方向箭头、`aria-sort` 和真实键盘按钮；不可排序列不显示箭头。排序及分页规则见产品行为，界面保留条数范围、当前页 / 总页数、上一页、下一页与每页条数 Select。表头使用 stage、行分隔使用后台 divider；行悬停仅提亮中性表面。

| 表格               | 最小宽度     | 列顺序与宽度                                                                 |
| ------------------ | ------------ | ---------------------------------------------------------------------------- |
| 文章               | 850px        | 标题与摘要及标签 38%、分类 12%、状态 10%、精选 12%、时间 18%、操作 10%       |
| 评论               | 960px        | 评论者 22%、评论内容 40%、状态 10%、时间 20%、操作 8%                        |
| 友情链接           | 960px        | 站点信息 32%、链接与简介 34%、分类 12%、审核与展示状态 14%、操作 8%          |
| 访客日志           | 1040px       | IP 16%、地理位置 18%、受访入口 26%、浏览器与系统 16%、停留时长 12%、时间 12% |
| 分类、热门文章排行 | 不强制 850px | 保持紧凑表格；排行保留 PV 排名与前三名标记                                   |

文章六列宽度仅在本表维护，标签与摘要归入标题列。正文自然换行，表格容器内部横向滚动，分页可换行；禁止把表格最小宽度传递为页面级溢出。

有业务操作的行采用「…」按钮点击打开 Base UI Menu，不通过 hover 展开。触发按钮为 36px 圆形 ghost，打开时采用 raised；<=600px 或粗指针为 44px。菜单宽 200px、最大宽度为视口减 24px，surface 底色、24px 外圆角、1px outline 边线、6px 内边距。菜单位于按钮下方右对齐，间距 6px、边缘碰撞留白 12px，空间不足时自动翻转，Portal 避免被表格裁切。

菜单项内圆角 14px、图标 16px、文字 14px / 20px，桌面至少高 36px、触屏至少 44px。hover 与键盘高亮采用 surface-hover、按下采用 raised、删除项采用 danger；普通、审核、删除操作之间用淡线分组。菜单支持方向键、Enter、Escape 和外部点击；关闭菜单和取消弹窗后回到行按钮，触发按钮已消失时回到搜索或新增入口。行操作名称应包含对应记录的可读标识。

## 仪表盘与数据分析

仪表盘按内容与访问指标、评论审核和排期任务、流量分析组织；评论审核与排期模块位于流量分析之前。统计卡宽屏六列、中屏三列、窄屏两列；趋势与来源宽屏约 2:1，窄屏堆叠。真实数量使用中性文字，不套增长高亮。新建文章为页首 primary，上传和分类作为平铺快捷操作，不添加重复撰写入口或快捷操作外卡。长排期标题和评论自然换行。

图表范围使用本地紧凑 Tabs，图表和进度条使用 primary、success 和中性色，需要警示时使用 danger，不添加装饰性色板。查询区间、数据来源及产品定义的缺失、错误和关闭采集状态须有可读文字。图表数据点为实际按钮，支持鼠标、触屏和键盘焦点；窄屏或粗指针通过后台作用域变量 `--admin-chart-touch` 扩展图表宽度，保证每个目标至少 44px，仅图表容器横向滚动。

数据分析页标题为“数据分析”；时间范围与当前区间同列，空间不足时换行，随后连接指标和独立图表模块。统计卡宽屏四列、窄屏两列；双指标趋势与设备分布宽屏约 2:1，窄屏堆叠。PV 使用 primary，UV 使用 success，平板比例用中性色；改善方向用 success、反向变化用中性文字，并保留方向文字、数值、图例与周期去重说明。

折线图保持比例，数据点提示显示日期与双指标数值；设备比例直接展示，不加重复建议舞台。排行榜使用语义化表格和淡行线，排名采用中性胶囊、完读率采用 success。数值用等宽字体，零值和单点趋势仍保持有限坐标。数据指标、范围、去重及提示内容见产品行为。

## 文章列表与写作工作区

文章列表复用后台框架，页首放“内容管理”、简短说明和新建操作。状态 Tabs、分类 Select、精选 Select 与关键词 Input 组成工具栏，直接连接表头、行和分页；不增加独立筛选卡或额外面板留白。桌面控件并排，空间不足时换行；390px 下状态栏局部横向滚动，筛选控件纵向排列。

标题自然换行，摘要预览一行，标签留在标题列。状态同时使用文字和 success、focus 或中性色，精选使用文字标记。行操作菜单提供包含文章标题的可读名称，空状态保留重置筛选或创建入口。文章访问表现由数据分析页承载，不挤入文章表格。

新建和编辑使用独立文章页，继续高亮内容管理导航。写作页默认保留后台框架，不重复页标题、说明与底部操作区。sticky 写作栏位于后台顶栏下方，background 底色、最小高度 56px、控件间距 12px，放返回、保存状态、文章设置、专注模式和保存按钮；写作栏所有按钮使用 compact，桌面高 36px，文章设置抽屉的底部操作使用 form，桌面高 40px，与单行字段同高；<=600px 或粗指针时两组操作均高 44px。窄屏操作可换行，状态与按钮不能撑宽页面。专注模式隐藏侧栏、全局顶栏和页脚，写作栏贴顶，退出时恢复布局；模式的初始化规则见产品行为。

标题和正文构成居中、最大宽度 960px 的连续画布。标题采用共享 display 字体，桌面 32px / 44px、手机 28px / 40px，自动增高、无常驻边框和填充，保留可访问标签及清晰焦点。正文 16px、行高 1.8，无外卡底色、圆角、边框或装饰高光；工具条和字符状态仅保留后台 divider。正文通过文本插入光标表达聚焦，不增加焦点边框或高亮分隔线；标题和工具条按钮保留键盘焦点提示。正文错误使用工具条下方 danger 指示线及关联字段文字，关联实际 contenteditable。块左侧保留手柄空间，窄屏不产生页面横向溢出。

文章设置收纳产品定义的字段。内容区可用宽度至少 1100px 时采用 320px 右侧面板、间距 24px；更窄时用 Base UI Dialog 右侧抽屉，宽 360px、不超过视口宽度，高不超过 100dvh，内容独立滚动。抽屉提供关闭和保存；关闭后焦点回到文章设置按钮，不使用入场位移。摘要采用 Textarea 并显示字符计数，精选采用 Switch，排序采用数字 Input；字段约束与禁用条件只在产品行为维护。

设置入口用“待完善”或“有错误”表达隐藏字段状态；校验错误时打开对应面板并定位首个相关字段，标题与正文错误留在画布内。写作栏以可读文字表达未保存、保存中和已保存。保存及重新载入规则见产品行为，视觉核对必须检查光标、滚动和撤销历史不因布局或状态反馈被清空。

### 块编辑器

代码块使用 input 中性底色、1px outline 边线、8px 圆角和 16px 内边距，长代码仅在块内横向滚动。顶部工具栏常驻，语言位于左侧、复制操作位于右侧，不随代码横向滚动；使用 muted 文字与 outline 底边线。语言控件为本地 Base UI Select，桌面高 32px、窄屏或粗指针至少 44px；语法高亮复用共享 syntax token，颜色只作用于代码区。

正文表格的滚动容器提供 1px outline 外框与 8px 圆角裁切；单元格保留折叠边线，表格自身隐藏外边线，避免双重边框。表头底色和内容随容器圆角裁切，仅在容器内横向滚动。前台正文的场景圆角另见[前台规范](frontend.md)。

格式菜单、链接和素材选择使用本地 Base UI Popover、Dialog。斜线菜单不夺取正文输入焦点，以 listbox、`aria-activedescendant` 和文字提示表达选择，支持方向键、Enter、Escape，并保留中文输入法组合输入的处理要求。选中文字出现浮动格式栏；块手柄支持拖拽，同时提供复制、删除、上移和下移的键盘与触屏入口。工具条只在自身范围内横向滚动，触屏目标至少 44px，图片替代文字具有可见输入入口。

Markdown 导入 Dialog 使用 surface、24px 圆角、24px 内边距，最大宽 640px、最大高 88dvh，内容内部滚动，输入与提交操作复用共享 form 尺寸，窄屏或粗指针目标至少 44px。关闭后焦点回到正文。导入格式、大小、插入规则及保存条件见产品行为；复制结果以可访问状态文字反馈。

## 评论管理

页首直接展示标题和简短说明。状态 Tabs 与关键词 Input 连接表格、分页，共用 14px 连续工作区；不另套筛选卡或列表卡。桌面筛选并排，空间不足时换行；窄屏标签局部横向滚动、搜索占满宽度。工具栏密度沿用基线。

评论者使用 32px 中性首字头像与邮箱，博主回复采用品牌头像。正文与评论者使用 14px / 20px，文章、时间和邮箱使用 12px / 18px；正文自然换行，评论内容和时间独立成列。审核状态通过文字和小圆点共同表达：通过用 success、拒绝用 danger、待审核用中性色。回复对象与管理员身份单独标明。

回复 Dialog 展示原评论、文章和带可见标签的 Textarea。字段错误就近关联，产品定义的冲突或失败反馈不能遮住输入。回复关闭或删除取消后焦点返回触发按钮，按钮消失时回到搜索框；删除完成后回到搜索框。

## 媒体库

页首放媒体资产库标题、必要说明和上传入口。搜索、类型 Select、结果数量、网格、反馈和分页共用连续工作区；工具栏底部以后台 divider 连接结果区。搜索宽 300px、窄屏占满宽度，窄屏上传入口占满宽度。清空搜索后焦点回到输入框，空状态保留清空搜索与上传入口。

素材网格宽屏四列、中屏两至三列、390px 单列，内边距和 gap 均为 16px。素材单元 24px 圆角、缩略图 14px 圆角；去掉素材单元轮廓阴影、缩略图内边线和时间操作区横线。缩略图 stage 底色、高约 176px，随后显示文件名、分辨率与体积、时间和删除操作；长文件名自然换行。预览与复制按钮在 hover 或 focus-within 时出现，触屏常显；减少动态效果时取消图片缩放。

预览与删除确认使用本地 Base UI Dialog。图片完整显示并附体积、分辨率、时间和格式，附件显示文件图标与下载操作；格式许可和下载条件见产品行为。上传队列用后台 divider 淡分隔，逐文件进度采用语义化 progress 和可读状态文字；后台切换与处理中状态的业务要求见产品行为。删除与查询错误各有独立反馈位置，不把成功写入后的刷新错误呈现为写入失败。

## 分类与标签

宽屏采用分类、标签双列业务 Card，窄屏纵向排列，标题使用简短名称与中性数量徽标。分类包含可见名称标签、颜色选择、添加入口和紧凑语义化表格；标签包含输入、添加入口及直接平铺、可换行的胶囊标签云。标签云无内层容器、底色或边缘，标签胶囊保留 raised 填充、无描边，不设置人为最小高度。

分类颜色只作为用户数据色点，不改变主题。颜色控件使用 input 表面、form 圆角和清晰焦点，宽高共用 form 尺寸，与名称输入和添加按钮同排对齐；选择、筛选和确认使用现有 Select、Combobox、Dialog 与 Button，不新增视觉 token。长名称自然换行，390px 不产生页面级横向溢出。删除取消后回到触发按钮，完成后回到新增分类输入；移除标签后聚焦相邻移除按钮或新增标签输入。

## 访客日志

页首提供采集口径说明。三项摘要采用独立 24px 业务 Card，宽屏三列、窄屏单列，保留数量与业务说明，去掉装饰图标舞台。更新状态、暂停 / 恢复与搜索连接连续数据表格和分页；旧快照及加载、采集关闭、空集合、无匹配等产品状态须有可读反馈。

表格采用 stage 表头、后台 divider、surface-hover 行反馈，列宽见通用表格。正文 14px / 20px，系统信息和停留时长 12px / 18px；长路径和地域自然换行。IP 使用 focus，停留时长用中性胶囊，数值与路径用等宽字体。状态点不循环动画；清空搜索保持输入焦点，390px 仅表格容器横向滚动。采集、轮询、脱敏和时间口径见产品行为。

## 友情链接与更新日志

友情链接使用连续工作区，分类、审核、展示状态和关键词排列于工具栏，390px 纵向排列。图标 36px，图片失败显示 Link2。审核状态使用文字和中性 / success / danger，展示开关独立显示文字。表单使用可见字段标签与本地控件，删除取消回到触发按钮，成功回到搜索框；列宽及目标尺寸沿用通用表格。

更新日志保持语义化时间线、连续工作区、搜索和发布 Dialog。版本号、类型胶囊、主题与逐条清单保持原有层次，四类类型用 focus、danger、success 和中性色并附文字标签。弹窗字段错误与控件关联并聚焦；390px 无页面级横向溢出。字段、排序、日期、发布和重试规则见产品行为。

## 系统设置

资料与站点、SEO、系统偏好、备案、社交账号、访问统计使用页面级 Base UI Tabs。字段和 Section 尺寸沿用基线，390px 标签栏局部横向滚动；重新载入作为分组旁的 ghost 次要操作。字段错误切换到对应分组并聚焦，不以隐藏分组掩盖错误。

SEO 分组分为“搜索与分享”和“站长平台验证”两个平铺 Section。搜索描述使用四行 Textarea，分享图片链接与三个验证码使用单行 Input；保留可见标签、用途说明和字段错误。与其他分组共用顶部“保存所有变更”，不增加独立保存入口。

社交账号编辑项直接平铺，仅相邻条目之间用后台 divider，无独立装饰卡。排序与删除有可读名称，操作后聚焦相邻条目或新增按钮，图片失败显示通用图标。业务说明应与实际前台行为一致，不出现未接入的 AI 服务、开发信息或自动备份占位项；备份入口由全局业务浮层承载。

## 全局检索、通知与备份浮层

检索和通知使用本地 Base UI Dialog，中性列表行允许长标题、评论摘要和备份摘要换行。范围筛选采用带 `aria-pressed` 的紧凑按钮。通知数量或读取异常、已读与已处理状态使用清晰文字反馈，具体范围和操作规则见产品行为。

备份浮层沿用列表、Button 和 Switch，提供真实调度时间、执行记录及影响用户决策的备份范围说明。处理中状态保留可读反馈，重复提交和关闭条件由产品行为定义。浮层边缘与遮罩保留，不套展示舞台；使用本地组件管理焦点、关闭和基础状态。调度机制与备份内容见部署指南。

## 场景核对

共享 hover、active、focus-visible、disabled 和 `prefers-reduced-motion` 规则只在根设计系统维护，本文件的业务容器与浮层都须继承。所有操作图标有可读名称，字段有可见标签，错误与字段关联；不能只靠颜色、动画、图标或截图证明状态正确。

视觉核对固定为 1440×1000、390×844，浏览器缩放 100%。记录路由、数据快照、筛选条件、侧栏状态、滚动位置和截图范围；等待字体、图片、布局及动画稳定，对照使用相同条件。字号、行高、内边距和最大宽度用 computed style 核对，设备密度未知的参考图像素不能直接作为 CSS 尺寸，也不以固定高度裁切内容。

核对 900 / 901px、600 / 601px 的布局交界，桌面侧栏展开 / 收起、移动抽屉关闭、sticky 顶栏、全局搜索收缩，以及表格、图表、标签和编辑工具条的局部滚动。分别检查长标题、长文件名、空集合、无匹配和字段错误；触屏检查真实 44px 目标。使用已有数据或隔离临时数据，不为填满截图向常用数据库写演示记录。

筛选、排序、分页回退、保存各分组、隐藏字段定位、失败草稿、版本冲突、删除确认及浮层关闭后的焦点恢复需独立验证。文章另核对专注模式恢复、设置面板 / 抽屉切换、保存后的光标 / 滚动 / 撤销保留、斜线菜单键盘和中文输入法、块操作的触屏入口。媒体另核对触屏常显操作、进度语义与切页后的反馈。访客另核对旧快照与暂停状态反馈。
